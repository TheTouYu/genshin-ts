## 一、为什么素材不在整合包里（格式分域）

| | 整合包 GIA | 素材 GIA |
|---|---|---|
| 内容域 | UI 控件资产（服务端模板+客户端模板+脚本映射） | **图片编辑器资产（kind=8, resource_class=15）** |
| 结构 | Root.graph 多单元 | 主资源 guid + 图元子节点 + 遮罩 + 组名 |
| 导入入口 | 资产导入 | **图片编辑器导入** |
| 文件 | `hmlt-qixia-整合包.gia` 93KB | 13 个 `*.scene.gia`（同目录已放好） |

同一 GIA 信封（20B 头 + 0x0326 tag），不同内容域——**资产导入看不到图片编辑器资产**。
一个 GIA 只装一个素材组（主资源唯一），13 素材=13 文件。

## 二、素材的完整结构（三层，官方 R53/R54/R57/R69）

```
图片编辑器资产（自建图，我们生成的 *.scene.gia）
  └─ 主资源 + 图元 children（六图形×颜色×不透明度×变换×zIndex 层叠）+ 遮罩 + 组名
素材组（素材库 type55）
  └─ 控件模板组合——可含模板仅 4 类：文本框 / 界面动效 / 图片 / 特殊数字（R54）
  └─ 遮罩四参数：开关/形状(矩形·圆形)/位置/大小（R56）
  └─ 可被引用处仅 6 类：自定义开关/自定义按钮/悬浮交互页/页签/单选项视窗/图片控件（R53）
图片控件（消费端）
  └─ 图片源：静态引用(=引用素材资产+填充色+图片类型) / 动态引用 / 道具 / 状态 / 技能 / 单位状态（R69）
  └─ 图片类型三档：普通（拉伸四角形变）/ 三宫格（单向拉伸四角保形）/ 九宫格（双向保形）
  └─ 单色资产改色表现更好；素材组无法被填充颜色（R69）
  └─ 图文输入框静态引用时不能用素材组（R74）
```

## 三、Lua 运行时边界（决定接入路线）

`SetImage(source, id)` 的 source 枚举（模拟器 enums.js:45，与官方 API 文档一致）：
`StaticReference / Item / Equipment / Skill / UnitStatus / Faction / Currency / Prefab`

**自建图不在此枚举** → Lua 运行时换不了自建图。两条合法路线：

| 路线 | 用法 | 适用 |
|---|---|---|
| A. 运行时图元（现状） | `SetImage('StaticReference', 100001..100006)` + 颜色 | 游戏实体（飞机/子弹/特效）——已可玩 |
| B. 作者态绑定 | 编辑器里给图片控件配静态引用→自建图；或**专属客户端模板内绑图**→Lua `InstantiateClientUIControl(模板guid)` 得带图控件 | UI 面（背景/立绘/面板底/按钮）+ 高质量实体 |

## 五、导入操作（真机图片编辑器）

1. 打开**图片编辑器**（不是资产导入页）。
2. 导入 → 逐个选 13 个 `*.scene.gia`（Beyond_Local_Export 目录）→ 每个成一个素材组（组名=x.scene）。
3. 导入后看两点：
   - 素材组在图片编辑器里的显示名（组名可改）；
   - **UI 编辑器里图片控件选「静态引用」时，自建图出现在哪**——确认作者态绑定可用（§三路线 B 的前提）。
