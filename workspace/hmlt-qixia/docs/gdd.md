## P0 核心循环

- 唯一核心动词：**射击（移动+开火是复合动词组）**。
- PC 输入：WASD 移动（具名键 MoveForward/Backward/Left/Right，改键安全）；**J=开火/蓄力（CraftspersonKey19）、K=放宝（CraftspersonKey20）**、Enter/J=菜单确认（白皮书 §2.1 键位 1:1）。
- 手机输入：左侧虚拟摇杆（WASD 语义）、右下两钮=开火(按住=蓄力)/放宝；菜单=点击。
- 开局：标题→选机体界面（P0 仅 fj 展示 1 项可直接确认）→ MISSION ONE 卷轴起。
- 第一次有效操作：按住 J 2 秒内看到首波 dj3 被击破+分数跳动。
- 成功：**击破 boss1（3000 血）→ MISSION ONE CLEAR 结算**。失败：life 4→0（中弹×4）→ GAMEOVER。重开：结算页按钮/再来一局，全程 ≤3 击。
- 循环：`波次推进 → 走位射击 → 吃 pow 升级 → 中弹降级+补偿 → boss 弹幕考验 → 放宝/凤凰救场 → 结算 → 重开`。

## 角色设计法则（2026-10-12 用户定案，铁律）

四支柱 = **基础射击 / 僚机 / 蓄力 / 大招**。前三支柱每级（lv1→5）都有对应提升；**每角色前三支柱各有独特机制**（结构不同，非数值差异）；全部配专属美术素材；每角色有独有进阶技巧。

### 蓝兔·冰魄银针机制（2026-10-12 用户设想，结构定案）

- **蓝兔定位铁律：除蓄力伤害高外，其余机制围绕「范围+速度+攻击频率」展开。**
- 触发：本体每射 3 发冰晶弹 → 攒 1 根银针；银针纵向排列在机体后方（僚机 jedfdj=针座，lv-1 台纵队）。
- 上限随 lv 提升：4/5/6/7/8 根。
- 满上限 → **自动齐射**：银针纵向均匀展开跨全场高，同时向右高速穿透飞行=扫场针墙（攻击延后、纵轴范围广）。
- 伤害：每针独立穿透（默认 8×lv，待平衡）；死亡 lv=1 银针全清（原版死亡循环口径）。

### 蓄力联动四钩子（2026-10-12 用户批；数值全部待实测平衡）
