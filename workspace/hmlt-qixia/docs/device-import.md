## 导入步骤（真机编辑器）

1. 打开千星沙箱（Wine 下编辑器），新建或选用一张空地图。
2. 资产导入 → 选 `hmlt-qixia-整合包.gia` → 确认。导入后资产树应出现：
   - 服务端控件模板「hmlt-qixia 界面」：根容器 → **游戏层**（全屏拉伸，showCursor=true，屏蔽按键穿透）
   - 客户端控件模板「hmlt-qixia 实体模板」：**5 个根子节点**（img / tx / btn / panel / cursor）
   - Lua 脚本 **main**（已挂载在 游戏层——整合包保留挂载关系）
3. 把服务端控件模板放进地图的 UI 空间。
4. 保存地图，试玩。

## ⚠️ 导入后必做：核对真实索引（最高风险项）

真机编辑器导入时会**按槽内资产顺序重编号 guid**（genshin-ts 桶 D271 实证：GIA 内
1073742301 → .gil 内 1073741871）。脚本用 5 个模板 guid 实例化控件，重编号后若不校准
= 开局黑屏/实例化报错。

**操作**：导入保存后，在编辑器里点开客户端控件模板的 5 个根子节点，把每个的实际**索引/guid**
抄给我（或截图）。旧值对照：

| 模板 | GIA 内 guid |
| --- | --- |
| img (t1) | 1073742300 |
| tx (t2) | 1073742301 |
| btn (t3) | 1073742302 |
| panel (t4) | 1073742303 |
| cursor (t5) | 1073742304 |

变了就报我：我用 `gsts assets:scripts update` 改脚本源码里的 `T_IMG..T_CURSOR` 常量
（lua/main.lua:241），你再保存重试——不需要重新导入 GIA。

## 操作（游戏内）

- **移动**：WASD 或方向键；触屏：按住场内拖动
- **J**：普通攻击；长按蓄力（lv≥2），松手放大招（虹猫=长虹贯日 / 蓝兔=冰魄剑+银针齐发）
- **K**：放宝（虹猫=火凤燎原 / 蓝兔=冰封千里）；特性教学卡弹出时也是 K/点击 关闭
- 蓝兔满匣：针匣冰蓝呼吸环亮起 → 蓄力提速 30%
- 只剩 1 条命：血红常驻环（背水一战）
- 右下角「宝·K」按钮=触屏放大招；左上「悟 x/10」=图鉴（收集式，初始只显名）
- R 键=回到选人
