# prototype/ — 步骤 3 HTML 效果展示

**用途**：验证宽屏 444×250 场地上的手感（移动速度/弹速/波次节奏/死亡循环/凤凰/放宝），不是交付物，不是 Lua 源。`browser-run: user`（本会话无浏览器工具，Agent 未亲自试玩）。

## 启动

```bash
cd /home/h/genshin-ts/workspace/hmlt-qixia
python3 -m http.server 8792   # 根目录必须是 hmlt-qixia（SVG 相对路径 ../research/extract/...）
# 打开 http://127.0.0.1:8792/prototype/
```

## 操作

| 输入 | 功能 |
| --- | --- |
| A/D/W/S 或 方向键 | 移动（±175/±100 px/秒，原版 ±7/±4 px/帧 ×25） |
| J 按住 | 自动连发（lv 决定 1/2/3/4 发或三向扇形）；lv>1 时蓄能，满出凤凰 |
| K | 放宝：护盾 1.2s 清敌弹 + 全屏爆（普通敌 -50） |
| A/D + J 或 直接点击 | 选人：虹猫（弹速 750）/ 蓝兔（雷电弹 500，僚机同弹） |
| 调试 | 1-5 直设武器级 · B +1 宝 · P 在身前掉一个 pow · R 重开 |
| 触屏 | 拖动移动 + 自动开火 + 右下放宝按钮 |

## 与原版/千星的坐标差异

- HTML 原点左上、Y 向下；本 demo **逻辑坐标全部用千星系**（原点左下、Y 向上，444×250），只在渲染层做 `y_html = 250 - y` 翻转。移植 Lua 时数值可直接搬。
- 宽屏重标定：原版 x∈[25,373] → 本 demo x∈[25,415]（×1.11），y∈[34,220] 零改动。
- 速度口径：原版 px/帧@25fps → 本 demo px/秒（×25），变步长 1/60 累加器（GDD 再创口径，千星 OnUpdate(dt) 同构）。
