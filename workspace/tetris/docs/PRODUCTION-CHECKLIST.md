## 五、已知限制（不是缺陷，写在这里免得当成 bug 报）

| 限制 | 原因 |
|---|---|
| 最高分不跨会话保存 | 官方客户端 API 无玩家侧存储接口（唯一持久化手段是"技能变量"，属角色技能域） |
| 手机不能进双人对战/合作 | v5.0 设计：手机拦下来并给「请回 PC」引导浮层 |
| 角色技能相关表现 | 用户点名保持现状，本轮未动 |
