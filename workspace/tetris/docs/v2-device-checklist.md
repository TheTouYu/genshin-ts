# T9 真机验证清单（tetris v2）

> 执行者=lead（真机操作归 lead）；本文档是波 4 交付窗口的执行手册，逐项带判据与验证操作。
> 依据：技能 `lua-2d-ui-game-build` §10/§11（v1 全部真机教训）+ v2 设计书（v2-modes-design.md）特有项。
> 状态标注：【已验】v1 已闭合机制，v2 复用；【待验】v2 新增依赖；【复验】v1 已验但 v2 形态变了；【不适用】v2 已规避。

## 〇、执行顺序（骨架）

1. **写回安全门五条**（技能 §10.1）：root9 字段序不变 / 501 索引=记录物理序列 / 悬空引用=0 / Save_Level+Temp 双写 / 三方 sha 一致。任一不过不进编辑器。
2. **编辑器写回纪律**（§10.2）：先离开我的图 → CLI 单窗口完成全部 .gil 改动 → 切回载入 → 才试玩。每步记 SHA（「没生效」vs「被抹掉」是两种病）。
3. **部署**：`node qxqy/deploy.mjs`（+ `--calibrate` 读真机 GIL 实际 guid 写进 TPL_GUIDS 再重建）。
4. **导入后三件事**（§10.3）：模板 guid 是否又变（变了加 TPL_GUIDS 首位）/ 服务端控件名是否都在 / 真机日志五要素：`canvas WxH`、`tpl guid=…`、`cellCount=200`、`listen ok`、`guide stage=1`。
5. 逐节过下文清单；音效与手感项交用户（§四）。

## 三、四模式试玩验收清单（给用户，逐条可勾）

**casual（按 1）**
- [ ] 开局 AI 自演，顶部有「AI 代打中」横幅，音效不静音
- [ ] 按任意游戏键接管：横幅消失、**分数不清零**（AI 打的分延续计入——裁决⑤）
- [ ] 停手 5s → 提示 2s → AI 接管续算（横幅回来），再按任意键交还
- [ ] 结算页正常，R 重开回标题/重开局

**ai-battle（按 2）**
- [ ] 左盘=玩家 右盘=AI，双 HUD 独立显示
- [ ] 前若干块形状序列两盘一致（同源同序——日志 `bag=` 两前缀对齐）
- [ ] 我消 2/3/4 行 → AI 盘底部出现 1/2/4 行带洞垃圾行
- [ ] AI 消行 → 我盘也涨垃圾行（对称）
- [ ] 任一盘顶满 → 胜负结算页（显示谁赢）

**pvp（按 3）**
- [ ] P1 左盘（WASD 移旋+Space 硬降+G Hold）、P2 右盘（方向键+X 硬降+F Hold）**互不串扰**（P1 按 A 只动左盘）
- [ ] 双方 HUD/预览独立
- [ ] 垃圾行互送（同 ai-battle 判据）
- [ ] 一方顶满 → 胜负结算页

**coop（按 4）**
- [ ] 人盘（左）双人共盘 + AI 盘（右）
- [ ] P1 只有 W 旋转/G Hold 生效；P2 只有 ←→↓/X 生效——**越权键无效**（P1 按 ← 无反应、P2 按 W 无反应）
- [ ] 双人配合完成一次消行（旋转手转好姿态 → 行动手放下去消）
- [ ] 人盘顶满=失败结算 / AI 盘顶满=胜利结算
- [ ] Hold 归旋转手的手感（**可调项**：不顺手反馈给调）

**全局**
- [ ] 标题屏按 Digit1-4 选模式正常进入对应模式
- [ ] 任意模式 R 重开、结算信号正常（结算页弹）
- [ ] 音效全程有反馈（消行/落地/垃圾行/胜负）
