## 二、判据分层（技能重构的核心结构）

五个层级，每层有独立验收仪器：
1. **L0 规则层**：玩法规则/数值/难度机制（可算：ρ/stack/计分表）
2. **L1 逻辑层**：状态机/输入/模式（可测：runner 用例）
3. **L2 渲染层**：控件/文字/层序/布局（可看：模拟器出图逐字）
4. **L3 宿主层**：真机脚本/模板/挂载/编译（可验：真机日志+弹窗）
5. **L4 协作层**：多代理/提交/部署（可查：git log+哨兵）
