## 0. 结论先行（给接手的兄弟代理）

1. **文案分三层落点，层级不同不能混用**（2026-10-28 实证）：
   - **标题屏**：服务端 textbox 被展台墙（`MS.addCell('menuWall*')`）压在下面 ⇒ 只能用**运行时实例文字** `MS.addText()`；
   - **局内**：`botBanner`（底部横幅，22 号 `THEME.hint`，框 `W-180 × 48`）是唯一常驻提示位，**`bannerTimer` 是它的占用闸**（>0 时别的提示让位）；
   - **结算**：`g.settleTitle/Score/Best/Info/Extra/Opts` 六件套；`settleExtra` 原本只放装饰点 `'·  ·  ·  ·  ·  ·  ·'` ⇒ 旁白放这里零成本、不占信息位。
2. **用例不锁横幅文案**：`grep -rn "准备开始|即将由 AI|连击|等级 |本局|游戏结束" tests/*.json` 只命中 HUD 行（`得分 N　消行 N　等级 N　已填 N`）与 note 字段。**红线是 print 日志锚**（`clear n=` / `tip level=` / `tip combo=` / `takeover hint|ai|back` / `guide stage=` / `battle win|lose` / `guide clear-tip|lock-tip` / `hot settle <键>`）——一字不能改。
3. 主题色沿用 v3.0 定稿 **D（清透天空底）**：底 `#F7FCFF`、奶油 `#FFFDF8`、描金 `#E8C88A`/`#B98A3C`，
   四模式角色色：纳西妲草绿 `#7FCF6A` / 刻晴雷紫 `#B39BEA` / 少女樱粉 `#FFA8C8` / 甘雨冰蓝 `#8FD8F0`。

### 1.2 世界观原句（出处：[BWIKI 原神·过场提示](https://wiki.biligame.com/ys/%E8%BF%87%E5%9C%BA%E6%8F%90%E7%A4%BA)，已取正文）

直接可改写成游戏文案的原句（**这是我们「原神味道」的语料库**）：

- **法则**：「提瓦特存在著自己的『法则』。」→ 可写「这座棋盘也有它的法则」
- **神之眼**：「当愿望过于强烈之时，神明便会向他投下视线，『神之眼』便会出现…」→ 连击/高分文案
- **地脉**：「连接这个世界一切事物的概念网络，不同的元素在其中奔流。」→ 消行文案（「地脉轻响」）
- **世界树**：「位于提瓦特地底深处，存储着世界的全部『知识与记忆』…草神的智慧也正是来源于世界树。」→ 须弥/草绿模式
- **命之座（原文）**：「不论当下的境遇如何…提瓦特的星空中永远存在着你的位置。」→ **失败结算**最合适的一句
- **摩拉**：「大陆上通行无阻的贵金属」→ 分数隐喻
- **蒙德城**：「在风骑士团统治下的自由而欢快的城市。城中的酒与诗都颇负盛名。」
- **璃月港**：「『万商云来，千船继至。百货迭出，诸海历览。』」
- **稻妻**：「『永恒』的国度」；「在鸣神大社可以抽『御神签』…所谓的命运，最终还是掌握在自己的手里吧…」
- **冒险家协会**：「在每个城市都设有对外办公窗口」；「完成一天四个每日委托后，在冒险家协会可以领取额外奖励」
- **散失神瞳 / 七天神像**：「『七天神像』的眼瞳被飞鸟啄去，散布在大地的各个角落」
- **元素视野 / 元素之印 / 原粹树脂 / 圣遗物五件（礼冠·花·杯皿·时计·鸟羽）** 均已确认可用词。

- 框高判据 **`h >= fontSize*1.45 + 4`**，实例文字同判据（`MS.addText` 里已按 `size*1.45+12` 留余量）。
- 同一时刻 `botBanner` 只演一件事：优先级 **升级 > 四消 > 连击 > 普通消行 > 彩蛋**，靠 `bannerTimer` 让位。
- 文案里的数字（分数/等级/连击）**必须留在文案里**：玩家看的是数值反馈，风味只做前缀/后缀。
