## 0 一句话结论

v4 的角色页没内容可写，根源是**每角色只有 1 主动 + 2 条被动，其中 2 条其实是同一件事的两面**（例如刻晴「雷楔至多五秒」与「瞬落不回头」都在描述瞬落；少女「她的乡愁」「月华不熄」都在描述推层）。
v6 给 **每个角色 1 主动 + 4 条机制各异的被动/机制**（共 20 条），每条都带：官方原型原句 → 方块映射 → 数值 → **玩家看得见的方式** → **可机检的验收锚**。

| 角色 | 主动 | 4 条被动/机制 | 机制轴（互不重复） |
|---|---|---|---|
| 纳西妲 | 所闻遍计·智慧代打 | 蕴种印 / 慧明缘觉智论 / 摩耶之殿 / 净善摄受明论 | **标记连锁**（消行→灭净三业→推/清）+ 精通成长 + 领域 + 施放延长 |
| 刻晴 | 星斗归位·瞬落 | 雷楔·二段 / 长按·跨地形 / 玉衡之贵 / 金紫定垂四叠 | **位移与引爆** + 输入分支 + 施放后窗口 + 操作叠层 |
| 甘雨 | 降众天华·冰封 | 冰莲 / 唯此一心 / 天地交泰 / 霜华矢二段蓄力 | **条件性守护**（冰莲）+ 消行窗口 + 节奏改写 + 慢锁积累 |
| 哥伦比娅 | 引力涟漪·潮汐 | 引力值 / 月诱 / 新月自己的法则 / 她的乡愁 | **资源条充能与满值爆发** + 叠层 + 概率触发 + 领域增益 |

四角色的机制语言**两两不重叠**：纳西妲=「消行触发的连锁伤害」、刻晴=「落点即坐标」、甘雨=「慢下来换收益」、少女=「攒满再放」。

## 2 换算规则（写在所有数值之前）

方块与原神都是实时游戏，但**节奏单位不同**：原神一个循环 ≈ 4~8 秒动作 + 1~2 秒判定；方块一块的耗时分两带——**强玩家 0.9~1.5 s/块、新手 2.0~3.5 s/块**（【源】`docs/数值策划.md` §0.5：AI 自演实测 2.58 s/块；lead 给的 1.0~1.6 s 口径落在强玩家带内）。一局落块量：新手 53 块顶死、高手打到 L12 约 318 块；一局时长 2~8 分钟。

据此定三条换算律（并给一个**校验口径**：任何一条天赋的持续时间，都要能换算成「玩家能感觉到的一段块数」）：

| 律 | 内容 | 为什么 |
|---|---|---|
| **T 律：时间 1:1** | 官方 CD / 持续 / 窗口的**秒数原样保留** | 两边都是实时轴，秒是唯一共同单位。校验（按每块 0.9~2.6s 折算）：25s 蕴种印 ≈ 10~28 块；15s 摩耶之殿 ≈ 6~17 块；8s 玉衡 ≈ 3~9 块；5s 雷楔 ≈ 2~6 块；2.5s 灭净三业间隔 ≈ 1~3 块 —— 全部落在「够长但不到半局」的合理带 |
| **P 律：百分比 → 同轴百分比** | 官方 +15% 暴击率（暴伤 100% 下期望 +15%）⇒ 方块**得分 ×1.15**；官方 +20% 冰伤 ⇒ 得分 +20%（或等价换成 20% 时间，见甘雨·天地交泰）；官方 +13% 月曜伤害 ⇒ 引力积攒 ×1.13 | 两边的「输出轴」都只有一个：原神是期望伤害，方块是分数。保持百分比等价，**不新增量纲** |
| **C 律：点数 → 可采集的局内量** | 官方的「精通点 / 引力值」这类点数，用本局**可量化行为**代理：精通 = 200 + 8×累计消行；引力值 = 每消 1 行 +5（上限 60） | 方块里没有「精通」这个属性，但「消了多少行」是玩家唯一持续积累的量；系数 8 使 25 行进入官方「200 点起算」的收益区，正好对应新手一局的量级 |

**禁止项**：不出现「每级 +X% 技能伤害」这类没有原型支撑的通用成长（v4 的"用得多就升级"就是被判死刑的那条）。

## 3 四角色天赋树

> 每条格式：**官方原型**（原句 + 出处）→ **方块映射**（触发/效果/数值/成长）→ **玩家怎么感知**（HUD / 特效 / 文案 / 音效）→ **验收锚**（日志行或状态字段，可机检）

### 3.1 纳西妲（草 · 蕴种印 / 灭净三业 / 摩耶之殿）

#### N1 主动「所闻遍计 · 智慧代打」
- **官方原型**：「在身边施以草木之业缚…对命中的至多 8 名敌人施加蕴种印」（所闻遍计，E）；「将梦想的殿堂具现，展开摩耶之殿领域」（心景幻成，Q）。【官】
- **方块映射**：保留 v4 已有机制——按 Z 把盘面交给 AI 代打 `aiDur` 秒（N1 等级 6/8/10s）。v6 追加：施放同时**施加蕴种印**（N2）并**展开摩耶之殿**（N3），且按本局精通**延长接管时长**（N4）。
- **数值**：CD 25s / 能量 0 / 接管 6~10s（N1 三级）+ 0.04s×（lv-1）+ 净善摄受加时（≤2.5s）。
- **感知**：名卡「纳西妲·所闻遍计」+ 浮字「标准代打 · 8.5 秒」+ 棋盘草绿描边（领域）。
- **验收**：`skill ai start tier=… lvidx=… dur=…`；`state.tal.nahida.domainT > 0`。

#### N2 被动「蕴种印」（新增机制）
- **官方原型**：「蕴种印持续时间 25.0 秒」「灭净三业触发间隔 2.5 秒」「对处于蕴种印状态下的敌人触发元素反应…对该敌人及其连结中的所有敌人释放灭净三业」。【官】
- **方块映射**：施放后 **25s** 内，**每次消行**触发一次「灭净三业」，两次触发至少隔 **2.5s**：
  - 对战（pvp / ai-battle）：给对手盘顶 **1 行**垃圾（官方「对连结中的所有敌人一起打」⇒ 一次触发覆盖全场）；
  - 单人 / 合作：清自己**盘底 1 行**（等价兑现，不空放）。
  - 成长：行数由 N3 的「精通」派生（1 → 2 → 3 行）。
- **感知**：HUD 一行「蕴种印 23.4s」倒计时 + 触发次数；触发瞬间棋盘边缘草绿爆点（fx `vine`）+ 音效 `skill.nahida`；飘字「灭净三业」。
- **验收**：日志 `talent nahida-seed push n=1`（对战）/ `clear n=1`（单人）；`state.tal.nahida.seedHits` 自增；`snapshot.buff` 含 `nahida.seed`。

#### N3 被动「慧明缘觉智论」（新增机制，成长轴）
- **官方原型**：「基于纳西妲**总**元素精通超过 200 点的部分，每 1 点元素精通能使灭净三业的伤害提升 0.1%，暴击率提升 0.03%。至多使伤害提升 80%、暴击率提升 24%。」【官】
- **方块映射**（C 律 + P 律）：
  - 精通代理 `mastery = 200 + 8 × 本局累计消行`（该角色个人账本，跨局清零）。
  - 伤害侧：`dmg = min(0.80, (mastery−200) × 0.001)` ⇒ **每满 40% 增幅，灭净三业多清/推 1 行**（1 → 2 → 3 行，封顶 80% 对应 3 行）。
  - 暴击侧：`crit = min(0.24, (mastery−200) × 0.0003)` ⇒ 折成「这一次灭净三业**额外再触发一次**」的概率（可复现 LCG）。
  - 成长曲线：25 行 → 增幅 20%（仍 1 行）；**50 行 → 增幅 40%（2 行）**；100 行 → 增幅 80%（3 行）+ 暴击 24%。
- **感知**：角色页「数值」页显示 `精通 200 → 增幅 0% / 连锁 1 行`；触发双段时飘字两连。
- **验收**：日志 `talent onClear … mastery=632 dmg=0.432 chain=2 seed=2`。

#### N4 被动「摩耶之殿」（新增机制，领域）
- **官方原型**：「摩耶之殿基础持续时间 15.0 秒」「雷元素：降低灭净三业触发的间隔时间（1 名角色 −0.25 秒）」「火元素：提升灭净三业伤害（1 名角色 +14.9%）」。【官】
- **方块映射**：施放后 **15s 领域**：
  - 领域内消行得分 **+14.9%**（P 律，火元素的伤害加成）；
  - 灭净三业触发间隔 **2.5s → 2.25s**（雷元素的间隔削减，官方原值 0.25s）；
  - 时长 15s 本身即官方基础持续（水元素延长那条不实现，避免三元素需要队伍元素系统）。
- **感知**：HUD「摩耶之殿 12.3s」+ 棋盘外圈草绿描边呼吸；消行分数明显变大。
- **验收**：日志 `talent onClear … mult=1.149 domain=1`；`state.tal.nahida.domainT`。

#### N5 被动「净善摄受明论」（改造：从「数值展示」变成「施放变强」）
- **官方原型**：「施放心景幻成时，摩耶之殿将获得以下效果：依据队伍中基础元素精通最高的角色的元素精通数值的 **25%**，提高领域内当前场上角色的非基础元素精通。通过这种方式，至多提升 **250 点**。」【官】
- **方块映射**：施放瞬间按本局精通延长本次接管：`+min(2.5, mastery × 0.25 × 0.01)` 秒。
  - 换算理由：官方 25% 是「把别人的精通借给场上角色」的比例；本作把「借来的精通」直接兑现为**接管时间**。汇率 = **1 点精通 = 0.01 秒**（100 点 = 1 秒 ≈ 3~5 块的手动推进量），于是官方 250 点上限 = **+2.5 秒**（接管 6s → 8.5s，+42%，与官方「250/1000 = +25% 档」同一量级）。
- **感知**：接管浮字时长比基础值长，名卡副文案「净善摄受明论 +2.5s」。
- **验收**：`skill ai start … dur=8.5`（> `params.aiDur`）；cast 返回 `res.takeDur`。

### 3.2 刻晴（雷 · 雷楔 / 位移 / 暴击窗口）

#### K1 主动「星斗归位 · 瞬落」
- **官方原型**：「迅速投出雷楔…在命中的位置留下雷楔标记…雷楔至多存在 5 秒，投出雷楔后冷却开始计时」；「再次施放星斗归位时，瞬移到标记处进行一次斩击」；「施展重击时，在标记处引发雷暴连斩」。【官】
- **方块映射**：保留 v4 机制（按 Z 把当前块瞬移到本列最底部并立即锁定），v6 追加**留下雷楔 5 秒**（记列号），供 K2 用。
- **数值**：CD 7.5s（N2 缩到 4.5s）/ 能量 0 / 瞬落后横移封锁 0.20→0.10s（N3）/ 雷楔 5s。
- **感知**：竖劈雷光（fx `bolt`）+ 浮字「雷楔 · 瞬落 N 格」+ HUD「雷楔 4.2s」。
- **验收**：`skill blink col=… rows=…`；`state.tal.keqing.markT = 5`。

#### K2 被动「雷楔 · 二段」（新增机制，v4 只留了空壳 `mark-blink` 分支）
- **官方原型**：「在雷楔的持续期间内，刻晴再次施放星斗归位…瞬移到标记处进行一次斩击」；「雷暴连斩伤害 = 84%×2」（属性表）。【官】
- **方块映射**：
  - 雷楔 5s 内**再按一次 Z** = 引爆：当前方块瞬移到雷楔列并落底（**免 CD**，只清标记）——官方「瞬移到标记处」。
  - 若这 5s 内**先消了行** = 雷暴连斩：清除雷楔列**底部 2 格**（官方 84%×2 的「两段」），雷楔被消耗。
  - 成长：N3（N3=刻晴 3 级节点）缩短瞬落 CD，间接提高雷楔投出频率。
- **感知**：雷楔列高亮一列青紫；引爆瞬间该列竖劈（fx `bolt`）+ 音效 `skill.keqing`；HUD「雷楔 3.2s」。
- **验收**：`talent keqing-slash col=6 n=2` / `skill mark-blink`；`state.tal.keqing.markT` 归零。

#### K3 被动「长按 · 跨地形」（新增机制，输入分支）
- **官方原型**：「长按以调整雷楔标记投掷的方向」「通过长按投出的雷楔，可以悬浮在空中…跨越地形障碍」。【官】
- **方块映射**：按住 Z **≥0.35 秒**再松手 ⇒ 瞬落目标改为「**最空的一列**」（列高最小者）并落底——把「跨越地形」译成「跳过坑洼的落点选择」。短按仍是原列瞬落。
  - 0.35s 的来源：短按/长按的通用判定带是 0.3~0.4s（本仓 DAS_DELAY=0.25s、DAS_HOLD=0.35s 同为这个量级）；取 0.35 与现有输入体系一致。
- **感知**：浮字「跨地形 · 瞬移到第 7 列」；两种落点轨迹肉眼不同。
- **验收**：`skill blink-best target=7`；cast 返回 `effect='blink-best'`。

#### K4 被动「玉衡之贵」（新增机制，施放后窗口）
- **官方原型**：「施放天街巡游时，刻晴的暴击率提升 **15%**，元素充能效率提升 **15%**，持续 **8 秒**。」【官】
- **方块映射**（P 律，两个百分比都用上）：施放主动后 **8s**：
  - 消行得分 **+15%**（暴击率 +15% 在 100% 暴伤下的期望等价）；
  - 技能冷却按 **1/1.15** 记（充能效率 +15% ⇒ 同能量需求下 CD 更快转好）。
- **感知**：HUD「玉衡之贵 6.1s」+ 分数跳动变大；CD 条回得更快（玩家能感觉「能按得更勤」）。
- **验收**：`talent onClear … mult=1.150 yuheng=1`；`state.tal.keqing.yhT`；施放后 `state.cd.keqing = 7.5/1.15 = 6.52`。

#### K5 机制「金紫定垂 · 四叠」（命座 6 → 本作的操作素养条）
- **官方原型**：「命座 6：普攻/重击/元素战技/元素爆发各提供 **6%** 雷元素伤害加成，四个独立叠层，持续 **8 秒**。」【官】
- **方块映射**：**移动 / 旋转 / 硬降 / 消行** 四类操作各叠 1 层「雷伤」，每层 **+6%** 得分，**各自独立 8s** 计时，最多 4 层（+24%）。
  - 为什么用命座而不是固有天赋：刻晴的两条固有天赋（抵天雷罚、玉衡之贵）都是「窗口型」；第三条必须是**持续性**的，否则刻晴四条目里三条都在讲窗口，玩家分不清。命座 6 的四独立叠层正好是官方现成的「操作档案」。
- **感知**：HUD 四个小格依次点亮（每格 +6%）；消行分数随点亮数变化。
- **验收**：`talent onLock … stk=N`；`state.tal.keqing.stkM/stkR/stkH/stkC`。

### 3.3 甘雨（冰 · 冰莲 / 蓄力 / 领域）

#### G1 主动「降众天华 · 冰封」
- **官方原型**：「召唤退魔的冰灵珠…持续降下冰棱…同一敌人每 **1.45 秒**只能被锁定一次，共 **10 轮 51 枚**」；「持续时间 **15.0 秒**、冷却 **15.0 秒**、元素能量 **60**」。【官】
- **方块映射**：保留 v4 机制（冻结当前 3~5 行垃圾 3s，冻结期玩家盘不收垃圾），v6 追加种下冰莲（G2）与蓄力加成（G5）。
- **感知**：棋盘覆冰蓝（fx `frost`）+ 浮字「冻结 4 行 · 3 秒」+ 音效 `skill.ganyu`。
- **验收**：`skill freeze rows=… sec=…`；`state.tal.ganyu.freezeT`。

#### G2 被动「冰莲」（改造：从「主动清顶」变成「条件性守护」）
- **官方原型**：「留下一朵冰莲并迅速后退…冰莲持续嘲讽周围的敌人，耐久度按比例继承生命值上限；**被摧毁或持续时间结束（6.0 秒）时，会剧烈地绽放**，造成冰元素范围伤害」。【官】
- **方块映射**：施放时种下冰莲 **6s**：
  - **到点自然绽放**（没被打掉）⇒ 清自己**盘顶 3 行**；
  - **期间你先消了行**（= 冰莲被提前打掉）⇒ 提前绽放但只清 **2 行**。
  - 为什么 3 行 / 2 行：官方绽放是 132% 面积伤害（比 E 的 132% 单段更强），本作把「面积」译成「行数」；提前绽放少 1 行，对应「耐久被打掉一部分」。这也是唯一一条**惩罚积极打法但给即时回报**的机制（清顶更快 vs 少清 1 行）。
- **感知**：左下角冰莲图标 + 6s 倒计时；绽放时顶部整行碎冰（fx `frost` + `shard`）。
- **验收**：`talent lotus bloom n=3`（自然）/ `talent ganyu-lotus early n=2`（提前）；`state.tal.ganyu.lotusArmed`。

#### G3 被动「唯此一心」（新增机制，消行窗口）
- **官方原型**：「霜华矢发射后的 **5 秒**内，会使接下来发射的霜华矢与这些霜华矢引发的霜华绽发的**暴击率提高 20%**。」【官】
- **方块映射**：每次消行后开 **5s** 窗口；窗口内再消行 ⇒ 本次得分 **+20%**，然后重新开窗。
  - P 律：暴击率 +20% 在 100% 暴伤下 = 期望 +20%。
  - 为什么窗口而不是常驻：官方是「上一次攻击之后的 5 秒」，本质是**连段奖励**；方块里对应「连续消行」。
- **感知**：HUD「唯此一心 3.4s」+ 窗口内消行分数金色。
- **验收**：`talent onClear … mult=1.200 focus=1`；`state.tal.ganyu.critWin`。

#### G4 被动「天地交泰」（新增机制，节奏改写）
- **官方原型**：「降众天华领域内的队伍中当前场上角色获得 **20%** 冰元素伤害加成。」【官】
- **方块映射**：冻结期间**重力下落间隔 ×1.20**（节奏慢 20%）。
  - 换算理由：官方 +20% 输出，本作换成等值**操作时间**（+20% 时间 ≈ +20% 有效操作量）。为什么不做成 +20% 得分：甘雨已经有 G3 的得分窗口，再加一条得分轴会与 K4/N4 同质；改写成「节奏」才是甘雨的体感（冰域里世界变慢）。
- **感知**：冻结期间方块肉眼变慢；HUD「天地交泰 2.1s」。
- **验收**：`params.ganyu.gravityMult = 1.2`（冻结期）；`talent onClear … field=1`。

#### G5 机制「霜华矢 · 二段蓄力」（命座/重击 → 慢锁积累）
- **官方原型**：「重击：瞄准蓄力…**二段蓄力**射出霜华矢；命中后产生霜华绽发（二段冰伤）」。【官】
- **方块映射**：一块**慢锁**（本块从出块到锁定 ≥**1.2 秒**且未使用硬降）= 蓄 **1 段**，最多 **2 段**；施放时每段给冻结 **+1 行**，结算后清零。
  - 1.2s 的换算：官方二段蓄力约 1.6~2.0s；方块节奏快约 25%（一块 ≈1.0~1.6s），取 1.2s ≈ 官方蓄力在方块时间尺度上的等值。
  - 为什么「慢」= 蓄力：原神的蓄力是**用时间换强度**；方块里唯一能「用时间换强度」的动作就是「不硬降、慢慢落」。

- **验收**：`talent onLock … charge=2`；`state.tal.ganyu.charge`；施放后 `n` 比 `params.freezeRows` 多 2。

### 5.3 得分倍率的合成口径（重要，避免叠成乘法炸弹）

所有百分比加成**先相加再乘一次**：`gain = floor(base × (1 + Σ加成) + bonus)`。
- 刻晴上限 = 1 + 0.15（玉衡）+ 0.24（四叠）= **1.39**
- 甘雨上限 = 1 + 0.20（唯此一心）= **1.20**
- 纳西妲上限 = 1 + 0.149（领域）= **1.149**
- 少女上限 = 1 + 0.15（月诱 3 层）= **1.15**
乘法叠加会让「玉衡 + 四叠 + 连击 + B2B」爆表（1.15×1.24×1.5…），四消分数会失控。

## 8 风险与未决项

| 风险 | 影响 | 缓解 |
|---|---|---|
| 4 条被动 × 4 角色 = 16 条机制，**接线量集中在 main.lua** | 若接线漏一条，那条天赋就是「隐形」的 | 每条都有独立日志锚（§6.6），接完跑一次 `grep '^talent'` 就能看出缺哪条 |
| 少女的「月曜反应」被砍到只剩「33% 概率」 | 与她官方机制的核心（反应类型三分支）不完全一致 | 这是 lead 明确裁定的约束；设计书 §3.4 开头写明「不实现月曜反应族」，且分支不搬 |
| 精通/引力值都是**局内**账本，跨局清零 | 玩家看不到长期积累 | 与 v4 的「会话内养成」一致；跨局养成走 `state.lv/exp`，两者不混 |
| 长按 Z（0.35s）在手机端可能误触 | 瞬落目标被错误切到最空列 | 阈值可配（`NUM.KEQING.LONG_PRESS`），先上真机观察，必要时提到 0.45s |
| 得分倍率上限 1.39 | 与现有 4 消 800 分 + 连击 + B2B 叠加后分数略高 | 只影响观感，不影响难度；若太高，降 `STK_VAL` 到 0.04 |
