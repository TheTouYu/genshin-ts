## 采集机制（下次直接用）
1. `ys-screen-grant grant --task sfx-catalog --eta 300 --user-said "…"`（单次最多 300s，同 task 可续）
2. `ys-gui-slot 0x1000003 45 bash -c 'xdotool mousemove 1590 <y> click 1; sleep 1.0'`
3. `cp $(ls -t /dev/shm/ys-capture/*.bmp|head -1) /tmp/x.bmp && ys-text /tmp/x.bmp`
4. **分类行坐标**（展开态会下移）：环境 y=885、角色动作 y=970；**间隔 85px**
5. **点一次 = 折叠/展开切换**（连点两次等于还原 = 看起来"没反应"）
6. **滚轮无效**（编辑器与原神本体一致）；滚动条拖动**有效**（x≈1893）
