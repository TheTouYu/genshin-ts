## 一、旧帮助页（三栏文字墙）的问题清单

对照用户截图（真机/网页）与 `docs/d-help.png` 出图，逐条定位：

1. **43 行同字号正文，没有视觉落点**。三栏 15/14/14 行同字号同字重，眼睛无处停。
2. **栏头与栏体不成组**。`helpHeadBar` 竖色条放在 `x-(colW-40)/2-14`，离栏头本身约 280px，孤零零一根绿/紫/粉竖条，读起来像划痕。
3. **栏宽与内容不匹配**。左栏最长 15 字、中栏 22 字、右栏 25 字却三栏等宽 ⇒ 中/右栏字贴边、左栏右侧空 100+px。
4. **层级只有两级，而且用反了**：`!` 前缀行全用模式色 ⇒ 40 行里 20 行是彩色，强调被稀释；栏头也是同一个模式色 ⇒ 栏头不比正文更响。
5. **模式信息被拆到两栏**：键位在左栏（单人/P1/P2/合作五组竖排），模式规则在右栏 ⇒ 玩 pvp 时要在屏上两处拼装。
6. **开发项混进玩家帮助页**：「T 调试填底两行（测试用）」。
7. **文案过期/缺失**：右栏写「停手 5s / 提示 2s」，v3.1 一-2 已定版 3s/3s；v3.1 二-1 的两条难度机制（连续 14/10/7 块不消行会顶垃圾行、Lv5 起开局预置 1~3 行障碍）完全没写。
8. **底部压线**：最后两行正文落到 y=-H/2+28 的页脚上；真机右下角还有平台调试读数盖住正文。
9. **与美术体系脱节**：整页只有一根金线 + 一根 bezel 线，没有面板/圆角/留白框，像 Word 文档；四角色色只当了字色，没成为容器。
10. **无图形**：1/2/3/4 消的分值差异用「100/300/500/800」一行字表达，没有任何图形暗示。

## 二、三个方案（同一份文案，三种版式）

### A. 冒险家协会 · 委托板（落地）
- **版式**：整屏奶油纸面 + 描金圆角外框；页眉左侧「冒险家协会 · 委托板」小字 + 34/40 号标题，右侧**派蒙气泡**给阅读顺序；
  左栏 7 行**深墨键帽胶囊**（键帽 = 圆角矩形 + 白字）；右侧**四张模式委托卡**（角色色浅底 + 白卡 + 卡头色带 + 圆形徽章内嵌按键数字 + 三条要点 + 胜负胶囊）；
  底部「怎么算分」两行**标签块**，第一行四块的左色标 = 四角色色（1/2/3/4 消的阶梯），第二行金标 = 补充规则；最底部两行小字 = 连四消/T-spin/判负 + 难度侵蚀/开局障碍。
- **信息组织**：按玩家的问题顺序排——**我先按什么键 → 我得多少分 → 我玩的那一局不一样在哪**；通用键位抽到左栏，模式专属键位写进各自的卡（pvp 的 P1/P2、合作的旋转手/行动手），不再跨栏拼装。
- **配色**：纸面 `#FFFDF7`、白卡 `#FFFFFF`、描金 `#E8C88A`、深金 `#B98A3C`、墨 `#3E4A63`、次 `#7C8CA8`；
  四模式徽章/色标 = 纳西妲草绿 `#7FCF6A` / 刻晴雷紫 `#B39BEA` / 少女樱粉 `#FFA8C8` / 甘雨冰蓝 `#8FD8F0`，浅底 tint 分别 `#ECF7E3` `#EEE9FB` `#FFECF5` `#E7F6FC`。
- **图**：`docs/d-help.png`
- 为什么选它：一屏读完、零交互（真机 H 打开即可读）、信息密度靠「四种容器形状」（键帽/卡/标签/气泡）切开，而不是靠字号。

### B. 派蒙的旅行手记（对比稿）
- **版式**：摊开的两页手账，中间描金书脊 + 两个圆点；左页「今天怎么玩」= 键帽列表，右页「报酬怎么算」= **分值柱状图**（100/300/500/800 的柱高就是分值，柱顶标数字），下面三行规则；页脚一人一句四模式。
- **信息组织**：图形化优先——分值用长度表达、模式压成一行条。
- **配色**：纸白 `#FFFFFF`、书脊金 `#E8C88A`、柱 = 四角色色，墨 `#3E4A63`。
- **图**：`docs/db-help.png`
- 落选原因：左页下半空白大；四模式一行条跨在书脊上，看起来像页脚而不是内容。

### C. 四位旅伴的委托卡（对比稿）
- **版式**：没有左键位栏，四张竖卡（348×420）各带角色色大色块头、`[1]`+模式名、胜负句、三条键位/规则；底部一条白色「共用条」放算分。
- **信息组织**：模式优先（想玩哪个模式就读那张卡），共用规则下沉。
- **配色**：四角色色实心色块 + 白卡 + 金标。
- **图**：`docs/dc-help.png`
- 落选原因：四张同尺寸实心色卡互相抢眼（没有主次），通用键位缺一个稳定的家，空带多。

## 三、结算三选项（组件级审美）

旧实现：三个选项是**同一个服务端 textbox** 里的一行字 + 三个透明热区，三态只能整体改这一行的字色 ⇒ 三项永远同字号同色，悬停还会闪到别项。

- **版式 P（落地，主大两小）**：`[R] 再来一局` = 模式色实心胶囊（当前模式 accent）+ 描金外环 + 25 号白字；
  `[V] 回主页` = 白胶囊 + 描金细边 + 20 号墨字；`[Q] 结算明细` = 纯文字 18 号次色（它给信息，不是行动）。
- **版式 E（对比稿，等宽三胶囊）**：三枚同为 208×56 胶囊，只靠填色/描边分主次。
- **三态**（每档都能一眼分开）：
  - 实心胶囊：悬停**加深** 13%（白字反而更清楚）、按下加深 26% 并**下沉 3px**，金边同步提亮/压深；
  - 白胶囊：悬停**染上模式浅色**、按下更深；
  - 纯文字项：悬停转墨色、按下转模式深色并下沉。
- **服务端那条文字被清空**（不是 `SetVisible(false)`——真机对运行时实例不生效，见 D581），层序上实例永远在 textbox 之上。
- **图**：`docs/d-settle.png`（常态）、`docs/d-settle-hover.png`（悬停主行动）、`docs/d-settle-press.png`（按下第三项，顺带演示 Q 的明细行）、
  对比稿 `docs/e-settle*.png`。
