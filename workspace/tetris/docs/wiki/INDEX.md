## 五、素材链路（可复现）

```
docs/wiki/
├── INDEX.md                 ← 本文件
├── nahida.md / keqing.md / ganyu.md / columbina.md   ← 四角色详情
├── raw/                      ← action=raw 原始 wikitext（角色页 + 语音子页）
├── parsed/                   ← 解析后的 JSON（技能/数值/命座/故事/语音全量）
└── scripts/
    ├── parse_wiki.py         ← wikitext → JSON（处理嵌套模板、属性 LV1~LV15）
    └── render_md.py          ← JSON + 人工提炼 → 本文档与单角色 md
```

复现：

```bash
# 1) 抓原文（一次一个，别并发轰 wiki）
for c in 纳西妲 刻晴 甘雨 哥伦比娅; do
  curl -sS -m 25 -A "Mozilla/5.0" \
    "https://wiki.biligame.com/ys/index.php?title=$(python3 -c \
       "import urllib.parse,sys;print(urllib.parse.quote(sys.argv[1]))" "$c")&action=raw" \
    -o "docs/wiki/raw/$c.wikitext"
done
# 2) 解析 + 渲染
python3 docs/wiki/scripts/parse_wiki.py docs/wiki/raw --all
python3 docs/wiki/scripts/render_md.py
```
