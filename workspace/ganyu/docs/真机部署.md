## 七、2026-10-29 第二轮（真机反馈后）

真机首测结论：**界面正常显示，但键位全灭、没有官方结算**。日志给出两条铁证，修复如下。

### 7.1 键位全灭 = 枚举传错

日志原文（每条键一条）：

```
[frost][warn] key fail KeyboardMoveForwardKeyDown :: bad argument #2 to 'AddKeyEventListener' (KeyEventType expected, got string)
```

真机 `AddKeyEventListener` 只收 `Enum.KeyEventType.X`，字符串一律抛错。修法：注册时 `Enum.KeyEventType[名]` 优先，只有当枚举表整体不存在（旧模拟器）才回落字符串；日志改为 `keys registered ok=N/total`。

### 7.2 没有结算 = 客户端没有结算能力

官方知识（`research/千星知识图谱/learn-lua71/知识提炼.md:98`）：客户端控件/脚本**无法**做存档与结算；结算必须由服务端节点图调「结算关卡」。首版只有自定义结算屏，所以官方结算页永远不弹。

已补：

1. 信号 `ganyu_settle(win:int)` 注册（四件套）；
2. 服务端图 `1073741825`：`监听信号 → 设玩家结算状态(Victory/Defeat) → 结算关卡`，编译注入；
3. 挂到关卡实体 `1094713345`（entity 层才执行）；
4. 客户端在结算屏新增主按钮「结算并结束」（`hit_result_settle`，`E` 键同效），发送 `game.ServerSignal('ganyu_settle'):AddInt(win):SendSignal()`（另带 `ServerSignal.send` 备选形态）。

### 7.3 顺带修的两条

- `SetLocalScale` 真机要 3 个参数（日志 `4 expected, got 3`）→ 改 `(s, s, 1)`；
- `DestroyClientUIControl` 每屏有 20 个实例销毁失败 → 失败分支 `SetActive(false)` + 挪出屏幕兜底，并按 `img/txt/hit` 统计打一条日志（下轮定位用）。

## 八、2026-10-29 第三轮（真机反馈 #2）

真机反馈：① 暂停→继续后残留一个异常小窗口；② 结算页主次不对，应鼓励继续，不应把结算放最显眼；③ 游玩超过 1 分钟退出应按胜利结算。

### 8.1 暂停小窗口 = 弹层销毁失败残留

日志：`pcall fail clear screen fail=20 kinds=img:20`（每屏固定 20 个图片实例销毁失败）。`clearScreen` 已有兜底，但 `closeOverlay` 没有 → 暂停弹层的阴影/面板图片没销毁掉，继续后留在屏幕上。

修法：统一 `T.destroySafe(ctl)`（销毁失败 → `SetActive(false)` + 移到 y=-100000），`clearScreen` / `closeOverlay` / toast 清理 / 粒子回收全部走它；失败日志带 `kind` 与控件序号，便于下轮定位。

### 8.2 结算页改成「留客」版式

| 层级 | 内容 |
| --- | --- |
| 主（默认焦点） | **继续 · 1-2 冰湖回响**（下一关；失败时是「再来一次」） |
| 次 | 再战本关 |
| 弱 | 返回地图 |
| **最低** | **结束挑战并结算**：12 号次色小字，点击后还要 `T.openConfirm` 二次确认 |

配套文案：结算页写「霜原还有 N 处雪线未走完，下一站的风更冷一点」，不写「结算成功」。用法：`hit_result_continue` / `hit_result_retry` / `hit_result_map` / `hit_result_settle`。

### 8.3 一分钟宽限（官方语义）

`official-guide-concepts.md:7664-7678`：结算状态 = 逃跑合法性 + 结算状态；逃跑合法性=否时退出必为「逃跑」，=是 时才看胜利/失败/未定，且结算时读当前值。

服务端图新增：

```
whenEntityIsCreated（变量 graceArmed 守卫）
  → setTimeout(60000)
    → setPlayerEscapeValidity(player, true)
    → setPlayerSettlementSuccessStatus(player, Victory)
```

⇒ 游玩满 60 秒后中途退出，官方结算按**胜利**记录；60 秒内退出仍按规则算逃跑。日志锚点：`ganyu-grace-arm`（0s）、`ganyu-grace-victory`（60s）。
