# 真机界面不显示：挂载丢失的定位与修复

> 2026-10-28，用户真机试玩《花间茶会》，界面不出现。检查结论：**不是 Lua 报错，是脚本挂载在编辑器保存后变成 0，宿主容器节点 1901 被编辑器剪掉。**

## 证据

- 编辑后地图：`1073741839/1073741839.gil`，145,543 B，sha `2b8a50f0…`。
- `assets:scripts list`：登记表仍有 `guid=1073741825 flower_main external=120843B`。
- `assets:scripts mounts`：**mounts=0**。
- `assets:ui list`：`花间茶会宿主`（group 1900）仍在，但其子节点 `1901` 已不存在；`gil-guard` 报 `children 悬空引用 1 个（1073741901）`。
- 最新 `Beyond_Debug_Log/2026-10-28_09-12-39_3374…` 里全是 tetris 的 `cellCount=200` 日志，**没有一条 `[tea]`**——说明花间茶会的脚本没有执行，而不是执行后报错。

## 修复（已写入地图）

1. 建新宿主：`client-container` 组 **2001** + 容器节点 **2002**；再建一个 **占位子控件 2003**（1×1，位置 -1000），避免编辑器把空容器节点剪掉。
2. 从旧宿主组 1900 的 `f503` 移除已不存在的 1901（消除悬空）。
3. 新脚本 **1073742100 · flower_main2**（避开默认布局 1073741825 的 ID），源码 `default_import_file/flower/main_1.lua`。
4. 挂载：`host=1073742002 script=1073742100`。
5. `maps:resync` + Temp 同步。

1. 如果编辑器当前正打开「花间茶会」：先切到别的存档，再切回，让它从磁盘重载；不要在旧内存上直接试玩。
2. 试玩后看日志：
   - `[tea] onstart version=1.0.0 ...`
   - `[tea] probe prim 1073741910 ok` / `probe label 1911 ok` / `probe hit 1912 ok`
