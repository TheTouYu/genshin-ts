# 《花间茶会》设计说明

## 1. 目标与边界

用户给定四个关键字：甘雨、刻晴、少女、小草神；要求「精美、可爱、清新、简洁」，并且明确说 **游戏内容先不做，终点是游戏交互和各种可能的功能，菜单设计要完整**。

因此本项目分两层：

1. **完整游戏壳**（主体）：标题、主菜单、茶席、角色、图鉴（角色/茶点/手账）、设置、帮助、制作名单、暂停、结算、确认框、Toast、三种详情浮层；
2. **可玩试玩**（连接壳的玩法）：7×7 茶点三消，四席用同一规则 + 四套主题色/目标/步数；不铺关卡内容。

## 2. 命名与世界观

- 游戏名：**花间茶会 / Blossom & Tea**
- 副标题：四时花事 · 一席清茶
- 四位主人：甘雨（月下冰露）、刻晴（紫电晚风）、少女（甜梦花园）、小草神（青芽晨露）
- 玩家身份：赴约的旅人；没有强制剧情线，所有文案都围绕「坐下来喝一杯茶」。

## 3. 页面地图

```
title ──space/click──▶ menu
menu ─1─▶ chapters ──chapter──▶ chapter detail ──▶ game
     ─2─▶ characters ──char──▶ character detail ──▶ game
     ─3─▶ gallery (tab 1/2/3) ──char/tea──▶ detail overlay
     ─4─▶ settings ──help/reset──▶ overlay / confirm
     ─5─▶ credits
game ─Q─▶ pause ──resume/restart/chapters/menu──▶ ...
     ─debug T─▶ result ──again/next/chapters/menu──▶ ...
H 在任何页面 ─▶ help（对局/暂停时 pausesGame=true）
```

所有切屏走 `T.go()`：不透明幕布滑入 → 销毁旧层 → 建新层 → 幕布滑出。没有用图片 alpha 做转场。

## 4. 状态与层

- **屏幕**：`T.screen` 持有 `key/update/afterBuild/defaultFocus`。
- **弹层**：`T.openOverlay(name, builder, opts)` 保存当前 items/hits/focus/screen，压栈；`closeOverlay` 恢复。嵌套 confirm 可压在 pause 上。
- **暂停语义**：弹层 `pausesGame=true` 时，`T.tick` 跳过 **非 UI 补间**（`tw.ui ~= true`），因此对局中的交换/消除/下落动画会冻结，Toast 仍会走。
- **层序规则**：运行时实例后建在上；每屏固定「背景图 → 内容图 → 全部文字 → 热区 → 焦点框」。服务端 textbox 永远低于运行时实例，所以本项目所有文字都用运行时 textbox 实例，不依赖布局。
- **焦点**：`T.items` 数组 + 四边细条 + 四角圆点组成的 focus frame；`moveFocus(dx,dy)` 按方向+垂直距离选最近项。

## 5. 交互矩阵

| 交互 | 鼠标/触屏 | 键盘 | 反馈 |
|---|---|---|---|
| 菜单/卡片 | 悬停变色、点击 | ↑↓←→ + 空格 | 悬停音、焦点框、卡片浮起/变色 |
| 角色页 | 点击卡片 | 焦点 + 空格 | 台词/喜好即时更新 |
| 图鉴页签 | 点击 | ←→（焦点在页签） | 页签下划线、切页转场 |
| 设置 | 点击开关/分段 | ↑↓ + 空格 | 开关滑动、日志 `opt ...` |
| 对局 | 点击两格 / 拖拽 | 方向键光标 + 空格 | 选中环、提示环、飘分、连锁文字、音效 |
| 暂停 | 点击 | Q | 不透明面板、继续/提示/重开/音效/回茶席/回主菜单 |
| 结算 | 点击 | ←→ + 空格；Q 回茶席 | 星级、得分、最高、连击、消除 |
| 通用 | — | H / Q | 帮助、返回；确认框防误触 |

## 6. 美术系统

- 只用六种图元：`rect 100001 / circle 100002 / triangle 100003 / fourstar 100004 / fivestar 100005 / ring 100006`。
- 调色板：奶油 `#FFFDF8`、墨紫 `#4A3A4A`、玫瑰 `#F2A7BE`、薄荷 `#A8DFC4`、天空 `#A9CDF0`、丁香 `#CDB4E8`、黄油 `#F7D88B`。
- 背景：16 条实色渐变带 + 大圆太阳 + 云团 + 三层圆丘 + 花田 + 飘落花瓣。
- 立绘：后发/身体/脸/耳/刘海/眼睛/高光/眉/腮红/嘴/角色配件，约 30 个图元一层层拼；卡片用 bust 模式（去掉裙摆三角），详情用完整立绘。
- 图标：花、星、蛋糕、叶子、皇冠、茶杯都由图元现场拼；没有任何外部图片。
- 阴影：实色偏移块（不用图片 alpha）。
- 文字：`enableOutline` + `outlineColor` 做复杂背景可读性；字号/框高按 `h ≥ size×1.45+4` 留足。

## 7. 玩法数值

- 棋盘 7×7，五种茶点，初始盘无三连且有解。
- 交换成功才扣步；无三连自动换回、不扣步。
- 得分 = 消除数 × 60 × 连锁层数 + (消除数−3)×30。
- 星级：达成目标 1 星；≥1.25× 2 星；≥1.5× 3 星。
- 提示：8 秒无操作自动提示；右侧「提示茶点」手动提示；无解自动洗牌。
- 记录只在当前运行期：`T.records`（best/stars/plays/clears/totalCleared/maxCombo/visited/achv）。

## 8. 性能与稳定性

- 单屏约 200~425 个运行时控件；对局峰值约 600（含 49×4 茶点 + 热区）。
- 不做每帧全量重绘：只在状态变化/补间时写 `SetAnchoredPosition` / `SetSizeDelta` / `imageColor`。
- 所有平台 API 包 `pcall`；每类失败只打一次 `[tea][warn]`（`T.warn`），不静默中断 OnStart。
- `T.tick(dt)` 上限 0.05s；固定 UI 逻辑；对局动画用补间，不依赖高帧率。
- 模板探测：模拟器直接命中；真机失败时按能力扫描 fallback（见 README）。

## 9. 真实地图

- `gsts maps:create/init` 新建 `1073741839`；
- 从 tetris `hl` 地图 clone 三个模板（image/textbox/cursor）；
- `template clone` 会在嵌套 `f505.f503` 里留下 donor 模板 id；`patch-template-refs.py` 改写为新 id，否则 guard 报 children 悬空；
- 新建客户端容器组 + 容器节点（宿主）；脚本挂到容器节点；
- 脚本 inline + external 双写 + Temp 同步；
- 模板被编辑器重编号时，`calibrate-device.sh` 读名字 → 重生成 → update → guard。
