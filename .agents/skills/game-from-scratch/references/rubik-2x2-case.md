## 元件布局（v6 已写回）

- 8 块按 WCA 角位拼 2×2×2：x/z 中心 ±0.5；底层 y=0.7（离地 0.2）、顶层 1.7。
- 元件 scale 0.965（块间缝 0.035）。
- 命名：角块_DBL/DBR/DFL/DFR/UBL/UBR/UFL/UFR（WCA 标准）。
- 配色：x+ 红 / x- 橙 / y+ 浅灰白 0xD0D0D0 / y- 黄 / z+ 绿 / z- 蓝；体块灰黑 0x404040；薄片 opacity 100。

## 已闭合规则（本次新增，出处=用户直接说明 2026-08-12）

1. 平面 10009003：零旋转平躺、法线 +Y、XZ 平面 1×1（外接圆直径 1 设计语言）、绕 Y 水平旋转；**scale 厚度不生效，要真厚度必须用长方体**。
2. 空模型 10005018：隐藏 1×1×1 正方体体积（坐标在中心点）；与同尺寸装饰物重叠 → 闪烁；宿主 scale 会连带装饰物缩放（缩宿主需反向放大装饰物）。
3. 元件模板可直接用基础元件（长方体当 1×1×1 可见主体设颜色）——免空模型宿主、免闪烁。
4. 薄片贴面：表面 ±0.5×scale + 半厚 + 间隙 0.005~0.01；薄片用长方体才有厚度。
5. 白色刺眼（两次反馈闭合）：纯白 0xFFFFFF 与近白 0xE8E8E8 均刺眼；透明度降敏（opacity 85）效果弱 → 换明显更暗的浅灰白 0xD0D0D0（待最终核验）。
6. 块间留缝用元件 scale 统一缩（薄片随比例自动保持贴面）。
7. 基础元件模板自带 `basicMotion`（preset=default）组件——P4 运动器研究需先确认其对游戏行为的影响。
