# 模板与字段说明

每份文件只回答一个层次的问题。下面是"该写什么/不该写什么"的判据，配合 `scripts/longtask_new.py` 生成的骨架使用。

## LINES.md（L0.5 并行线看板）

- **该写**：进门协议（线由用户指定 / 一轮一条线 / 收尾只改本线）、线表（8 列）、共享资源与仲裁、收尾四件套、开/关线三问。
- **不写**：单线的读数细节（放 `dossiers/<line>.md`）、历史（放 `04-timeline.md`）。
- **线表 8 列**（体检器逐列校验）：`线 id`（`` `kebab-case` ``）｜名称｜目标一句｜判据｜状态｜当前断点｜恢复入口（相对链接）｜上次读数。
- **状态词表**：`活跃`（同时最多一条）/ `等用户` / `暂停` / `待裁决` / `已闭环` / `已废弃`。
- **判据**：一个新模型只读 `INDEX` + 本文件，能说出"我在哪条线、它的判据和断点是什么、我现在能不能动那块独占资源"。
- **别做的事**：把线表写成散文；把"当前在哪"只留一组（那就是被用户否掉的单线模型）。

## INDEX.md（L0）

- **该写**：三句话任务说明 + **"这是多条线并行"的一句**、现在在哪（**线表快照 + 本会话在哪条线**，不写单线断点）、按任务选读的指针表、更新分工、四条硬规矩。
- **不写**：具体读数细节（放 `03-state.md` 或 dossier）、历史（放 `04-timeline.md`）、任何"当前只做某条线"的断言。
- **判据**：一个新模型只读这份，能说出"这任务要什么、现在哪几条线在跑、下一步读哪份"。

## 01-charter.md（L1 宪章）

| 小节 | 内容 | 判据 |
|---|---|---|
| 目标 | 用户原话（带日期/会话/seq），不是转述 | 每条都能 grep 到会话里的原句 |
| 验收判据 | 可判、可数（G1/G2…） | 每条能回答"怎么算完成" |
| 边界 | 已拍板不再讨论的事 | 每条有出处 |
| 权威文件表 | 冲突时以谁为准 | 路径可达 |
| 证据三层 | 结构/行为/用户 | 防止把"能编译"说成"好用" |

## 02-xinfa.md（L1 心法）

**一条的固定形状**：

```markdown
### X# 一句话标题（动词开头）
**要做什么**：可执行的动作，正向表述。
**为什么**：不做会怎样（一句）。
**判据**：怎么检查我做到了（命令/读数/自问）。
> YYYY-MM-DD：「用户原话」
```

- 只收**用户给的**方法论，不收自己的感想；自己的推论写在 dossier 里。
- 同一主题有多条时合并，别按日期堆。
- 用户改口了：改这一条，并在 `04-timeline.md` 记一行（旧说法作废要留痕）。

## 03-state.md（L1 共享现状）

- **只放共享面**：机器与常驻服务、门禁/回归读数、最近提交（跨线都记，标线 id）。
- **分线读数**：要么放本线 dossier，要么放**标了线 id 的分节**（`[football]` / `[global]` …）；收尾只改自己那条线。
- 每张读数表标**测量时间**；空闲/负载两种场景必须分开报。
- "断点"不在本文件（它在 `LINES.md` §二 与 dossier §五）。

## 04-timeline.md（L2 决策日志）

| 列 | 要求 |
|---|---|
| 日期 | `MM-DD` 或 `YYYY-MM-DD` |
| 发生了什么 | 一句事实，不写评价 |
| 用户原话/决策 | 逐字摘，太长就截断加 `…` |
| 影响/产物 | 文件路径、commit、规则条目 |

只 append；纠错就再加一行「更正：…」。**跨线决策（开线/关线/切线/仲裁）必须进这里**，日常进展不进。

## 05-open.md（L2 缺口）

四段固定：A 用户诉求未满足 → B 缺陷/技术债 → C 待拍板 → D 已否决。
编号 `O-YYYY-MM-DD-n`；**开放条目每行第 2 列写线 id**（`` `[football]` `` / `` `[global]` `` …，体检器校验）；
关闭时移到"已关闭"段并写证据（命令/读数/commit）。

## dossiers/*.md（L3 子主题 / 单线档案）

- 开头一句"这条线要交付什么（含判据表：结构层/行为层/用户层）"，然后：在哪（仓/图/环境）、现状读数（带时间）、
  已闭环的块（别再重做）、断点（按顺序）、已否决路线、指针。
- **只做摘要与指针**：细节放权威文件，避免两处漂移。
- 每个 dossier 收口后归档（见 `archive/README.md`）。

## archive/

历史记录，不参与"当前入口"。归档件只加一行 `> 归档于 YYYY-MM-DD`。
