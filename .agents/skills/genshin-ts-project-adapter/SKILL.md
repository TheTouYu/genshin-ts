# Genshin-TS Project Adapter

This is a bounded router over existing Genshin-TS rules and Portable Knowledge Core. It does not replace `AGENTS.md`, Composite navigation, source/tests, or PKC transaction rules.

## Start

1. Read root and nearest `AGENTS.md`; run `git status --short --branch` and preserve all existing changes.
2. For complex compiler diagnosis select the `compiler-diagnostics` Context, then query Knowledge L1→L2. Use L3 only for exact claim/evidence boundaries.
3. Follow `.agents/skills/composite-docs-navigator/SKILL.md` whenever Composite/GIA is involved.
4. Read only registered authority refs and task-relevant files. Working-tree observations remain pending.

## Evidence contract

Keep current source, focused regression, real GIA, editor import, injection, and game behavior separate. STATUS, handoff, commit messages, and decisions are pointers or intent; they do not alone prove current implementation or external behavior.

## End

Run the value gate. Propose at most three immutable Bundles only for a stable diagnostic constraint, durable red/green or environment evidence, a reusable correction, an architecture decision, or invalidated knowledge. Stop for explicit approval of the displayed hash before applying. Never commit, push, inject, overwrite game files, or modify production compiler code without task-specific authorization.
