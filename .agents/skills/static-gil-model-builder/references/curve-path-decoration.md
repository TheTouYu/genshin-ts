# 沿曲线路径的连续装饰物铺放（块长/局部截面比算法）

本参考解决一类通用问题：**沿任意曲线路径（螺线、管道、线框、字母弧段、蛇形装饰等）连续铺放装饰物块**，要求视觉均匀、相邻块无断开。等角螺线 V4/V5（游戏内核验通过）是本方法的生产样本，参数与公式可直接复用；「真实样本确认」标注处为游戏/编辑器验证过的事实。

## 适用场景与触发条件

- 曲线半径或截面尺寸沿路径**变化**（对数螺线、渐开线、变径管）；
- 需要"装饰物密度与模型大小成比例"——模型/截面小的地方块数少、大的地方块数多；
- 已知旧方法失败模式：**按角度/参数均匀分布**。对数螺线半径指数增长下，内圈（小半径）一囤四五十块、外圈最后半圈只有两三块，比例严重失调、外圈精度崩坏（V1–V3 100 块均匀分布的实测问题，用户反馈，真实样本确认）。

## 算法（V4 实现，真实样本确认）

曲线以参数 θ 表示：点 `P(θ)`、切线 `T̂(θ)`、局部截面尺寸 `d(θ)`（如管径）。

1. **目标块长与局部截面尺寸成比例**：`L(θ) = λ·d(θ)`，λ≈1.2（实测 λ ∈ 1.16–1.20，±6% 内视觉均匀）。
2. **等 F 划分（核心）**：定义
   `F(θ) = ∫₀^θ (r(s)/d(s))·√(1 + K² + (z'(s)/r(s))²) ds`
   （数值积分 + 二分反函数求 `θᵢ = F⁻¹(i·F_max/N)`）。直观含义：**角度间隔 = 块长 / 局部半径** → 内圈稀疏、外圈密集。
3. **块数两种模式（V7 实测，真实样本确认）**：
   - λ 固定模式（默认）：`N = round(overlap_mult · F_max / λ)`，`overlap_mult = 1.25`——即块长 = 弦长 × 1.25，相邻块端部**轴向重叠 ≈ 20%**，无断开；
   - **N 固定模式**：用户指定总块数时 N 直接固定，λ 变为推导值 `λ = overlap_mult · F_max / N`（V7：N=198 → λ≈0.53，块比管径短、排列更密，视觉仍均匀）；自检 λ 断言用推导值 ±6%。
   - **参数耦合**：改 `D_MIN/D_MAX`（截面尺寸）会改变 F_max → λ 固定模式下 N 自动变、N 固定模式下 λ 自动变，自检断言必须从新参数表推导，勿沿用旧值。
4. **每块**：position = 相邻采样点弦中点；轴向 = 切线方向；块体 scale 随元件类型（见 calibration-and-geometry.md 轴语义表）：圆柱 `scale = [d, L, d]`（长轴=scale[1]）、长方体 `scale = [d, d, L]`（长轴=scale[2]）。
5. **结果分布（真实样本）**：V4 = 3.125 圈 120 块，各圈 `[11, 27, 68, 14]`；V5 = 3 整圈 66 块，`[9, 18, 39, 0]`；V6 = 76 块 `[13, 22, 41, 0]`；V7 = 198 块 `[43, 58, 97, 0]`。内圈稀疏外圈密集，游戏内视觉均匀（用户核验）。

关键实现要点（V4/V5 生成器 `generate-spiral-v4/v5.mts` 有完整代码）：

- F 的数值积分用细表（40000 步梯形法）+ 线性插值 + 二分反函数，保证终点 `θ_N = θ_max` 精确落在目标点（消除浮点尾差）；
- 块长/管径比自检断言从参数表推导：λ 固定模式 `λ ∈ [1.2×0.94, 1.2×1.06]`、N 固定模式用推导值 ±6%；`重叠 ≥ 19%`、各圈块数内 < 外（单调递增）；
- 每块颜色**按块索引** `t = i/(N−1)` 逐通道 lerp（见下节），与块分配算法正交、可单独复用。

## 颜色：按块索引均匀渐变（真实样本确认）

- 做法：`colorOf(i) = lerp(RED, GREEN, i/(N−1))`，逐通道 `round(0xff + (0x4c−0xff)·t)` 等；
- **不要按角度/弧长插值**：外圈块数少时最后几块颜色几乎不变（V3 按角度插值的实测问题）；
- 按块索引时每块色步进一致、都有可见色差（V4：120 块 R 通道恒步进 3；自检断言相邻块步进一致、终点 = 箭头绿 #4CAF50）；
- 渐变终点颜色必须与末端指示件（箭头）颜色一致。

## 末端指示件（箭头 '->'）比例设计（V5 用户反馈，真实样本确认）

箭头 = 三棱柱尖 `10009004` + 长方体杆 `10009001`，全部尺寸以最后一块截面直径 `dLast` 为基准（V4 教训：写死常量 0.025/0.04 不匹配放大后的管径，箭头没接上）：

| 部件 | 比例（×dLast） | scale 写法 |
|---|---|---|
| 尖底边宽 | **2×**（V4 = 1× 太窄，用户反馈不明显） | `scale.x = 底边宽/0.866`（三棱柱外接直径 = scale.x，底边 = 0.866×外接直径） |
| 尖长（顶点到底边） | **3×**（V4 = 2×） | `scale.z = 尖长/0.75`（等边三角形顶点到底边 = 0.75×外接直径） |
| 尖挤出厚度 | 1×（高度与管径匹配） | `scale.y = dLast` |
| 杆宽 | **0.55×**（V4 = 1× 杆太粗） | `scale = [0.55·d, 0.55·d, 1.0·d]` |
| 杆长 | **1×**（V4 = 2.5× 缩短） | `scale.z = dLast` |

无缝衔接约束（自检断言，误差 < 1e-6）：

- 杆背面（中心 − 半长×T̂）= 最后一块管端面心；
- 尖底边面 = 杆前端面；
- 尖点 = 管端 + (杆长 + 尖长)·T̂（整体在管端之后、共轴）；
- 三棱柱零旋转顶点朝 `-Z`（校准表），顶点朝前 +T 需按 `basisToEuler` 转局部基。
- **换元件类型必须同步换轴向索引**（V6 实测教训）：管端偏移 `tubeEnd = last.position + T̂·(轴向长/2)` 用的轴向长取自块 scale——圆柱长轴是 `scale[1]`、长方体长轴是 `scale[2]`；V6 从圆柱改长方体后漏改索引，箭头与管端差 4.9mm，被自检衔接断言抓到。

## 自检断言清单（V4–V7 直接复用）

结构级（structure.json）：

1. `items = N + 2`（N 块 + 杆 + 尖）；N 固定模式另断言 `N == 目标值`；
2. 块长轴 == 切线（`worst < 1e-6`）：圆柱局部 Y（`scale=[d,L,d]`）、长方体局部 Z（`scale=[d,d,L]`，V6/V7 同构）；平面变体另断言所有块中心 y == 抬升值；
3. 块截面 == 局部管径：圆柱 `scale.x == scale.z`、长方体 `scale.x == scale.y`；
4. λ 均匀（±6%，λ 或推导值）、相邻重叠 ≥ 19%（无断开：`worstOv > 0.001` m）；
5. 各圈块数单调递增（内 < 外；**勿用"圈3 > 半"——V7 分布 43/58/97 中圈3 占 49% 也合格，那是 V4 特例**）；
6. 箭头 5 项比例 + 3 项衔接断言；
7. 颜色：第 0 块红 #FF0300、最后一块与箭头 = 绿 #4CAF50、相邻块 R 通道步进一致、`第 i 块 == lerp(RED,GREEN,i/(N−1))`。

回读级（export.json）：同一套断言，**几何容差放宽到 float32（1e-4）**——V4 教训：回读比对用 1e-9 会在杆长等字段误报 FAIL；断言数值一律从参数表推导，禁止手写魔数；一次跑完所有断言再报（勿 fail-fast 一次一个）。

**自检脚本拷贝纪律**（V7 实测，踩两次）：从上一版复制 self-check 时，必须全量替换版本号、`BASE` 路径、structure 文件名、`prefabId`（export 过滤条件）四处，否则回读自检静默读到旧数据/旧 ID 报假错。

## 视觉调参迭代工作流要点（V4→V5 复盘）

- 参数（圈数/起点终点半径/管径/λ/重叠/箭头比例/颜色端点）集中在生成器头部参数表；自检断言从参数表推导，改参数即自动改断言；
- 每轮**只改一类变量**：V4 一次改了 4 件事（几何元件 + 块分配算法 + 箭头 + 颜色）导致一轮耗尽预算；V5 只调 3 个参数（圈数/箭头/管径）即顺利通过。全新算法与参数微调分开派活；
- **参数微调轮（改 2–3 个参数，如 V6 换元件/去高度/改粗细、V7 改数量）主代理可直接做**：复制上一版生成器 + 自检 → 改参数表与 ID → 跑生成 → 自检 → 候选 → 写回，全程十几分钟，无需派子代理（派活反而 15 分钟起步）；全新算法/几何或技能覆盖缺口才派子代理；
- 用户游戏反馈（「真实样本确认」）是参数真值来源：反馈"方向不平行"→ 减圈使 θ_max = π 整数倍；"箭头不明显"→ 给 '->' 比例；"再粗一点"→ 加管径。用户给出的比例要求直接写进验收标准与自检断言；
- 减圈/改终点时必须重算增长率 K（保持起点半径与终点锁定）并复查整体 bbox 仍在目标区域（如 1×1 地格 `[−0.5,0.5]²`，见 calibration-and-geometry.md）；
- 每轮增量添加：新 prefab + 新 aux 区间，V1–Vn 旧闭包原样保留；写回前重取实时 ID 占用（见 SKILL.md 已知陷阱）。
