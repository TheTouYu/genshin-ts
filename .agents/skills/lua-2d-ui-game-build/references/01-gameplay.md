# 玩法规则层（出货/预览/暂存/计分/难度/判负）

> 出处：复盘表 A1–A10。数值与规则改动先看本节判据。

## 1. 出块保底（A1）
- **7-bag**：每袋 7 种各一，袋内 Fisher-Yates（用主 LCG 保可复现）。
- **判据（数学上限）**：任意连续 **13** 块窗口必含全 7 种。**12 块不成立**（袋 A 尾 6 + 袋 B 头 6 可同缺一种）。
- 首袋队头排除 S/Z（开局体验）。日志 `bag=<袋序> piece=<名>`。

## 2. 预览（A2）
- NEXT 区两块：第一块原尺寸、第二块缩 14px/55% 亮度；数据来自 bag 队列队头（渲染零副作用）。

## 3. Hold（A3/A4）
- 键位先实证（模拟器键池：字母 C 不可用，G=craftCodes[14] 可用）。
- **用户定版防滥用语义**：空槽=纯存入；**非空槽交换=两块各进一格**（当前块 y+1、换出块出生位后再落一格，日志 `hold swap cur_drop=1 out_drop=1`）；**贴底交换=forced lock 代价**（当前块直接锁、槽不动）。
- canHold 闸：同一块只能 hold 一次，锁定/新块重置。

## 4. 计分体系（A5/A6）
- 行分表（Tetris Guideline）：1/2/3/4 行 = 100/300/500/800 ×等级。
- 连击：`+50×(链-1)×等级`；B2B：连续两次四消 ×1.5；**空落必须同时打断 combo 与 b2b**。
- T-spin：3 角判定 + `400×行数×等级` + 专属音效。
- `level` 从 1 起，用 `level` 不用 `level+1`；速度表逐档可读（问「人手能否完成一次操作」）。

## 5. 难度机制（A7，与速度正交）
- **机制 A 垃圾行侵蚀**：连续 14/10/7 块（按等级）无消行→底部顶 1 行带洞垃圾行；每盘独立账本、**到阈值清零重计**、每盘独立随机洞位。
- **机制 B 开局障碍**：Lv5+ 预置 1-3 行带洞障碍，**进局首帧可见**，双盘独立。
- 两者都复用 raiseGarbage 管线；日志 `garbage n=` / `obstacle n= rows=`。

## 6. 判负（A9）
- **标准 topout=新块 spawn 位置被占满**。垃圾行顶推活动块**不立即判负**——交锁定延迟（0.5s 内可横移自救），真 topout 由 spawn 兜底。
- 终局冻结（E3）：任一盘 gameOver → MODE_OVER：双方输入拒收、重力/DAS/AI 全停。

## 7. AI 难度档（A5/A6/A8）
- 三档：easy 失误 25%/topK 8 → normal 8%/3 → hard 0/1（+hold）。
- **演示/代打强制 hard**（用户原话「演示就用最强」）。
- AI 辅助等级联动：初始 easy 陪练 → Lv5 normal → Lv8 hard（`ai assist lv=`）。
- **ρ 物理上限 0.40**（每块 4 格 ÷ 行 10 格）；验收=**ρ≥0.35 + 盘面判据（stack 均值≤6、零 reset）**，别追 0.5（无源之水）。
