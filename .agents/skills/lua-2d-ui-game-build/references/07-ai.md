# AI（评估权重/难度/双盘）

> 出处：复盘表 A5–A8、E1–E3。用户三次追问「AI 是否真的会打」。

## 1. 权重不要手调——抄论文
Thiery & Scherrer 2009（BCTS，ICGA Journal，HAL inria-00418954）8 特征权重（1-ply 即达千万行级）：
```
−12.63*Landing height + 6.60*Eroded piece cells − 9.22*Row transitions
−19.77*Column transitions − 13.08*Holes − 10.49*Cumulative wells
−1.61*Hole depth − 24.04*Rows with holes
```
特征补全：洞深度（加权和）、带洞行数（我们原先缺的两个）。
实现口径：Eroded=消行数×贡献格；墙算井；Landing=四格平均。

## 2. 「会不会打」的判据
- **ρ 物理上限 0.40**（每块 4 格 ÷ 行 10 格，净持平点）→ 验收=**ρ≥0.35 + stack 均值≤6 + 零 reset**（盘面形状比 ρ 区分度更高）。
- 参照：手调 Dellacherie 0.145 → 论文权重 1-ply 0.35 + 盘面极平。

## 3. 难度档（与速度正交）
- easy: 失误 25%/topK 8；normal: 8%/3；hard: 0/1（+hold）。
- **演示/代打强制 hard**；easy/normal 仅玩家自愿。
- 难度≠只有速度：垃圾行侵蚀 + 开局障碍（见 01-gameplay §5）。

## 4. 双盘（E1–E3）
- **独立出块**：AI 盘用独立 bag（`aiRand` 独立洗袋**不动全局 LCG**，保住主盘序列断言）；7-bag 保底本身即公平，**不要镜像同步**（MIRRORQ=对手等我，用户否）。
- **镜像坑**（若仍用镜像）：spawn override 路径必须同步 `nextName/nextBag`——否则 2-ply 恒按固定块评估（实测 62 块 0 消行）。
- 终局：任一盘死→MODE_OVER 冻结双方（E3）。

## 5. 拟人外壳
- 观察-决策-执行分离：thinking 期**分帧**精化（每帧 2 候选，预算内收敛）；拟人节奏参数（think/hover/soft drop 概率）与决策质量分离——**决策要纯、执行才拟人**（实验：混入拟人修正会把 ρ 从 0.30 拖到 0.26）。
