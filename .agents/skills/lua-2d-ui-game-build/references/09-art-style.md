# 美术风格（系统化/四角色色/浅色 UI）

> 出处：复盘表 C4–C6/C8/C11。用户三次否掉风格（「太丑」「太冷」「没有审美」）。

## 1. 风格系统（一行切换）
- `config.lua` 顶部 `STYLE_VARIANT='D'` + `STYLE_A/B/C/D` 表（chrome/modes/modeTheme/deco/bg）。
- main 只读 `THEME.*` / `MODE_THEME[mode].{bg,plate,frame,accent}` / `THEME.deco`。
- 切变体=改一行→build→shot 出图对照，零代码改动。

## 2. 定稿 D「可爱清新原神风」
- 底色：墙 `#F7FCFF`、奶油 `#FFFDF8`、描金 `#E8C88A/#B98A3C`、墨 `#3E4A63`。
- 四模式四角色色：休闲=纳西妲 `#7FCF6A`（草绿/林间光点）· AI 对抗=刻晴 `#B39BEA`（雷紫/雷纹）· 双人=少女 `#FFA8C8`（樱粉/花瓣）· 合作=甘雨 `#8FD8F0`（冰蓝/冰晶）。
- 组件：标题=清透天空+奶油缎带；卡片=胶囊（矩形+两圆，**不透明预混色**——半透明重叠会露接缝）；棋盘=纸白格+模式色描边；结算=奶油面板+描金边+模式色顶条；帮助=委托板。

## 3. 审美迭代法
1. **一次做 2-3 个真不同的变体**再挑（出图 ~1 分钟/版，比改一版问一次便宜）。
2. 用户偏好线索：**克制、大字、无容器、朴素放大动画**；复杂动效/轮播会被否。
3. 用**有视觉能力的模型**自检：read_image 逐张核对（文字裁切/叠字/层级）——无视觉的模型不要凭坐标想象审美。
4. 用户会否掉「控件堆砌」：每个视觉元素要能回答「为什么在这里」。

## 4. 浅色 UI 专属坑
- 同底色对比不足（textMain 在浅底上=纯黑白）→ 高亮用**模式强调色**；文字用深墨 `#3E4A63`。
- image 的 A 通道真机不可靠 → 不透明预混色；渐暗只做在 fontColor alpha。
- 背景 wash 全屏实例会盖服务端 textbox（见 03-ui-layout 双写）。
