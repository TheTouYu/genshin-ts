## 2. 反模式清单
1. **拿控件属性/模拟器当画面**——用户看的是渲染，必须出图核（00 §0）。
2. **本机语法门当真的编译过**——真机 200-local、注入版占位符都是本机放过的（05 §2/§4）。
3. **「接线了」当完成**——L2 层未验=未完成（00 §3）。
4. **多模块只部署主脚本**——每个 require 模块都要 register（05 §3）。
5. **整文件重放/checkout 覆盖队友**——单元即 commit+禁整文件重放（10 §1）。
6. **commit 不验证内容**——哨兵 grep（10 §2）。
7. **把「感受」直接当需求实现**——先翻成数值/判据（帧耗时/对比度/ρ+stack）。
8. **装饰堆砌**（轮播/滑动下划线/箭头）——用户偏好克制（04 §4）。
9. **层序靠「后建在上」赌**——整屏浮层显式置顶（04 §2）。
10. **hidden textbox 只藏一处**——必经路径末尾收口（03 §2）。
11. **手调 AI 权重**——抄论文（07 §1）。
12. **验收追 ρ≥0.5**——物理上限 0.40（07 §2）。
13. **镜像同步对手**——独立 bag（07 §4）。
14. **异步等待空转轮询**——子代理完成会回报（10 §3）。

## 3. 每次交接/开工的自检
1. `grep -cE '^local ' lua/main.lua` ≤150？
2. `git log --oneline -3` + `git status` 干净/知道谁在改？
3. `node qxqy/runner.mjs` 基线绿？
4. `node qxqy/shot-style.mjs all d` 出图并 read_image 核一遍？
5. 部署三处同步？版本指纹是什么？
6. 用户上次反馈的最后一条是什么（别丢）？
