# 浮层层（结算/引导/帮助/倒计时/遮罩）

> 出处：复盘表 C1/C2/C10/C12/C5/C6/E3。

## 1. 浮层生命周期
- **懒创建**：第一次需要时才 `pcall(build)`，建完按当前画布摆位；用完 `DestroyClientUIControl`（幂等，重开/退出两入口都调）。
- 不用「常驻+隐藏」（`SetVisible(false)` 对运行时实例真机不生效，D581）。
- 容器模板：编辑器新建的可实例化；GIA 导入的**也可能可**（按存档区分，D639 修正 D582）——双形态探测，失败退化横幅。

## 2. 层级与顺序（C2 的真因）
- 用户看到的「文字被压成灰雾」=**先建文字后面板**。正确顺序：**遮罩→边框→面板→文字**；整屏浮层建完**显式 `SetAsLastSibling`**（别赌创建顺序）。
- 遮罩要**真全屏**（盖住棋盘与左右栏）；`dimColor` 只压暗实例层。

## 3. 结算页（C12）
- 三级选项：**主=模式色实心胶囊+白字**（再来一局）/ **次=白胶囊金边**（回主页）/ **弱=纯文字次色**（结算明细）。
- 三态：悬停提亮放大、按下下沉加深；键盘与鼠标共用动作表（`SETTLE_ACT`），防 V 双触。
- 数据行：本局/最高/消行/落块/等级 + 一句旁白；终局冻结（E3）后才允许 R/V/Q。

## 4. 引导与倒计时（C5/C6）
- 双人准备：P1/P2 **分别确认**（ready 状态实时显示 ✓），双 ready 才倒计时；AI 对抗=AI 预置就绪+单键仪式感。
- 倒计时：大字号（~120 号）屏幕正中+每秒缩放弹跳；**框高按峰值字号算**（500×190 装不下 146 号需 215.7——峰值帧 fits=false 数字不画）。
- 动画克制：单一呼吸/放大脉冲（26↔28）优于轮播+滑动下划线+侧箭头（用户原话「不如之前的字体放大动画」）。

## 5. 帮助页（C10/C11）
- 局内开帮助=**真时停**（OnUpdate 顶 return，重力/AI/计时全停），H 全局可用。
- 关键行高亮用**各栏模式强调色**（textMain 同底对比不足=纯黑白根因）；字号 19/21+行距。
- 信息架构用**容器隐喻**（委托板/旅行者手册）：页眉+派蒙气泡+键帽胶囊+模式委托卡+算分阶梯+页脚；不要三栏文字墙。

## 6. 标题页（C4/C5）
- 模式选择：避开中央棋盘投影区；胶囊卡/主机列表（无容器）；选中=放大+色点+整行高亮+模式名大字动画窗。
- 文案：手记轮播（6 条，6.1s/条，实例文字）；底栏三段提示（单行、可长按呼吸）。
- 「下一个/Hold/预览」标签用实例+`valign=Middle`（缺 valign 会顶裁）。
