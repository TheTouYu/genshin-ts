| # | 检查 | 忘了会怎样 |
|---|---|---|
| 1 | 改 lua → **`build` 再 `runner`**（runner 读存档副本，不 build=假绿） | 该红的用例全绿，白高兴 |
| 2 | **部署三处**：仓库 `tetris.save.json` / 网页工作区 `~/qxqy-workspace/*.save.json` / **真机**（地图脚本+外部文件） | 用户核验看到旧版（「还是老板版」） |

## 1. 阶段总表（0~7，每阶段：输入 → 产出 → 验收门）

| 阶段 | 产出 | 验收门（判据一句话） |
