## 0. 动手前 30 秒自查（最容易忘的 10 条）

| # | 检查 | 忘了会怎样 |
|---|---|---|
| 1 | 改 lua → **build → runner**（runner 读存档副本） | 用例全绿但跑旧代码 |
| 2 | **部署三处**：仓库 save / 网页工作区 save / 真机脚本 | 用户「还是老板版」 |
| 3 | 多模块：**每个 require 模块都 register**，`registryEntries==主+模块数` | require 全失败/跑旧版 |
| 4 | 素材用 **build 注入版**；注入点可能搬进模块 | 真机白屏（占位符 nil 截断候选表） |
| 5 | 部署前 `grep -cE '^local '` ≤150 | 真机 200-local 编译报错、白屏零日志 |
| 6 | 真机写完**让用户切图重载** | CLI 全绿但真机没变 |
| 7 | 文字：框高 `h≥1.45×size+4`、宽度按最长文案、对齐要枚举 | 整行不画/裁半字 |
| 8 | 层序：**服务端 textbox 永远在运行时实例之下** → 常驻文字双写（实例可见+textbox 隐藏，挂必经路径末尾） | 文字「写了但看不见」 |
| 9 | 每个 UI 修复**必须出模拟器截图 read_image 逐字核对** | 用户第三次打回「接线了但画面没有」 |
| 10 | 写完写 `git diff --stat` 核对不卷队友；commit 后哨兵 grep | 覆盖队友/空壳 commit |
