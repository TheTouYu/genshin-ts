# `src/injector/`：GIA → GIL 注入器

## 适用范围

这里把 `.gia` 替换进游戏 `.gil` 地图文件。它直接影响用户游戏文件，是高风险目录。

## 修改前

- 先读相关 CLI 和注入架构文档，确认操作对象、地图类型、目标图和备份策略。
- 涉及真实 GIL、玩家、`mapId`、`nodeGraphId`、覆盖、删除、清理或 reinject 时，必须先向用户展示目标和计划并获得明确确认；不能从测试配置或本机目录猜值。

## 修改规则

- 保持 GIL 外层二进制解析与 GIA protobuf 解析的边界；不要因方便而把两者混成同一种解析方式。
- 保留 `_GSTS_*`、非空图、图类型一致性和注入前备份等安全检查；任何绕过必须显式配置且经用户确认。
- 信号节点 ID 修补、文件夹遍历和二进制字段路径依赖逆向结论；修改时必须有最小样本和 pre/post 结果。
- 注入成功只说明目标替换完成，不说明编辑器或游戏行为正确。

## 验证

- 优先使用内存字节、临时副本或只读检查验证；记录目标、前后结果和失败信息。
- 改动 TypeScript 后运行 `npm run build` 和受影响测试；最后运行 `git diff --check`。

## 不要做

- 未经确认不要对真实游戏目录执行注入、覆盖、删除、清理或自动 reinject。
- 不要绕过安全检查来让测试或单个地图操作通过。
