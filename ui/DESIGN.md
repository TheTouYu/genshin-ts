## 第一章 设计约束（定稿）

> 来源：63 轮差分知识形状 + 用户四原则（扩展性/分层/递归/保留游戏概念）+ 2026-09-03 设计讨论。
> 每条约 1-2 行，实施时逐条对照。

### A. 数据与模型层

1. **双模型 + 未知字节透传**：概念对象树与 wire 读写器分层；编辑默认字节级定点修改（surgical patch），
   整记录重编码仅限整记录克隆；任何编辑不得破坏未解码字节（wire 知识仅覆盖约 1/3）。
2. **身份与寻址分离**：路径寻址（布局→容器→控件→页签→页面项）+ ID 寻址 + 角色寻址；
   ID 不可预测/同步后换新 → 同步后按角色/路径重锚。
3. **类型注册表（元数据驱动）**：控件类型 = 判别签名 + 属性 schema（值类型/单位/presence 开关/字段路径）+ 默认几何；
   新增类型只加 schema。
4. **坐标系作用域**：页面级 wire = 编辑器坐标 −(800,450)（1600×900 中心）；容器内/素材 member 相对坐标未覆盖 → schema 带坐标系上下文并显式留白。
5. **规则版本化**：知识文件带证据 hash/版本；编辑器升级可能改结构（实证），已存数据按当时 schema 解释。

### B. 操作与工作流层

6. **玩家协作第一公民**：状态锚点（AI 产出记录集）独立模块；list = 树 + 锚点差异 + 玩家改动标注；
   edit 区分"玩家细排后"与"AI 再改"。
7. **克隆引擎统一**：模板化三合一、私有树克隆、同步广播、删除清理共享内核（克隆+ID 重映射+引用/索引更新）；
   孤儿/替换/增量策略按体系记录（悬浮页=孤儿残留；按钮族/队列模板化=物理删除）。
8. **作用域参数**：官方单条/实例/模板/库实例角色结构不同；edit 默认=布局实例，广播显式。

### C. 命令体验层

9. **list 三视图**：树视图（概念层级）/ 差异视图（锚点）/ 平面视图（记录+角色+未知标记）；输出 JSON schema 稳定供 AI。
10. **dry-run 与快照即 undo**：删除/同步/模板化先展示将产生的 wire diff 再执行；不依赖编辑器 undo。

### D. 工程安全层

11. **写回纪律内建**：SHA 锁定→候选→diff 断言→读回为命令默认行为；破坏操作分级确认。
12. **官方共存与 fail-closed**：官方单条与自定义模板体系并存（from-official/from-template）；未知结构标记不猜并产出待补清单。
