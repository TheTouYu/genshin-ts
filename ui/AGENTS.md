> 本文件每次进入 `ui/` 目录都会被加载。模块总图/文件索引见 `ui/README.md`；设计全稿见 `ui/DESIGN.md`。
> 本文件只放**必须每次记住的高频约束**。

## 模块身份

原神 UGC「屏幕 UI / 界面控件」模块：把编辑器 UI 领域（布局/模板/实例/控件/容器/素材/页签/消息队列…）
变成 AI 可操作的命令层。北极星：**AI 快速创建可用控件（位置排列大致正确、属性就绪）→ 玩家细排 → AI 检测并理解玩家改了什么**。

## 铁律（每轮开发必读）

1. **双模型 + 未知字节透传**：概念对象树（游戏概念）与 wire 读写器分层。wire 知识只覆盖约 1/3——
   任何编辑**不得破坏未解码字节**：编辑默认用**字节级定点修改（surgical patch）**；
   整记录重编码仅限整记录克隆场景（模板化/同步）。
2. **身份与寻址分离**：记录 ID 不可预测（+14/+22/连续都出现过）、同步后 ID 全换、默认名会重名。
   命令定位 = 路径寻址（布局→容器→控件→页签→页面项）+ ID + 角色寻址（实例↔模板）；同步后按角色/路径重锚，不按记忆 ID。
3. **玩家协作是第一公民**：list = 读树 + 对 AI 状态锚点做差异 + 标出玩家改动（几何/文本/开关）；
   edit 需区分"AI 生成后玩家细排"与"AI 再改"。状态锚点是独立模块。
4. **克隆引擎统一**：模板化三合一、私有素材树克隆、同步广播、删除清理共享同一内核
   （克隆 + ID 重映射 + 成员/back-ref/索引更新）。孤儿/整树替换/增量补齐策略**按体系记录，不混用**
   （悬浮页素材树同步留孤儿；按钮族/消息队列模板化物理删旧树）。
5. **作用域参数**：同一对象在官方单条/实例/模板/库实例下结构不同；命令默认作用域明确（edit=布局实例，广播需显式）。
6. **类型注册表（元数据驱动）**：控件类型 = 判别组件签名 + 属性 schema（值类型/单位/路径/显隐条件）+ 默认几何。
   新增类型 = 加 schema，不写新函数。字段号随容器不同（对齐 f19.f503 vs f68.f506），路径按控件表。
7. **写回红线与确认制**：SHA 锁定 → 候选 → diff 断言 → 读回；破坏性操作（删除/同步/模板化）先 dry-run 展示差异再执行；
   快照即 undo（编辑器 undo 不可依赖）。操作游戏文件前先获用户确认。
8. **fail-closed**：未知结构标记不猜；产出"未解码字段清单"供后续差分轮定向补。
9. **全量验收 + 可复查（2026-09-03 用户核验纠偏后固化）**：L1 语义 list/anchor/diff 的验收必须对全部差分快照
   （当前 80 个 `.gsts/diff-exp/ui学习/*.gil`）逐个执行**真实 CLI** + 断言
   （`ui/tests/exhaustive-snapshot-verify.ts`、`semantic-list.snapshot-assert.ts`），禁止只抽查代表样本；
   重要输出落盘为可复现样例（`ui/verification/`）。未知结构沿用 fail-closed 并登记 open-items。

## 分层路线（实现顺序 = 用户定级）

- **L1 list**（最关键）：树视图 + 差异视图（玩家变更锚点）+ 平面视图；JSON schema 稳定供 AI 消费
- **L2 create**（很关键）：from-official / from-template / 三合一 / 克隆
- **L3 edit**：几何/文本/素材/状态 通用编辑（surgical patch）
- **L4 props**：精确属性（字号/颜色/对齐/显隐/容器-控件状态配置/消息项…）

## 递归与概念

层级递归：容器可含控件、控件可含素材树、页签可含页面项、页面配置引用容器。
概念树用统一节点接口（children/refs/props），**由 schema 声明父子关系，不硬编码层级**。
保留游戏概念：布局 / 模板 / 实例 / 官方单条 / 界面控件组库 / 容器（固有、页面）/ 控件
（按钮族、图文输入框、页签、消息队列…）/ 素材（type55 组与 member）/ 样式 / 消息项 / 页签页面项 / 状态块。

## 坐标与通用属性速记

- 几何：位置=控件中心；wire = 编辑器坐标 −(800,450)（1600×900）；**编辑器坐标 y 向上**
  **（0=屏幕底、900=屏幕顶；视觉越靠上 y 越大——轮18 贴边公式 上缘中心 y=900−h/2−m 同口径）**；
  尺寸 f32 对；t12 4 设备槽。
- 文本配置容器 f19（文本框 t25 / 图文输入框 type45 共用）：f502=字号（默认 20）/ f503=对齐（1=居中）/ f505=文本 / f510=颜色 varint ARGB。
- 小开关/标记 = `f50x varint=1` 增删（±3B），偶有反向语义——以反向实验为准，不猜。
