# 千星试玩「退出流程」实测记录（2026-10-16 真机跑通）

> 窗口：原神 0x01400001，2560×1440（屏幕）；游戏画布 1600×900（比例 1.6）。
> 输入通道：ydotool（键盘/相对鼠标）+ xdotool 读回做闭环；焦点管理走 `tools/ys-editor/ys-gui-slot`。

## 流程（三段）

| 步 | 动作 | 界面响应 | 观测时延 |
|---|---|---|---|
| 1 | 游戏窗聚焦后按 **ESC** | 暂停菜单出现：**继续挑战 / 重新挑战 / 中断挑战** | 菜单 1~2s 内出现 |
| 2 | 点 **中断挑战** | 结算页：**「未完成」** | 结算页 3~5s 内出现 |
| 3 | 点 **离开** | 回到千星大厅加载页 → 编辑器页面 | 5~10s |

## 目标坐标

| 目标 | 游戏坐标(1600×900) | 屏幕坐标(2560×1440 窗在 0,0) |
|---|---|---|
| ESC 菜单·继续挑战 | (800, 450) | (1280, 720) |
| ESC 菜单·重新挑战 | (800, 400) | (1280, 800) |
| **ESC 菜单·中断挑战** | **(800, 350)** | **(1280, 880)** |
| 结算页·重新挑战 | (1425, 47) | (2280, 1365) |
| **结算页·离开** | **(1146, 47)** | **(1833, 1365)** |

> 换算：`屏幕x = 窗x + 游戏x × 1.6`；`屏幕y = 窗y + (900 − 游戏y) × 1.6`（千星原点左下、Y 向上）。

## 关键工程事实

1. **没有可用的绝对指针定位**：KWin `workspace.cursorPos` 只读；`ydotool mousemove -a` 无效（指针跑到 0,0）；XTEST 在 Xwayland 下无效（指针纹丝不动）。
   → 唯一通道 = **ydotool 相对移动 + xdotool 读回闭环**（封装为 `ys-pointer-click`）。
2. **相对移动传递比不稳定**：实测 1.5~2.6 屏幕px/unit（随位移大小/速度变化），所以单次开环移动必不准，必须闭环逼近。
3. **点按钮要打中心**：实测点在按钮上边缘线上（y=1313 vs 按钮顶 1312）**不生效**；闭环容差 12px 内打中心即成功。
4. **界面渲染有 1~3s 滞后**：点击后至少等 2.5s 再截图判定；动作之间留 ≥2.5s。
5. **验证信号（可截图判定）**：
   - 暂停菜单在 = 画面出现「继续挑战/重新挑战/中断挑战」三按钮；
   - 结算页 = 画面出现「未完成」+ 右下「离开/重新挑战」；
   - 已退出 = 游戏窗**无「奇域试玩中…UID」水印**、显示大厅背景，编辑器页面在前。
