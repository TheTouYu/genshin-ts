### 这套容器的完整 wire 配方（CLI 要落地的全部内容）

```text
模板组 T        : 类1序5{自身} + 类2序6{序号} + 类4序4{ f14.f501 = packed[所有实例ID] }
                  名字 + 类62序82 成员表{ f73.f501 = 模板侧容器节点 }
实例组 I        : 类1序5{自身} + 类2序6{序号} + 类3序3{ f13.f501 = T } + f504 = 父(库 或 布局)
                  名字 + 类62序82 成员表{ f73.f501 = 该实例侧容器节点 }
容器节点 N      : 类7序86，名字「容器节点」，无父指针；顶层 f503 = packed[子控件ID]
控件 C          : 类7序86 家族头 + f504 = 所属容器节点 + f505{名字/类4序23 类型描述/类1序12 布局} + 类型内容块

必须同步的三处追加（缺一编辑器就丢整棵子树）：
  ① 父容器记录（布局或库）f503 追加 实例组 I 的 ID
  ② 模板组 T 的 f14.f501 追加 I 的 ID
  ③ root9.f501 森林根集追加 容器节点 N 的 ID（不含实例组）
```
