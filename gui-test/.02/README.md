## 实测事实（下轮采集直接用，别再踩）

1. **该面板滚轮无响应**——正文一律单屏完整（最长的故事2 也只有 19 行），
   「滚动+多帧拼接」整条链路对本页不需要；帧间 md5 差异全部来自背景动画相位。
2. **正文列右缘 ~x2490**，裁窗必须到 x≥2540；裁到 2450 会吞行尾字符（.01 与本轮首版同犯）。
3. **帧 md5 相等 ≠ 内容稳定**：ys-capture 连续两次可能取到 daemon 同一帧（seq 未推进），
   settle 判据须校验 `frame.seq` 前进（本轮 collect02.sh 未做，靠双重确认兜底）。
4. 右缘暗角区（x≳2460）墨迹阈值法失效——判行尾有无字符要用**邻近短行同区参照对比**。
5. RapidOCR 系统性吞/并破折号（——→一/—/无）；破折号一律用第二通道复核。
