# 场景空模型压扁方案（进行中）

> doc-type: D · status: 进行中 · updated: 2026-10-30
> 目标：把「空模型 + 装饰物」实体的**空模型**压扁（消除出生点被顶起一格），**装饰物尺寸与高度不变**。

## 0. 用户口径（2026-10-30）

> 改实体 scale.y 本身**没错**，但改完之后必须**同时补偿装饰物的缩放**，否则装饰物跟着被压扁。

数学关系（实体 scale 对子条目是乘法）：
```
世界_尺寸y = 装饰物.scale.y × 实体.scale.y
世界_高度y = 装饰物.pos.y   × 实体.scale.y
实体.scale.y: 1 → 0.01 时，要让世界值不变：
   装饰物.scale.y ×= 100
   装饰物.pos.y   ×= 100
```

## 2. 下一步（可机械执行）

1. 写 `dump-aux-tree.ts`：从实体记录出发，递归 dump `f5` 每个条目的 `res / pos / scale`，按 `res==10005018` 认出空模型条目；
2. 确认装饰物条目的存储层（root5 实体 f5 子树 / root8 实例），列出全部条目的 `(res, pos.y, scale.y)`；
3. 写 `flatten-empty-model.ts`：
   - 实体 `scale.y` → 目标值（0.01）；
   - **每个装饰条目** `pos.y ×= 100`、`scale.y ×= 100`；
   - 空模型条目本身不动（或按需要单独处理）；
4. 验收：装饰物读回 `pos.y × 0.01` 与 `scale.y × 0.01` 的乘积与原值一致（世界尺寸不变）；编辑器打开正常；出生点不再被顶起。
