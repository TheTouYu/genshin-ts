# 足球物理引擎 v3（2026-10-31 重写）

> doc-type: R · status: active · updated: 2026-10-31
> 源码：`examples/football/src-fb3/kit-loop.ts`（客户端 20008 图 1082130436，979 节点）
> 本文件是**引擎契约**：改物理前先读；调手感只看第 3 节。

## 1. 四条设计契约（用户 2026-10-31 定）

1. **时间 = 客户端造物图稳定 15 次/秒**。一步 `dt` 从**球实体变量 `fb_dt`** 读，默认 `0.0666667`（=1/15）。
   **不再读 Lua 帧时长、不再读服务端帧率**——旧实现的 `dt = fb_dt(lua) × 1.66` 让整场快慢由 HUD 脚本帧率决定
   （15fps ⇒ 1.66 倍速、60fps ⇒ 0.42 倍速）。
2. **参数全部从球实体变量读进技能变量**（首拍一次）：`fb_g/fb_e/fb_mu/fb_roll/fb_spin/fb_air/fb_magnus/fb_maxv/fb_rest`；
   缺失或为 0 时用源码常量兜底（绝不静默变 0）。另有 5 个**活参数每拍读**，改完下一拍生效：
   `fb_dt`、`fb_kick`、`fb_drib_kp`、`fb_drib_kd`、`fb_drib_r`。
3. **计算与渲染严格分离**：内核只产生 `pos/vel/spin/state`；`kit-render` 只做「朝 pos+vel·fb_dur 走」的插值运动器，
   段长 `fb_dur`（默认 0.2s）是**渲染自己的节奏参数**，与内核 dt 无耦合。
4. **引擎 API**：所有速度改变只有两个入口——**冲量**（瞬时 Δv）与**力**（加速度 × dt）。外部系统可直接施力：
   载体实体 1082130445 的 `fb_fx/fb_fy/fb_fz`（单位质量力 m/s²，每拍叠加）。

### 1.1 玩家位置的三级来源（2026-10-31 翻面）

| 优先级 | 来源 | 延时 | 条件 |
| --- | --- | --- | --- |
| 1 | **客户端直读角色实体**（载体变量 `fbc_e` 是服务端在玩家选中球选项卡时写一次的句柄 + `getEntityLocation`） | **0** | 句柄有效且位置非原点 |
| 2 | 服务端每拍写 `fbvx/fbvz` | 1 拍（0.133s） | 上一级失效 |
| 3 | **冻结上一拍位置** | — | 两级都失效（绝不回 0，回 0 会把球吸向中圈） |

20008 白名单**没有** `getCurrentCharacter` / `getCharacterEntityOfSpecifiedPlayer` / `getEntityLocationAndRotation`（编译期实测拒收）⇒ 句柄只能由服务端给，位置查询搬到客户端。

**句柄登记（2026-10-31 用户提议落地）**：kitListen 的 `whenEntityIsCreated` 事件（官方语义：角色实体进入关卡时触发）里解析玩家角色并写 `fb_char_e` + `fbc_e`；`kit_state('B')` 的缓存解析也同步双写。⇒ **不再依赖"玩家点过球的选项卡"**，角色一进关就有句柄，换角色/倒下重解析也覆盖。

## 2. 每拍管线（顺序固定，改顺序 = 改物理）

```
读状态
 → 累积冲量（踢球 5 种 / 抢断 / 解围 / 停球 / 身体拦截）
 → 施加冲量
 → 累积力（重力 g / 带球弹簧-阻尼 / 马格努斯 / 外部施力）
 → 空气阻力 → 自旋衰减 → 限速（在位置积分之前！）
 → 位置积分（速度平均值 = 二阶：x += v̄·dt，15Hz 弹道误差 22% → 2%）
 → 地面接触（TOI：解出撞击时刻 t*，用**撞击时刻速度**反弹，余下时间继续吃重力）
 → 接触摩擦（法向冲量 + 库仑上限 + 自旋耦合，Δslip = 3.5·J）
 → 纯滚动约束（ω = (vz/R, wy, −vx/R)）+ 滚动阻力（恒定减速度 roll·g）
 → 静止（平滑衰减：<rest 减半，<rest/4 归零）
 → 门柱（扫掠圆：线段 p0→p1 与柱截面求交，快球不穿柱）
 → 门线穿越（插值判进球，先于边界反弹）
 → 边界反弹（门洞内不放墙，球能真的越过 52.5 的门线）
 → 状态机 0..5 → 写回 + 回传
```

| 变量 | 默认 | 作用 | 调大的效果 |
| --- | --- | --- | --- |
| `fb_dt` | 0.0666667 | 物理步长（秒） | 同一次操作模拟时间变长（慢动作）；与真实 15Hz 不一致会改变球速观感 |
| `fb_g` | 9.8 | 重力 | 球更沉、弹道更低 |
| `fb_e` | 0.5 | 触地反弹系数 | 弹得更高更久 |
| `fb_mu` | 0.8 | 库仑摩擦系数 | 落地更「粘」、滑行更短 |
| `fb_roll` | 0.06 | 滚动阻力系数（减速度 = roll·g） | 滚得更快停下 |
| `fb_spin` | 0.15 | 竖直轴自旋衰减（1/s） | 弧线更短 |
| `fb_air` | 0.05 | 空气阻力（1/s） | 球飞不远 |
| `fb_magnus` | 0.03 | 马格努斯系数（只作用于 wy） | 弧线更大 |
| `fb_maxv` | 18 | 限速 | 允许更快射门（也更容易隧穿） |
| `fb_rest` | 0.35 | 静止阈值 | 球更早停下 |
| `fb_kick` | 1.0 | 踢球力度倍率 | 所有键的球速同比放大 |
| `fb_drib_kp` | 45 | 带球弹簧刚度 | 球回位更快、更「粘脚」 |
| `fb_drib_kd` | 12 | 带球相对速度阻尼 | 更不容易过冲（太小会抖） |
| `fb_drib_r` | 2.0 | 带球助力半径 | 更远就能把球吸过来 |
| `fb_dur` | 0.2 | **渲染**每段补间时长（秒） | 视觉更平滑但更「飘」；与物理无关 |

键位：有球（2.4m 内且球速<8）1 轻射 10+3.2 / 2 重射 16+4.5+侧旋 / 3 高吊 7+9 / 4 贴地传 12+0.8 /
5 弧线 14+4+交替侧旋 / 6 重置到脚下；无球 1 抢断 7+4（2.5m）/ 2 解围 14+5（3m）/ 3 停球（吸掉 88% 速度）。
踢球方向：跑动时按**移动方向**，站定时按「玩家→球」（旧实现永远按玩家→球 ⇒ 跑过球再按射门会把球往回踢）。

## 5. 已知限制（不是 bug，是取舍）

- **横梁**没有独立碰撞体：越过 2.5m 的球按「门洞外」处理（会撞底线反弹），观感像打在框上。
- **马格努斯只作用于竖直轴自旋 wy**。滚动自旋 ω=v/R≈40rad/s 若参与气动力，K=0.03 会给出 ~12m/s² 的「砸地」力
  （旧测试台 slot2 漏清 wz 时球被吹到 6.59m 就是同一机制）。
- **带球助力是弹簧-阻尼力**（不是瞬移、不是速度改写）：`a = kp·(目标−球) − kd·(球速−玩家速度)`，上限 30m/s²。
  目标点 = 玩家前方 1.0m。跑动时球贴脚；站定时球停在 1m 处。
- 碰撞只有球↔地面/门柱/边界/玩家身体；**无球员间碰撞、无球门网**。

## 6. 改动纪律（踩过的坑）

1. 改 `kit-loop.ts` 后**必须** `node scripts/gen-kit-loop-test.mjs`（测试图是生成物，手改会被覆盖）。
2. 位置积分、接触求解、限速顺序不能乱：限速必须在**位置积分前**（旧实现先走 1.33m 再夹）。
3. 任何「每拍 ×N」的系数都是帧率相关陷阱；一律写成「每秒速率 × dt」。
4. `sim/` 是旧的规格实现（9.81 / magnusK 0.00356），**与本引擎已分叉**，不能互相借读数。
