## 0. 设计前提（先钉死，否则技能会互相打架）

| # | 前提 | 影响 |
|---|---|---|
| P1 | **4v4 = 8 个玩家实体 + 1 个共享球**，球只有一份，谁碰谁改 | 球权=瞬时接触权，不是"持有道具" |
| P2 | 物理**单客户端权威**（当前）：一台客户端算球，其余客户端收结果 | 远端玩家看到的是"插值后的球"，≤1 拍延迟（133ms） |
| P3 | 技能输入走 Lua 键位，7.5Hz 拍频（15Hz 上限待丘丘人实测） | 按键响应 ≤2 拍；连招需去抖 |
| P4 | 客户端图**没有输入原语**，只有几何/数学/造物操作 | 一切"方向/瞄准"都要么取玩家朝向，要么取玩家→球向量 |
| P5 | 服务端运动器是"演"，不是"算"：球的位置每拍被覆写 | 技能只需给出**速度/自旋/目标点**，不写位置 |

## 2. 我建议的 P0 基本盘（8 个，能打一场像样的 4v4）

> 选取原则：**覆盖"控-传-射-防"四拍闭环 + 全部可在当前节点面实现**，多人争议项先不上。

1. **A1 带球**（已有）
2. **A2 停球**（新增，否则来球接不住）
3. **B1 短传 + C3 吊传**（一个键位区分长短，复用现有两种踢法）
4. **C1 推射 / C2 抽射 / C4 弧线**（复用现有三种踢法，C4 加方向调制）
5. **D1 抢断**（最小可玩的防守，需一个 0.5s 冷却）
6. **D2 拦截**（E1 线段判据已验，接线成本低）
7. **D4 解围**（复用重射，限定区域）
8. **E1 换人**（4v4 没它无法"防守时切到最近的人"）

P1（第二阶段）：A3 护球 / A4 踩球 / A5 挑球 / B2 直塞 / B4 传中 / C5 凌空 / D5 门将扑救 / E2 团队指令。
P2（可选，趣味向）：B5 回做 / B6 花式 / E3 表情。

## 5. 4v4 必须先拍的三个多人问题（技能设计绕不过）

1. **谁算物理**：单客户端权威（现在）⇒ 主机掉线全队卡死；要 4v4 得定"房主/服务端算"或"球权持有者算"。
2. **延迟补偿**：远端玩家 133ms 看到旧球位，抢断判定必须以**服务端时间戳**为准，否则"我明明先碰到"。
3. **球权仲裁**：两人同拍碰到球时，谁赢？（建议：距离更近者赢，相同则 tick 奇偶决定，且服务端记录 lastTouch 供回放。）
