## 4. 状态机

### 球状态

```text
FREE(自由/静止) ──控球判定──▶ CARRIED(被带球·弹簧场)
CARRIED ──传球──▶ FLYING(传球飞行) ──接球判定──▶ CARRIED(控球权转移)
CARRIED ──射门──▶ FLYING(射门飞行) ──门线判定──▶ GOAL(进球+1) ──2s──▶ 复位
FLYING ──出界/停球──▶ FREE/复位
```

| 状态 | 渲染/表现 | 接受事件 | 运动 |
|---|---|---|---|
| FREE | 球静止或自然滚动 | 控球判定 | 无（或惯性滚动） |
| CARRIED | 球在脚前贴地 | 选项卡 9 项 | 控球弹簧场（见 5.3） |
| FLYING | 球自旋（ω 随物理更新） | 无（输入锁） | 完整飞行物理 5Hz（见 5.1/5.5） |
| GOAL/SETTLE | 停球 | 无 | 延时后瞬移回罚球点 |

### 角色状态

- HAS_BALL / NO_BALL；控球判定：球距角色 < 1.2m 且球速低 → CARRIED

## 5. 物理模型（已确认 2026-08-22，5Hz）

### 5.1 飞行物理（射门/传球空中）—— 含马格努斯效应

每 tick（dt=0.2s）积分，合力 = 重力 + 空气阻力 + 马格努斯力：

```text
a_g = (0, -9.8, 0)                    # 重力
a_d = -k_d · |v| · v                  # 空气阻力，k_d≈0.03
a_m = k_m · (ω × v)                   # 马格努斯力，k_m≈0.008（ω=角速度向量，×=叉积）
v += (a_g + a_d + a_m) · dt
p += v · dt
ω *= exp(-k_ω · dt)                   # 旋转衰减，k_ω≈0.08 /s
```

- 叉积 `ω×v` 方向决定弧线弯向（右手系，Y 轴朝上）：
  - ω 竖直（绕 Y）→ 水平弧线（香蕉球）
  - ω 水平横轴（绕 Z）→ 上旋/下旋（下坠差异）
- 射门默认内旋：右路射门 ω_y<0（绕 Y 负向）→ 球向门内侧弯

### 5.2 碰撞物理

| 对象 | 简化几何 | 模型 | 系数 |
|---|---|---|---|
| 地面 | 平面 y=0 | 球心 y<r → 拉回 y=r，v.y=-e·v.y，水平摩擦 | e=0.65，水平×0.85 |
| 门柱 | 圆柱（轴 x=-52.5, z=±3.66, r≈0.12） | 标准反射 v' = v - (1+e)(v·n)n（n=水平法线） | e=0.7 |
| 球员/队友 | 圆柱（r≈0.35, 高 1.8，位置实时读） | 同上 | e=0.7 |
| 滚动 | 贴地 | v *= 0.985/tick；\|v\|<0.3 → 停 | μ=0.985 |

- **碰撞扫掠（防 5Hz 穿透）**：球速 22m/s × dt 0.2s = 每 tick 移动 4.4m，离散判定必穿透 →
  用**线段-圆柱最近距离**：计算旧位置→新位置线段上离圆柱轴心最近点，距离 < r球+柱半径 → 碰撞
- 碰撞制造旋转（真实细节）：反弹时 ω 加切向扰动分量（v1 简化）

### 5.3 控球物理（带球·弹簧场，已确认"要脱脚"）

```text
每 tick（CARRIED 状态）：
  锚点 = 玩家位置 + 玩家朝向 × 0.9m（脚前，y=r 贴地）
  球加速度 = k·(锚点 − 球位置) − c·球速度      # 弹簧-阻尼
  k≈20 /s²（刚度），c≈10 /s（阻尼）
  丢球判定：球距锚点 > 1.5m 或 球速 > 玩家速度×1.5 → 脱脚 → FREE（带当前速度滚动）
```

- 直线走 → 球稳贴脚边；急转/急停 → 球甩出去（真实感核心）

### 5.5 5Hz 实现方案（引擎通道，已确认）

```text
物理 tick（dt=0.2s）：
  ① 计算新位置（5.1 积分 + 5.2 碰撞 + 5.3 若带球）
  ② activateFixedPointMotionDevice(球, "physics", 匀速直线, 固定时间=0.2s,
       targetLocation=新位置)   ← 帧间平滑插值，视觉 60fps 不跳帧
  ③ whenBasicMotionDeviceStops("physics") → 触发下一 tick（相对时序，负载下自然减速不漂移）
```

- **为什么用匀速直线而不是瞬间**：5Hz 下瞬间写位会跳帧（4.4m/跳）；匀速直线运动器在 0.2s 内平滑到达
- **不用定时器驱动**：绝对时刻在负载高峰后放行会中断未完成的运动器（engine-rules 实证），停止事件链是相对时序
- 每 tick 节点预算：飞行 ~125（三力积分+5 对象扫掠碰撞+写位+旋转），带球 ~40
- 球自旋表现：随物理更新（v1 用写旋转或匀速旋转运动器，阶段 0 验证）

## 10. 状态机设计（2026-08-23）

```
state: 0=静止 FREE / 1=空中 FLYING / 2=滚滑 ROLLING
```

| 状态 | 受力 | 转换条件 |
|---|---|---|
| 空中 FLYING | 重力 + 空气阻力 + 马格努斯 + 旋转衰减 | 落地反弹后 |vy| 小 → 滚滑；|v|<0.3 且贴地 → 静止 |
| 地面反弹（瞬态） | y<r 且向下 → 拉回 y=r + vy=-e·vy + 水平×0.85 | 反弹完 → 空中或滚滑 |
| 滚滑 ROLLING | 滚动/滑动摩擦（水平 ×0.985/tick） | |v|<0.3 → 静止 |
| 静止 FREE | 无 | 选项施力 → 空中/滚滑 |

- 选项（tabBar 挂足球，5m 球体范围）施力：8 施力（覆盖重力/阻力/马格努斯/弹力/摩擦/旋转）+ 1 复位（瞬移场中间）。
- 球持续运动直到动能耗尽（|v|<0.3）才算静止，中间经历完整物理过程。
