# 跟随运动器公转复刻方案（B 轮 Round 0 草稿，日志核验后定稿）

> 状态：待验证提案（2026-08-31 模型侧）｜来源：1913 全 9 图读图 + 26 块组件槽扫描 +
> 跟随运动器官方文档 mhuts59m9gju + 用户情报（跟随需配置、与基础运动器互斥）。

## 一、机制结论（图级证据，帧级证据待 1913 新日志）

1. 1913 全部 9 图没有任何跟随运动器节点（245/246/365/668 genericId 零命中）——
   跟随不是节点图运行时动态添加的。
2. 1913 内 26 个块定义/实例没有 followMotion(9) 组件槽（只有 basicMotion(4) 等）——
   跟随配置在官方元件资产层（编辑器资产库，地图文件不可见）。
3. 中心球 = 创建图 n=6 的 Create Prefab 1077936170（空模型 10005018），位置
   = 魔方位置+(2,2,-2) = 世界 (2,2,-2)（魔方中心），写图变量"实体"，供镜头跟随
   （挂接点"物件镜头_1"）。
4. 官方 per-block 图（1073741835）：监听旋转信号 -> busy 锁 -> 循环写回 3 个向量变量
   （3D Vector Rotation->取整->Set）-> 分支 Target-Oriented 设备 / Fixed-Point 瞬移设备
   -> 设备停解锁。位置传动靠跟随（图内不体现）。
5. 用户情报：跟随运动器需要配置，且与基础运动器组件互斥；不配置就只是基础运动器。
6. 完全隐藏（1082130433）= 恒 false 的 20001 布尔过滤器，当前 1913 无任何引用——
   疑官方资产层绑定用（隐藏中心球），复刻可不用。

## 二、复刻方案（推荐架构，待用户确认）

目标形态：让转动层的 9 块跟随一个"轴心球"完成圆弧公转+自转；其他块不动。
中心球本身用基础运动器（匀速/朝向目标）自转 90°，层内块通过跟随运动器
（完全跟随 or 跟随位置+旋转）传导位置+旋转变化。

- 组件层（地图级，一次性）：
  - 26 块定义/实例：basicMotion(4) 槽替换为 followMotion(9)（CLI 已有 followMotion(9)
    完全跟随预设快照编码器与回归；与基础运动器互斥，必须替换不能并存）。
  - 新建"轴心球"实体（空模型 10005018，隐藏）保留 basicMotion(4)（供设备转动）。
- 节点层（每转）：turn 图 signal 入口（现有翻转信号/求解信号已闭环）：
  1. 算层内 9 块列表（复用现有 logic_apply_face 物理链，只取下限）；
  2. 对 9 块 switchFollowMotionDeviceTargetByGuid/ByEntity（跟随类型=完全跟随，
     相对坐标系，偏移=块当前相对中心球向量；或挂接点 GI_RootNode）；
  3. 中心球加单个旋转设备（时长=动画时长，角度=90° 轴向）；
  4. 设备停（或时长到）-> busy 解锁 -> 视 FAQ 语义决定是否断开跟随（官方大概率保留）。
- 错峰定时器下线清单（负载铁律违例项，同一轮消除）：
  - turn.ts：faceTurnTimes[0.01..0.05]+faceTurnTimesB[0.01..0.04]+middleTurnTimes[0.01..0.08]
    +wholeTurnTimes0..3（0.01）×4 -> 全删，改信号直达；
  - visual.ts：turnblock/turnblockB/turnblock0..3/orbit2/orbit2B/orbit20/orbit21
    定时器群 + motion_spin_block/motion_orbit_segment 折线数学 -> 全删，改"单设备+跟随"；
  - game.ts：dispatch 0.01s 定时器可保留低频化（0.7~1s）或改事件驱动（按接入信号）。
- logic/view 对接点：
  - logic（turn/logic_apply_face）：仍服务端权威写回位置变量（跟随期间实体坐标静止，
    FAQ 语义需日志确认——命中检测/GetEntityLocation 读到什么决定 blockOrient/格点
    同步策略）；
  - view（visual/motion_*）：动画链整体替换为跟随+单设备；view_prepare_visual_order
    重排（1e08 系）先保留观察。
- 核验链（每小步）：编译 0 错 -> 回归绿 -> .gia wire 断言（新动画链节点参数逐个核对）
  -> 注入（游戏/编辑器关闭窗口）-> .gil 回读 + dump_asv + 复合 refs 0 悬空
  -> 用户进 1914 实测 -> gia_log perf --compare vs 3029/2960。
