# ADR-0001: 位置职业用引擎职业系统实现（而非单位状态 buff 分化）

日期：2026-09-01 ｜ 状态：已接受（设计定稿）

## 背景

笼式足球需要四位置差异（FW/MF/DF/GK）：移速、技能集、专属规则（GK 禁区/扑救）。
两条实现路线：
- A. 引擎职业系统：每位置一个职业配置（属性+移动方式+职业技能集+职业节点图），
  服务端「更改玩家职业」运行时切换；
- B. 单一职业+单位状态 buff：全员同职业，用「移动速度调整率」等动态状态做数值差异，
  技能集靠技能装配状态切换。

## 决策

选 A。选位置 = 切职业，一次调用原子完成属性/技能集/（可选）节点图切换。

## 理由

1. 职业技能集由引擎自动替换（切职业即换技能），B 需要手工装配/卸载技能实例，状态多且易漏；
2. 职业可配置移动方式（禁战斗技能/冲刺键），保证输入语义唯一（冲刺全走自研技能）；
3. 职业节点图提供按位置的图挂载位（v2 扩展位）；
4. 已知坑可防御：切职业节点必须连**玩家实体**（FAQ 实证连角色实体无效）。

## 后果

- 技能配置×10（8 通用技能+职业专属）需建空技能资产并按职业模板装配，前期资产成本高于 B；
- 职业属性可调项受官方职业模板限制（如无"拦截半径"项）——领域数值中触球半径等仍由
  球物理图按职业 ID 查表实现，职业系统只承载它天然承载的部分（移速/移动方式/技能集）；
- 单位状态仍用于**运行中动态**效果（冲刺/带球惩罚/铲球硬直），与职业静态基线分工。
