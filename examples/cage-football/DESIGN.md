## 1. 目标体验与规则总览

**一句话**：最多 8 名玩家以四个位置职业在标准球场上踢 5 分钟笼式足球——围栏反弹永不出界，
位置分工 + 技能差异化对抗，进球多者胜。

**核心循环**：
```
LOBBY(选队+选位置职业) → KICKOFF(传送站位+2s) → PLAY(带球/抢断/传射/围栏反弹)
→ GOAL_PAUSE(2s 进球表现) → KICKOFF → … → END(结算 10s) → LOBBY 重赛
```

**规则集 v1**：5 分钟单节不换边；无越位/犯规/界外球/角球；进球后失球方开球；
GK 出禁区拉回；AI GK 兜底空缺槽位。

## 2. 领域边界场景（压力测试过的规则边界）

| # | 场景 | 规则裁决 |

## 4. 四位置职业系统（核心设计）

### 4.1 职业实现机制

- 每位置一个**引擎职业配置**：属性差异 + 职业技能集（切职业自动替换角色技能）。
- 输入图**不挂职业**（挂玩家模板一张通用图）：四职业技能实例不同，但都是
  "空技能+施放事件→统一 kick 信号"，输入图按技能实例 ID 查参数表分派——一张图服务全职业。
- 选位置流程：LOBBY 屏幕按钮（前锋/中场/后卫/守门员 ×红/蓝队）→ UI 事件→角色图→信号→
  规则图登记槽位 → 规则图回发"切职业"指令 → 该玩家输入图执行「更改玩家职业」
  （**连玩家实体**，FAQ 坑）。比赛中不可换位（v2 死球换人）。

### 4.2 职业数值表（v1 平衡基线，阶段 6 调参）

| 职业 | 移速修正(单位状态) | 触球/挡球半径 | 专属技能(冷却) | 被动 |
|------|------------------|--------------|----------------|------|
| FW 前锋 | +8% | 触球 1.1m / 挡球 0.55m | 强射(2s)、吊射(2s)、冲刺(8s) | 带球移速惩罚 −10%（他人 −15%） |
| MF 中场 | 基准 | 同上 | 长传(1.5s)、短传(1s)、冲刺(8s) | 传球弹道稳定（旋转衰减减半） |
| DF 后卫 | −3% | **触球 1.35m** / 挡球 0.55m | 铲球(3s)、大脚解围(2s)、冲刺(8s) | 被动抢断概率 65%（他人 50%） |
| GK 守门员 | −10% | 触球 1.0m / **挡球 0.8m** | 扑救(5s)、手抛开球(1s)、大脚开球(2s) | 禁区规则+扑接保护球权 |

全员共享：普攻键=普通踢球（0.5s 冷却）。移动方式：四职业全部**禁用原神战斗技能与冲刺键**
（职业移动方式配置），冲刺走我们的技能实现（统一冷却/速度），保证输入语义唯一。
跳跃：不禁（保留原神手感，头球 v2 评估）。

### 4.3 AI 守门员（Backup GK）

- 激活：KICKOFF 进入时该队 GK 槽无人 → createPrefab 生成守门员实体；真人选 GK → 销毁。
- 行为（守门员图，0.3s tick）：门线横移跟球（z 钳制门宽±0.5m，4m/s）；
  球朝门飞行且 1s 内越线 → 扑救冲刺 8m/s 至预判拦截点（线性外推，冷却 2s）；否则回中。
- 挡球并入球图统一圆柱判定（§6.4），AI/真人 GK 同参数。

## 5. 动作规格全表（输入→判定→物理→表现→边界）

### 5.1 踢球家族（Kick）

**通用链路**：技能施放 → 客户端技能节点图/服务端技能事件（阶段 2 实测定通道）→ 输入图
（查冷却、phase=PLAY、非 KICKOFF 锁）→ 信号 `kick(施放者GUID, 技能ID)` → 球图验
owner=施放者（场景 7）→ 读施放者角色旋转 → 水平前向单位向量 f=(fx,0,fz) → 设
`v = f·V·cos(θ) + (0, V·sin(θ), 0)`，`ω` 按表 → state=FREE_FLY → 播踢球音效+施放特效。

| 技能 | V 初速 | θ 仰角 | ω 旋转 | 备注 |
|------|--------|--------|--------|------|
| 普通踢球（全员普攻） | 16 | 12° | 上旋 1.5 | 基础射门/短距离处理 |
| 强射（FW） | 24 | 8° | 内旋 5.0 | 马格努斯弧线，贴地快 |
| 吊射（FW） | 13 | 45° | 0 | 越门将头顶 |
| 长传（MF） | 17 | 35° | 上旋 2.0 | 高弧线落点 |
| 短传（MF） | 12 | 3° | 上旋 1.0 | 贴地快出 |
| 大脚解围（DF）/ 大脚开球（GK） | 20 | 40° | 0 | 向前场解围 |
| 手抛开球（GK Drop） | 10 | 30° | 0 | 扑接后专用 |

- v1 无蓄力（固定分档）；踢球方向=施放瞬间角色水平朝向；v2 加长按蓄力与传球自动瞄准。
- 边界：非带球者踢球无效；KICKOFF/GOAL_PAUSE/END 输入锁；踢出瞬间球权释放（owner=∅）。

### 5.2 带球（Dribble）

- 获得：无主球 + 触球事件（§5.4）→ CARRIED，owner=该角色。
- 保持：弹簧场——锚点=带球者水平朝向前方 0.85m 贴地点；每 tick
  `a = k·(锚−pos) − c·v`（k=20，c=10）；锚点移动自然产生"贴脚滚动+急转变滞后"表现。
- 带球移速惩罚：owner 被施加单位状态移速 −15%（FW −10%），丢球即撤销。
- 丢失：距锚点 >1.5m，或球速 >1.8×带球者速度，或 owner 离场/掉线 → FREE。
- 表现：球实体贴地滚动音（低速循环音效，速度阈值门控）。

### 5.3 冲刺（Sprint，全员）

- 输入图内闭环（不经球图）：施放 → 自身单位状态移速 +60%（3s）→ 8s 冷却。
- 单位状态提速有上限（FAQ）：上限内取 min；与带球惩罚叠加计算。
- 表现：施放者脚下特效（职业节点图或输入图触发，本地特效）。

### 5.4 触球与抢断（Touch / Steal）

- 判定主体：球图 5Hz tick 遍历 8 槽位（方案 A，角色位置实时可读）；空槽跳过。
- 无主球：最近且 <触球半径（职业值）者获球权（同 tick 并列取槽位序小，场景 1）。
- 有主球（防守方进入带球者触球半径）：
  - 普通抢断：概率 50%（DF 65%）→ 球被捅走：v=抢断者朝向×6m/s 贴地，owner=∅（**不是抢断者直接拿球**——逼迫跟球二段操作，防守有收益但不无敌）；
  - 概率判定失败：无效果（同一次接触不重复判定，1s 每对玩家判一次，图变量记录上次判定 tick）。
- **铲球（DF 技能）**：施放→前方 2.5m、120° 扇形内有球（无论球权）→ 80% 球停脚下获球权；
  20% 失败→施放者单位状态移速 −70% 1.5s（硬直）；冷却 3s；KICKOFF 锁。
- **扑救（GK 技能）**：施放→朝向方向冲刺（单位状态 +300% 0.4s，钳一次位移）+ 挡球半径
  0.8→1.2m 持续 0.6s；冷却 5s。扑到球速 <8m/s 的球 → **扑接**：owner=GK+3s 保护期
  （抢断/铲球免疫），保护期内必须 Drop（手抛/大脚），超时球掉落门前。
- **挡球（Block，被动）**：球图每 tick 检查全部 8 槽位+2 守门员逻辑圆柱（水平距离<挡球半径
  且 y<2.2m）且球速>4m/s → 反射 `v'=v−(1+e)(v·n)n`，n=球心指向圆柱轴的水平法向，e=0.55，
  出射角随机偏转 ±15°（扑救脱手感）。

### 5.5 得分（Goal / Score）

- 判定（球图边界处理段，顺序固定）：门柱反弹 → 横梁反弹 → **进球区判定**（线段判定：
  球心轨迹穿 `|x|=门线+r/2` 且 `|z|≤门半宽−r` 且 `y≤横梁−r`）→ 围栏反弹。
- 进球动作序列（规则图）：+1 分 → GOAL_PAUSE 2s：球 vel×0.1（挂网感）+门内庆祝特效+
  全场音效+计分板文本跳动+屏幕播报"红队进球！{lastKicker 名}"（kick 信号时登记
  lastKicker，进球读出）→ KICKOFF。
- END：比分大屏 10s（胜方配色特效）→ LOBBY 清槽重注册（比分清零）。

## 6. 足球物理实现（球物理图，全节点图模拟）

### 6.1 状态机与驱动

```
FREE_FLY ⇄ FREE_ROLL → CARRIED ⇄ FREE_* ；任意 → GOAL（复位）
```
- 驱动：`匀速直线运动器(0.2s)` 停止事件（按 motionDeviceName 过滤）→ 积分 → 边界/挡球
  → 写回图变量 → 重新激活。图变量 `pos/prevPos/vel/spin/state/owner/immuneUntil` 唯一事实源。
- CARRIED 不跑飞行积分，只跑弹簧场（同 5Hz 复用 tick 链）。

### 6.2 公式与参数表（v1 定稿值）

| 参数 | 值 | 说明 |
|------|----|----|
| dt | 0.2s | 5Hz tick |
| 重力 g | (0,−9.8,0) | 仅 FREE_FLY |
| 空气阻力 | a−=0.03·\|v\|·v | 仅 FREE_FLY |
| 马格努斯 | a+=0.008·(ω×v) | 内旋/上旋弯向 |
| 旋转衰减 | ω×=exp(−0.08·dt)（MF 传球 −0.04） | |
| 地面反弹 | e=0.65，水平 ×0.85 | vy<0 且 y≤r 触发 |
| 围栏反弹 | e=0.6，切向 ×0.85 | 线段判定 |
| 门柱/横梁 | e=0.7 | 圆柱反射 |
| 滚动摩擦 | v×=0.985/tick | 仅 FREE_ROLL |
| 停球阈值 | \|v\|<0.3 → 保持 FREE_ROLL（无静止态，笼内总有可抢性） | |
| 贴地高度 | y=r=0.25（按导入球模型实测校准） | |
| 速度上限 | clamp 30m/s | 数值稳定 |
| 触球后保护 | 获球权后 0.3s 内他人不可抢 | 防同 tick 连环判定 |

### 6.3 数值稳定性（写图必守）

- 所有边界碰撞用**线段判定**（prevPos→pos），防 6m/步穿透（场景 4）；
- 每 tick 位置 clamp 到场地 box（围栏内 0.05m 裕量）；
- 卡角计数器（场景 3）；重复求值三防线（写后读回/快照物化，PKC clm_6583 规则）；
- 反射统一复合：`normalize+dot+zoom+addition` 四向量节点，禁手写分量反射。

### 6.4 挡球/守门员圆柱

- 8 球员（0.55m）+2 守门员（0.8m，扑救 1.2m）逻辑圆柱，每 tick 与球线段做距离判定；
- 与触球判定（半径大、获球权）互不干扰：挡球先判（球速>4m/s 才反弹，慢球走触球获权）。

## 7. 客户端节点图与表现层架构

**分层原则**：
1. **一致性关键逻辑 → 服务端图**：球物理/规则/触球判定/进球——所有玩家必须看到同一结果。
2. **全员可见表现 → 服务端节点触发实体组件**：特效（特效播放组件）/音效（音效播放器组件）
   挂在球/球门/守门员实体上，服务端图执行播放节点，全员同步可见可听。
3. **施放者本地反馈 → 客户端技能节点图**（挂技能动画事件轨道，本地运行）：踢腿动作时间点
   触发本地音效/镜头微震/冷却提示；v1 最小化为**技能施放信号回传通道**（若服务端技能事件
   直通可用则客户端图退化为纯表现）。
4. **技能→服务端链路**（阶段 2 实验二选一，client-nodegraph-development 决策树）：
   a) 技能配置→角色装配→施放→客户端技能节点图→信号回传服务端；
   b) 服务端技能施放事件直收（若事件 payload 够用优先 b，少一层）。

**表现资产清单**：

| 事件 | 表现 | 载体 |
|------|------|------|

## 8. 比赛规则状态机（规则图，挂关卡实体）

```
LOBBY ──(两队各≥1人且房主按开赛)→ KICKOFF ──(2s)→ PLAY
PLAY ──(goal 信号)→ GOAL_PAUSE(2s) → KICKOFF
PLAY ──(clockSec=0)→ END(10s) → LOBBY
```
- phase/scoreR/scoreB/clockSec/slots[8]/lastKicker 存**关卡实体变量**（重连安全）。
- 计时：1s 定时器（PLAY 才累计）。
- 槽位表：`slots[i]={玩家GUID, 队伍, 职业ID, 心跳tick}`；注册=玩家实体创建事件→输入图→
  `join` 信号；LOBBY 选位/换队=UI 按钮→`pick(位置,队)` 信号→规则图改槽+回发切职业。
- KICKOFF 复位：球瞬移中点+槽位传送站位表（x=±(3,8,14) 三列×z=(0,±5,±9) 按
  职业：GK 门线/FW 最前）；传送用短距快速移动（同图内，规避 loading 丢实体坑）。
- GK 禁区：1s tick 检查 GK 槽位位置，出禁区→文本警告 1s→传送回门线。
- 输入锁：KICKOFF/GOAL_PAUSE/END 期输入图屏蔽技能（读 phase）。

## 13. 风险与备选

| 风险 | 对策 |
|------|------|
| 技能→服务端链路细节（客户端图中转 vs 服务端直收） | 阶段 2 双通道最小实验，优先服务端直收 |
| 8 槽遍历编译膨胀 | 切方案 B（玩家图自查距离+球 pos 写关卡变量）；或槽位数静态编译 |
| 单位状态提速上限压低冲刺效果 | 实测上限值；不足则冲刺改"职业固有移速差异放大" |
| 空技能无动画导致踢球无打击感 | 技能动画配通用攻击动作（踢腿近似）+音效补 |
| 传送复位丢实体（loading 坑） | 同图短距传送+实体永不重建（球/守门员复用） |
| lastKicker 与进球判定跨 tick 竞态 | kick 信号在进球判定前必然先到（事件序列保证），写后读回 |
| 触球判定与挡球同 tick 冲突 | 固定顺序：挡球（快球）先于触球（慢球），速度阈值分界 |
| 职业切换失败（FAQ：连了角色实体） | 切职业节点必须连玩家实体，输入图内做归属转换 |
