## 1. 目标体验与玩法概述

**一句话**：最多 8 名玩家用自己的原神角色在标准球场上踢笼式足球——球撞围栏反弹永不出界，
进球得分，限时赛制，AI 守门员守双边球门。

**核心循环**：
```
大厅(集人/分队) → 开球站位(2s 倒计时) → 对战(带球/抢断/传射/围栏反弹)
→ 进球(庆祝 2s) → 开球站位 → … → 计时结束 → 结算展示 → 重赛
```

**规则集（v1，刻意精简）**：
- 赛制：5 分钟限时（可配置），进球多者胜；平局保持平局（v1 不做点球大战）。
- 无越位、无犯规判罚、无界外球/角球/球门球（围栏全封闭）。
- 进球后双方回半场站位开球，被进球方开球。
- 球速过低且无人触球超时（如 15s）不强制判死球（围栏内球总能被够到）。
- v2 候选：犯规推人、点球大战、传球自动瞄准、体力条。

## 4. 球物理设计（复用已验证通道，全部节点图模拟）

球 = 1 个动态实体（足球模型 + basicMotion 组件），挂**球物理图**（唯一事实源）。

**状态机**：`FREE_FLY（空中）→ FREE_ROLL（贴地滚）→ CARRIED（被带）→ FREE_*  → GOAL（进门瞬间，转复位）`

- **驱动**：5Hz 链式运动器插值——`匀速直线运动器(0.2s 固定时长)` 停止事件（按 motionDeviceName
  过滤，防双触发）→ 积分 → 碰撞写回图变量 → 重新激活。图变量 `pos/vel/spin/state/owner` 唯一事实源。
- **空中三力**：重力 + 空气阻力(−Kd·|v|·v) + 马格努斯(Km·(ω×v))，ω 指数衰减。
- **贴地滚滑**：独立积分复合——仅水平摩擦，vy=0，y 锁定贴地高度，**不积分重力**（防微弹）。
- **碰撞反射**（统一边界处理段，每 tick 顺序检查）：
  - 围栏四面墙：`|x|≥X_lim`（且**不在进球开口区**）→ 法向反射 e≈0.6 + 切向摩擦 ×0.85；
  - 进球开口区：`|x|≥门线 && |z|≤门半宽 && y≤横梁高` → 不反弹，判进球（GOAL）；
  - 门柱（垂直圆柱）：水平法向 `normalize(dx,0,dz)`；横梁（水平圆柱）：`normalize(dx,dy,0)`；
  - 两对称门用 `|x|` 统一处理，省一半节点。
- **对称性**：球场沿 x 轴对称，所有边界判定用绝对值统一。
- **复位**：GOAL/开局 → pos=中点(或罚球点)，vel/spin 清零，state=FREE_ROLL。

球图读不到的（跨图）不读；需要的输入（踢球指令/带球者变更）全部由信号传入（见 §8）。

## 5. 球员-球交互

### 5.1 触球/抢断判定（推荐方案 A，备选 B，阶段 2 最小实验定夺）

**方案 A（推荐）：球图集中判定。** 球图每 tick（5Hz）遍历 8 个角色槽位：
- 读 8 个角色位置（角色是玩家直接操控，位置读取可靠——无运动器反读坑）；
- 距离 < 触球半径（约 1.1m）→ 触球事件（CARRIED 或抢断）。
- 节点成本：8 ×（查实体+读位置+距离+比较）≈ 70~90 节点，可控；
- 空槽位（不足 8 人）防御：注册表里无效槽位跳过（槽位数组存关卡变量）。
- 带球规则：无主球→先到者得；有主球→对方进入触球半径且球在可抢侧→球权转换
  （v1 简化：对方触半径即 50% 概率捅走——球速设为抢断者朝向 6m/s 贴地）。

**方案 B（备选）：球员图分布判定。** 挂玩家实体的图每玩家一份，0.2s 定时器自查"我的角色
vs 球位置"距离→信号发球图。要求球图把 pos 冗余写入关卡实体变量（5Hz×3 变量）。
若方案 A 的 8 槽遍历编译膨胀超预期再切换。

### 5.2 带球表现（CARRIED 状态）

- 控球弹簧场：球被吸向带球者**面朝方向前方 0.85m** 贴地点——每 tick 读带球者位置+旋转算锚点，
  `a = k·(锚点−pos) − c·v`（k≈20，c≈10）；
- 丢球条件：距锚点 >1.5m（被围栏/门柱卡位）或球速 > 角色速度×1.8 → FREE。

### 5.3 踢球（射门/传球）与冲刺（输入见 §6）

技能施放事件 → 角色挂载的**输入图**判定（是否带球者）→ 信号发球图：
- **射门**（重踢）：v = 朝向 × 22m/s + 仰角分量（y≈6~8m/s），ω=内旋 4~6 rad/s（马格努斯弧线）；
- **传球**（轻踢）：v = 朝向 × 14m/s 贴地（y≈0.5），ω=上旋 2 rad/s；v2 加"前向锥内最近队友"自动瞄准；
- 力度/方向全部来自施放瞬间的角色旋转（前向向量），辅以按键种类区分弹道；
- 无球时按射门/传球=无效（或做 v2 的"铲球/挡球"）。
- **冲刺**：不经过球——输入图直接给自己上单位状态"移动速度调整率 +60%" 3s，冷却 8s
  （冷却用输入图内计时，不进球图）。

  禁用→待用户定（不禁=保留原神特色，技能乱飞可能干扰；禁=锁技能列表）。

## 7. 比赛规则状态机（规则图，挂关卡实体）

```
LOBBY ──(人数≥2 或房主开赛)→ KICKOFF ──(2s 倒计时)→ PLAY
PLAY ──(进球信号)→ GOAL_PAUSE(2s) → KICKOFF
PLAY ──(剩余时间=0)→ END(10s 结算展示) → LOBBY（或直接 KICKOFF 重赛）
```

- **状态存关卡实体变量**（`phase/redScore/blueScore/clockSec`）——断线重连安全（玩家 GUID 会变，
  比分不能绑玩家实体）。
- **计时**：1s 低频定时器累计（PLAY 态才计数），符合负载铁律（事件驱动→低频定时器优先）。
- **进球判定在球图**（边界处理段天然知道），进球→信号→规则图加分+换 phase。
- **KICKOFF 复位**：球瞬移中点；8 槽位角色按队伍传送回半场站位（传送节点；固定站位表
  x=±5/±12，z=0/±6）；倒计时期间输入锁（输入图读 phase 屏蔽技能）。
- **队伍分配**：玩家进图注册（进图事件→输入图发"加入"信号→规则图按到达顺序/平衡分配，
  槽位表 `slot[i]={玩家GUID, 队伍}` 存关卡变量）；红蓝上限各 4；换队按钮可调。
- **重连**：重连玩家重新发"加入"→ 规则图按名字/旧槽回收槽位（v1 简化：重新排队分配，
  比分不受影响）。

## 8. 多人架构与跨图通信

**图挂载原则（利用"玩家实体图按玩家分别执行"的天然隔离）**：

| 图 | 挂载 | 份数 | 职责 |
|----|------|------|------|
| 球物理图 | 球实体 | 1 | 状态机+积分+碰撞+触球判定+进球判定 |
| 输入图 | 玩家实体（模板挂载） | 每玩家 1 份自动 | 技能事件→信号；冲刺自闭环；加入/重连注册 |
| 规则图 | 关卡实体 | 1 | 比赛状态机/计分/计时/分队/复位/传送 |
| 守门员图 | 守门员实体 ×2 | 2（同图两实体） | AI 行为 |
| UI 图 | 关卡实体（可并入规则图） | 1 | 计分板变量刷新（或纯变量+文本框，零图） |

**跨图通信**：全部走信号（send_signal）+关卡变量。信号清单（注册三件套 def）：
`kick(施放者GUID, 类型)` / `touch_claim(角色GUID)`（备选方案 B 用）/ `goal(侧)` / `reset_done()`。
信号按需发（事件驱动），无轮询广播——8 人同场无风暴。

**去重**：全局一次性逻辑（开局建球、初始化变量）只在规则图（挂关卡实体，单份）做；
玩家图永不写全局状态，只发信号。

## 9. AI 守门员（自建人形 + 基础运动器 + 服务端图驱动）

- **移动**：基础运动器匀速直线（0.2~0.3s 步进，同球物理插值模式）；仅沿门线横移（z 轴，
  x 锁定门线前 0.5m），不做全向移动——节点省、行为可信。
- **决策（0.3s 低频 tick，守门员图内状态机）**：
  - 球在己方半场：目标 z = 球 z 钳制到 [−门半宽−0.5, +门半宽+0.5]，横移速度 4m/s；
  - 球朝门飞行且预测 1s 内越门线：扑救——朝预判拦截点冲刺 8m/s（一次性，1s 冷却）；
  - 其他：回门线中点待机。
- **挡球判定**：不做物理——球图每 tick 顺带检查两守门员圆柱（水平距离 <0.55m 且 y<2.2m）
  → 球速反射（e≈0.55，向外侧偏转随机 ±15°，模拟扑救脱手）。
- 守门员不做持球/手抛（v1）；进球判定在守门员身后的门线，挡球在前。

## 11. 负载设计账本（写图前先算账）

- 5Hz 球物理 tick：单 tick 帧 <400（状态分派后每状态独立小复合，单 tick 只走一条）；
- 守门员 0.3s tick、规则 1s tick、输入图事件驱动（无周期）——全部有停止条件（phase 门控）；
- 无 0.06s 级高频轮询；无多层有限循环叠链；跨图信号按需触发。
- 验收：游戏日志 perf 面板单秒负载平稳，无 >3000 帧单记录。
