## 规则与机制
- **编译链是三层产物、可追溯**：TS → `.gs.ts`（节点图节点裸调用）→ JSON 中间表示（变量/节点/连接关系）→ GIA；编译报错会指向某个产物。
  - 出处：`[00:10:52]` "编译会生成一些中间产物首先是点JS点ts文件编译器会将你的代码转换成F形式的节点图节点函数裸调用"
  - 证据等级：硬规则
  - 维度：D7 工程化工具链
- **同步定时器的同名语义**：在定时器到期前同名事件再次发生，第二个事件不会再触发定时器效果；工具链的做法是按情况自动生成"定时器名称池"轮询创建，从而贴近真实 JS 环境 setTimeout 的效果。
  - 出处：`[00:06:58]` "如果你用一个简单的定时器而在定时器到期前事件又发生了由于同名此时第二个触发的事件不会再触发定时器的效果"
  - 证据等级：硬规则
  - 维度：D3 逻辑编写
- **定时器池大小可标注指定**：用 `@gstsTimerPool=4`（原话"at js t s timer pool等于四"）这类标注指定池大小；属更高阶用法、一般用不到，多数情况只需在配置文件里全局指定即可。
  - 出处：`[00:06:58]` "你还可以通过标注at js t s timer pool等于四"

- **定时器聚合分发优化**：编译器会对简单的定时器事件名检测做 switch 聚合分发，以改善性能。
  - 出处：`[00:07:47]` "编译器还会尝试对一些简单的定时器事件名称检测做switch聚合分发优化从而改善性能"

- **（邪修）默认元件缺基础运动器怎么办**：要么自己新建一个带基础运动器的元件替换掉，要么直接把要用的元件 id 告诉 AI，让 AI 在代码里引用你的元件。
  - 出处：`[00:00:00]` "由于默认原件没有基础运动器所以这里我替换成了我新建的原件你也可以直接告诉AI要用的原件id"
