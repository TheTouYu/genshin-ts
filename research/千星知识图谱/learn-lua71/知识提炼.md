- **定位**：界面控件组库中的**服务器控件模板**；生成仍走节点图，内部逻辑全由**客户端 Lua 脚本**执行 [BV1qYeF6nEiq 00:16-00:31]

- 控件属性栏新增**「脚本」选项**；脚本挂载到容器**容器节点**上（如 main.lua）[BV1qYeF6nEiq 00:41 / BV1BYeF6JEPg 04:02-04:13]
- **Lua 能做**：拖拽、框选、双击、长按按钮、移动界面控件、大幅提升 UI 动效体验 [BV1Zten6VEeD 01:26]；2D 肉鸽、2D 平台跳跃「都能做」[BV1BYeF6JEPg 05:49-05:59]

## 三、通用脚本能力（官方示范关 [BV1dqeF62EbP 02:38-04:14] + 动画教程 [BV1DieU6rEiQ]）

- **生命周期**：onStart 启动回调 ⚠、控件生成/销毁事件 ⚠；script.object = 脚本挂载对象 ⚠
- **脚本变量**：脚本变量管理区域（类似节点图变量）；可公开变量供控件脚本区「编辑变量」[BV1qYeF6nEiq 00:50-02:13]
- **require 复用**：脚本之间 require 引用（≈复合节点功能），入参为客户端脚本中显示的文件路径 [BV1qYeF6nEiq 03:27-03:48]
- **动态创建/销毁控件**；调整位置大小旋转缩放；父子层级定整体关系，同级顺序定前后显示 [BV1dqeF62EbP 02:38-02:55]
- **补间动画**：提供控件+目标状态+时长 → 自动过渡；**目标字段必须在 API 文档标记为 tweenable** [BV1DieU6rEiQ 01:18]；**控制实例非模板** [BV1DieU6rEiQ 00:49]
  - Tween 函数接收：控件对象、目标表（Lua 表 字段=目标值）、持续时间 → 返回动画对象 ⚠（疑 Game:Tween）
  - setRelative(false)=绝对目标值 / true=相对增量 ⚠；easing 选曲线（linear 匀速）；play 播放；目标值是最终位置非移动距离
  - 可补间字段：anchorPositionX/Y（位置）、localScaleX/Y（缩放）、sizeDeltaX/Y（布局尺寸，与缩放分开理解）、localRotationZ（平面旋转）、imageColor RGBA 0-255（透明度 0→255 淡入）、fillAmount（填充进度 0→1，配 setFillMode 遮罩/setViewHorizontal 方向）⚠
  - setPivot 中心点（旋转基准）；锚点 min/max 各 XY 分量（相对父区域布局约束）；softEdgeWidthX/Y+softRange 边缘羽化 ⚠
  - **31 种缓动**：linear/easeIn 缓入/easeOut 缓出/easeInOut；**回弹和弹性可能越过目标位置，要预留空间**
- **动画序列**：多动作编排；依次/并行；等待+完成回调；seq:append 顺序加入，总时长=相加 ⚠ [BV1DieU6rEiQ 04:39]
- **逐帧逻辑**：持续更新位置/计时器/玩法状态；初始化/暂停/继续/销毁时管理对应控件和任务；计时和状态保存在客户端 [BV1dqeF62EbP 03:20-03:29]
- **输入**：监听键鼠+手柄；设置聚焦目标和导航方向（手柄导航）[BV1dqeF62EbP 03:29-03:41]
- **音效**：播放/停止指定实例/查询播放状态 [BV1dqeF62EbP 03:49]
- **i18n**：读取当前语言和文本映射，界面适配 [BV1dqeF62EbP 03:49]

## 四、客户端 ↔ 服务器桥接（架构关键）

- **客户端无存档能力**：存档/结算是关卡必须，但客户端控件/脚本**无法实现** [BV1uBaP61Ekj 05:09-05:34]
- 正解 = **信号双向桥**：
  - 脚本→服务器：「发送客户端脚本信号」→ 服务器节点图监听 → 完成结算/存档（自定义变量/局外变量存档）[BV1uBaP61Ekj 05:38-06:44]
  - 服务器→脚本：新节点「发送脚本信号」（功能与服务器发送信号一致）[BV1Zten6VEeD 04:17-04:24]；例：时间到→服务器发信号→客户端收到→显示结算按钮 [BV1uBaP61Ekj 05:44-06:07]
- **AI 默认产出局内存档**——存档需求必须显式告诉 AI + 连好节点图 [BV1uBaP61Ekj 06:52-07:11]
- 官方示范关全部演示逻辑在客户端完成，不发服务器信号不改服务器变量（纯客户端架构可行性证明）[BV1dqeF62EbP 04:05-04:14]
- 与服务器信号/自定义变量配合可实现启动界面显示和数据刷新 [BV1dqeF62EbP 03:49]
