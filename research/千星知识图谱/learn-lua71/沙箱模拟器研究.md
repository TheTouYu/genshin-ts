## 0. 决定性事实（30 秒版）

1. **它是 DSH 插件**：`dsh-plugin-beyond-simulator` v2.0.6，pnpm workspace 十个子包，可直接 `dsh plugin --profile web add` 装进我们正在用的 Harness——模拟器视图 + qxqy_* 工具 + 七步 Agent 预设即刻可用。
2. **Lua VM = fengari 0.1.5**（纯 JS 的 Lua 5.3 实现，32-bit integer 已知限制），自写宿主桥（`client/lua-runtime/src/`，仅 8 个文件：runtime/lua-bridge/scene/tween/color/enums/ease）。
3. **它手里有官方《Lua客户端UI脚本API》文档**（observed-contract.md 引用「官方 API 文档表面」+ 本地快照），且建了真机探针回路（三轮 `probes/engine-fidelity` + 用户真机回传）——**这是我们「API 名听写待核对」缺口的最佳交叉验证源**。
4. **它逆向了 7.1 客户端 UI 控件的 GIA protobuf wire**（`studio/gia/codec.js`）——genshin-ts injector 尚未覆盖的新资产面。
5. 商业模式：npm 三包（web/mcp/dsh-plugin）+ GitHub Actions Trusted Publisher 自动发布；作者即 B站 UP「神奇嘟嘟可」。

## 2. 真机契约表（observed-contract.md 全量提炼）

> 来源标注：官方 API 文档 + 三轮真机探针（7.0.50）+ 用户真机回传。这是**对我们知识提炼.md 的逐条校正**。

### 2.1 生命周期与挂载

- 顺序：`OnInit → OnEnable → OnStart`；EnableUpdate 前无 OnUpdate；退出 `OnDisable → OnDestroy`
- `SetActive(false)` 立刻 OnDisable；再 `SetActive(true)` 只跑 OnEnable **不重跑 OnStart**（2026-08-29 真机）
- `InstantiateClientUIControl` **仅在 OnStart（及 running）成功**；OnInit/OnDestroy 里返回 nil
- 实例的 active/visible 继承模板定义，运行时不强制打开
- 仅客户端控件/模板可挂脚本；模板脚本随实例化运行；**没有「服务端 Lua」**（三类资产：服务端 UI、客户端模板、Lua 脚本）

### 2.2 API 语义校正（对照我们的 ASR 听写）

| 我们的知识提炼.md 写法 | 模拟器契约（更权威） | 判定 |
|---|---|---|
| onStart/onDestroy 等（听写） | **OnInit/OnEnable/OnStart/OnUpdate/OnDisable/OnDestroy**（On 首字母大写） | ✅证实+大小写校正 |
| game 点号调用（听写） | `game` 全局表**点号调用 + 固定参数个数核对**；真机回传 `game:GetClientUIRoots()` 报 `bad argument count ... (0 expected, got 1)` | ✅证实（有真机日志） |
| getComponentByPath（听写待核对） | **FindChild 支持 `A/B` 路径；GetChild 仅一层** | 🔧校正 |
| ——（未听到） | 控件标识字段：`Id`（首字母大写）/ `prefabIndex`；`scriptMappingId`（GetScript 参数同名）；grid 的 `itemPrefabIndex`；reference 的 `referencedPrefabIndex` | ➕新增 |
| Tween（听写 game.twin） | Tween **默认绝对**；`SetRelative(true)` 才增量；Linear 按时间线性（对照过真机） | ➕新增语义 |
| —— | `fontSize`/`minimumFontSize` 必须 integer：真机日志 `38 * .62 = 23.56` 被拒 `integer expected, got number` | ➕新增（踩坑点） |
| —— | `script.path` **保留目录**：真机返回 `default_import_file/levelScript` 而非 `levelScript` | ➕新增 |
| PauseLevelTime（听写） | 只停 `OnLevelUpdate`，**不停 OnUpdate** | ✅证实+细化 |

### 2.3 沙箱裁剪清单（真机 7.0.50）

- `_VERSION` = **nil**；无 `io`/`package`/`loadfile`/`coroutine`/`string.dump`/`load`/`dofile`/`collectgarbage`
- 保留：`utf8`、`os.time/date/clock/difftime`、`debug.traceback`、`math.modf/ult/isnan/isinf`
- 文档异常行提到 `math.isnaf` 无处记载 → **反编造政策：不提供**（读 nil）
- `require`：映射路径 `子目录/文件名`（无 .lua 后缀）；独立 `_ENV`；缓存；不跑生命周期；失败报 `failed to load script '…'`
- 每个挂载脚本一台 Lua VM；模块导出值放主线程 registry（不可经 toJs/pushValue 往返——会损坏 metatable/upvalue/循环表）
- `typeof` 返回：`Script`、控件类名、`EnumItem`、`CursorEventData`；普通 table 返回 `table`
- Color = 打包整数 **AARRGGBB**；`Color()` / `FromRGB` / `ToRGBA`
- Enum 是 userdata；`==` 比身份；有 Name/FullName/EnumType
- 控件 userdata 按类型封死：缺字段读 nil、写报 `cannot set <field>, no such field`；光标监听只挂预设按钮/光标检测区
- `imageType`：文档标读写，但 Instantiate 后赋值真机被拒——模拟器保守跟拒绝路径

### 2.4 层序与画布

- 显式层级数值**大的在上**；Lua sibling 大索引置顶，First 置底、Last 置顶（scene.js 边界反向映射）
- 动态实例化新根**默认置顶**（2026-09-28 规则，`provided_unverified/device`——用户要求采用的兼容性规则，非官方文档）
- 图片不把指针传给子级光标区；按键监听 `return true` 中断后续
- 画布五档（与 GetUICanvasSize 同源）：PC KEYBOARD 1600×900、2100×900；手机 TOUCHSCREEN 1280×720、1560×720、1280×960
- **原点左下、Y 向上**、锚点相对父矩形（不能直接搬 HTML/CSS 坐标）
- 布局只保存 GIA 四平台 `transformByPlatform`；存档 version 4、`layoutSchemaVersion: 2`

## 3. GIA wire 逆向（studio/gia/codec.js）——对 genshin-ts injector 的直接价值

内嵌 proto3 schema（Root.graph 建为 repeated——官方模板列表资产合法多次发 field 1）：

```
GraphUnit: id{class,type,id} + relatedIds + name + which + ui=19(UiControlGroup) + script=35(ScriptMappingWrapper)
ScriptMapping: id + name + file_path + source        ← 脚本源码直接进 GIA！
UiControlGroup.ContentWrapper: guid=501 + info=502 + children=503 + parent=504 + data=505
Details slots: transform(13)/field14/rootChildRef(73)/genericSlot(74)/textConfig(75)/cursorConfig(76)
  /templateRefSlot(77)/footerSlot(78)/containerNodeSlot(79)/gridView(80)/buttonPreset(81)
  /keyHint(83)/imageSlot(84)/image(85)/effectSlot(86)/fullscreenEffect(87)
```

- **脚本映射进 GIA**（ScriptMapping.source 直接存 Lua 源码）——7.1 后「导入导出带脚本的 UI」是官方链路
- GUID：编辑器控件/模板索引 `1–2147483647`；探针模板 `1073742100`；真实编辑器导入可能重映射索引（以导入后检视器为准）
- 导出边界：旋转线号未验证不写猜测字段；部分填充形状/方向、自定义羽化值、非100%进度只留在 Authoring JSON
- 「资产包 GIA 整合包」= 服务端 `UIControlGroup` 与客户端 `UIControlTemplate` 并排写入同一 GIA 的 Root.graph

## 4. MCP/DSH 工具面设计（AI 试玩的工程范式）

工具族：`qxqy_project_open/save`、`qxqy_studio_get/patch/load`、`qxqy_studio_play`（start/get/pointer/device/view/stop）、`qxqy_studio_ui_screenshot` / `qxqy_studio_play_screenshot`、`qxqy_preview_open/status`。

值得抄的设计：
- **expectedRevision 乐观并发**：每次写操作带 revision，冲突报 `revision conflict: expected N, current M` → 重新 get 重算，不盲目重试
- **两种截图分工**：ui_screenshot（编辑器静态布局）vs play_screenshot（Runtime 实际画面/动画帧）——Host 进程内出 PNG，不需用户切页签
- **runCase 回放断言**：操作录成时间线，修改后回归；快照带 canvasId/platform/device 可直接断言
- **多设备=换真机**：切设备重建运行时（新生命周期、时间归零）；多人 1–8 各一份客户端，`PlayerSelf` 相对当前视角
- **handle 句柄模型**：工程级操作必须带 handle；保存是显式操作，patch 不自动落盘

## 5. 七步工作流 Skill（agent/wonderland-lua-builder）——skill 设计参考

1.策划案 → 2.TDD 测试用例 → 3.HTML 效果展示 → 4.千星美术素材 → 5.Lua 编码 → 6.测试 → 7.真机验证修复。

值得抄的设计：
- **按需读取**：每步只读对应 references/NN-*.md，不预加载七份全文
- **TDD 在 HTML 之前**；「有效 Red 要等步骤 5 可运行骨架缺少目标生产行为；路径/JSON/工具故障不算 Red」
- **证据分级三档 `runtime=html|simulator|device`**——与我们的三栏门禁同构；「模拟器绿灯≠真机通过」
- **PREFLIGHT 不计入七步**：启动前核验知识库来源与实际可用性，「不从普通 Lua/UI 或 3D 节点经验猜接口」
- 产出物约定：`docs/production-plan.md`（当前步骤/退出证据/阻塞项）+ `records/playtest.md`（实际结果与来源）
- 提问纪律：「只在玩法语义、HTML 体验、真正不同的美术方向与真机结果需要用户判断时提问」
