# 沿曲线路径连续装饰物铺放

等 F 划分算法、块长/截面比、块数模式与端面缝隙处理（等角螺线 V4-V11 真实样本）

### 等 F 划分：角度间隔 = 块长/局部半径

沿变径曲线（对数螺线等）铺放装饰物用等 F 划分：F(θ)=∫₀^θ (r(s)/d(s))·√(1+K²+(z'(s)/r(s))²)ds，θᵢ=F⁻¹(i·F_max/N)，即角度间隔 = 块长/局部半径（内圈稀疏外圈密集）；目标块长 L=λ·d(θ)，λ≈1.2（±6% 内视觉均匀）。按角度/参数均匀分布是失败模式（V1-V3 实测：内圈一囤四五十块、外圈最后半圈只有两三块）。

#### 适用边界

结论来自等角螺线 V4-V7 生成器与用户游戏核验；其它曲线类型/元件需单独验证。数值积分用 40000 步梯形法 + 二分反函数保证终点精确。

### 块数两种模式与参数耦合

块数两种模式：λ 固定模式 N=round(overlap_mult·F_max/λ)，overlap_mult=1.25（块长 = 弦长×1.25，相邻块轴向重叠≈20% 无断开）；N 固定模式 λ=overlap_mult·F_max/N 为推导值。参数耦合：改 D_MIN/D_MAX（截面尺寸）会改变 F_max → λ 固定下 N 自动变、N 固定下 λ 自动变，自检断言必须从新参数表推导。

#### 适用边界

V7 实测 N=198 时 λ≈0.53（块比管径短、排列更密，视觉仍均匀）；自检 λ 断言用推导值 ±6%。

### 块间端面缝隙处理：V9 恒定放大被否定、V11 楔子填充（真实样本确认）

变径曲线下相邻块端面因 Δβ（切线夹角）存在楔形缝隙。V9 恒定放大（OVERLAP_FIXED=0.002，内外圈同一放大率）被用户否定（内圈块小增长快放大缝隙、外圈缝显小）。V11 楔子填充（用户核验通过）：端面缩回 p=(d̄/2)·tan(Δβ/2)（d̄=相邻块平均管径），块长=弦长-两端缩回量；三棱柱楔子 10009004 顶点=两块缩回端面交点 E（内侧）、底边=端面外侧端点、pivot=三角形质心，scale 按底边宽/0.866、尖长/0.75 等边换算；自检 A2 块间零重叠（0.001mm）/A3 顶角=Δβ（0.1°）/A4 腰长覆盖端面/A5 贴合。

#### 适用边界

V11 结论为游戏核验通过；V11.1 动态放大（内小外大线性 s_i=S_MIN+(S_MAX-S_MIN)·(TM_i/THETA_MAX)）与少转一圈（6π→4π）尚未定稿（用户反馈三角形突出、内圈凸起），未闭合前不作为正式经验。

### 颜色按块索引渐变而非角度/弧长

逐块颜色按块索引 t=i/(N-1) 逐通道 lerp（如 lerp(RED, GREEN, t)）；不要按角度/弧长插值（外圈块数少时最后几块颜色几乎不变，V3 实测问题）；渐变终点颜色必须与末端指示件（箭头）颜色一致。

#### 适用边界

V4 实测 120 块 R 通道恒步进 3；自检断言相邻块步进一致、终点=箭头绿 #4CAF50。
