# 节点图值语义与列表运行时规则（真实日志实证）

图变量/列表值的引擎运行时语义：重复求值、全 0 短物化、初始化上限、长列表分块——全部来自 Beyond_Debug_Log 帧铁证与真实 GIL 回读。

### 图变量重复求值家族：data 连接非值快照，消费点重新求值（一周 8 次实证 + 三道防线）

引擎 data 连接不是值快照：同一表达式/复合输出被 ≥2 处消费时在每个消费点重新求值；两次消费之间若写回其输入图变量，第二次求值得到新值。一周内同族 8 次：进度计数器跳步（2887 丢尾步、2899 negPhase 少 90°）、solveBuf 残留（2931）、跨 tick 写序竞态（2954 solveLen）、足球运动器速度翻倍（08-27 kickApply npos 二次求值）、黑块回归（2956 复合数据引脚+分支赋值变体）。三道防线：① 写后读回（set 后重新 get 再判断，禁止复用旧表达式）；② 复合输出物化快照（先 set 到 tmp 图变量，消费点只读快照）；③ 跨 tick 共享推进状态用显式 pos 入参、让位入口集中清零。仓库 ESLint 规则 gsts/server-repeated-evaluation 存在但 examples 无 lint 门禁（O-2026-08-26-2），编译器自动物化/报错为候选（O-2026-08-27-02）。

#### 适用边界

服务端节点图 DSL（server ctxType）；语义以 Beyond_Debug_Log 帧值为准；客户端图未验证。

### int_list 列表三规则：全 0 短物化 / 写 0 不扩容 / 初始化 ≤100（哨兵与补整块模式）

引擎 int_list 运行时三规则：① 全 0 列表只物化出短长度（cornerOrient 声明 8 个 0 → 运行时 [0,0]，日志 2766；solveBuf 声明 100 → 25 项，日志 2944），「长度由什么决定」机制未解释（O-2026-08-27-08）；② set_list_value 写 0 到越界下标不扩展列表（写非 0 才扩展）；③ 字面量声明列表初始化最多 100 个元素，超限地图直接拒载（101 项事故 08-27）。通用对策：可能全 0 的发布列表尾部追加调用方约定忽略的哨兵 1（总长仍 ≤100）；长列表查询复合（乘法选择器/分块读取）要求每块长度 = chunkSize，生成器把最后一块补整块（2886 localAxisTable 越界、2964 乘法选择器越界读死循环）。

#### 适用边界

int_list 图变量/自定义变量（server 侧真实日志实证）；短物化长度决定机制开放。
