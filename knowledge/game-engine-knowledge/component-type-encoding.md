### 铭牌组件 27 三层编码：配置列表→内容组→主条目

铭牌组件类型配置字段是 38，为配置列表（重复字段 501）：38.501[n] 一个铭牌配置 {501 配置序号（v1、v2 递增，身份标识，wire 顺序不可靠）、505 fixed32 显示范围（米，默认 5.0）、507/508 fixed32 数值属性（默认 20.0/1.0，语义待确认）、512 内容组列表、602 UTF-8 配置名称（自动命名如“铭牌 配置ID1”）、605 varint 13}。每个配置可有多个内容组（重复字段 512）：512[n]={502 主条目、503/504/505/506/507 辅助容器、602 组序号（v1、v2 递增）}。主条目 502={502 字号（默认 18）、503 尺寸（501 宽度=UI 一半/疑似半宽、502 高度）、504 文本（501 显示内容，支持内嵌变量占位符 {<id>:<变量名>}，如“这是显示内容{2:PDist}”；变量名可不在关卡文件其他位置出现）、505 偏移（501 X、502 Y）、510 varint 12}。已确认字段值样本：字号 18→30、宽度 UI 2000→wire 1000.0、高度 30→300、偏移 333/444、显示范围 5→25。新增配置=追加 501，序号与名称自动递增，自带一个默认内容组；游戏节点图按配置序号切换显示。

### 自定义变量组件 1 编码与类型码共用 VarType 枚举

组件类型 ID 1=自定义变量组件（编辑器“自定义变量组件”是单位默认挂载组件，元件/实体创建时自动带上）。其类型配置字段是 11，内为变量列表（重复字段 1）：1.11.1[n] 一个自定义变量条目（38B，同构）={2 UTF-8 变量名（同一组件内不允许重名）、3 varint 类型码（全局通用 VarType，与信号参数/关卡变量共用同一枚举，已三方核对：GIA proto VarType、信号 InParam、GIL wire 类型码）、4 length-delimited 默认值容器 {1:类型码, 2:{1:类型码,2:0}, (10+类型码):默认分支}、5 varint 1（疑似 exposed/可见标记，恒定）、6 length-delimited 类型引用 {1:类型码, 2:0}}。新增变量=追加一条同构 field-1 条目；复制新建的变量与原条目字节一致（仅名称不同）。类型 6=String、15=VectorList 为本次样本。

### 组件引用绑定：名称引用+root 注册表、资源引用只存 ID

引用绑定模式（物件镜头/计时器）：组件配置内以名称引用（如物件镜头 f4.f2="自定义镜头_1"、全局计时器 f26.f1="全局计时器1"），目标注册表在 root（root18 镜头容器、root12 计时器容器）以同名条目+自增 ID 存在；绑定是名字+ID 双重引用（f502 ID ↔ root18 条目 ID）。资源 ID 存储（特效 exp10 确认）：资源只存 ID 不存名字，游戏运行时用 ID 引用；特效条目 ID 双处存储（f1 + f10={f2:ID}，切换资源时两处同步更新，如 2→7），音效条目单处（f2）。GIL 中无资源名字样；特效条目 f503 是编辑器自动生成的条目名（如“特效(1)”），非资源名。

#### 适用边界

来源：component-investigation exp9/exp10（资源等长替换 2→7）、exp13-14/15（物件镜头/计时器绑定）、nameplate 轮；仅覆盖特效/音效/镜头/计时器四类引用；其他资源类型与名称解析机制未验证
