### 「禁锢」类控制单位状态静默阻断技能装配与施放（3045 vs 3070 因果闭合）

编辑器给角色施加的「禁锢」类控制单位状态会静默阻断技能装配与施放：被禁锢时技能实例创建被拦（Create Custom Skill Instance 无有效实例产出）、Cast Specified Skill Instance 帧全对但无效、客户端图零执行，且无任何报错日志。解除禁锢后同一注入链路（含 addCharacterSkill 装配步骤）全链通过：create OUT=10000002 → cast → 客户端图 f8=2097154 执行 → 信号回传。单变量差分定论：日志 3045（禁锢，拦截）vs 3070（解除，全通），地图 1073741914，技能配置 1098907651（6 自定义+瞬发）。

#### 适用边界

判据适用于「服务端链路帧全对但客户端图零执行/装配无产出」的排查：先查角色是否被施加控制类单位状态。禁锢为用户编辑器侧可施加/解除的状态（本项目后续仍复用），本条不覆盖其施加编码及其它控制状态的作用面。

### 客户端节点图只能读、不能写自定义变量

客户端节点图不具备写自定义变量的能力：官方客户端节点文档（角色技能/造物技能/造物状态/造物状态决策/角色操控技能/过滤器六类）全篇无『设置自定义变量』节点，本项目 vendor 的客户端节点模式表 setCustomVariable 命中数为 0，两侧互证。因此『客户端写实体变量、服务端读』不构成可用通路；跨端数据回传必须改走信号等既有能力。

#### 适用边界

适用于当前全部七类客户端节点图（含布尔/整数过滤器）。不排除后续版本新增写变量节点；也不否认客户端可读自定义变量（读取需变量已在资产侧预注册，且声明层级决定可见性）。

### 客户端节点图的三类能力限制与两条可靠性约束

客户端节点图（月之六客户端运算）受三类能力限制：不能使用复合节点、不能修改自定义变量、不能修改引用类型。另有两条可靠性约束：动画与技能互斥；异步调用不可靠。创作者在这个边界上做变通，而不是绕开边界。

#### 适用边界

本条只列限制本身，不含变通做法；『不能修改自定义变量』与另一条 Claim（客户端只能读不能写自定义变量）为同一事实的不同表述，本条补充其余两禁与两条约束。限制随版本可能放宽，实现前应复测。
