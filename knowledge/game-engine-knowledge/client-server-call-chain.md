### 服务端调用客户端节点图：技能实例施放→节点图开始→信号回传（魔方-客户端优化版本实证）

服务端调用客户端代码的官方链路：服务器节点创建自定义技能实例（技能配置ID→实例ID）并用施放指定技能实例触发技能释放；技能动画节点图事件轨道打点绑定客户端节点图，释放到该时点时客户端图节点图开始顺序执行（官方文档 mhj4a0rzu4pi/mho2iu0eaia0/mhlaj0r9bldi）。角色操控技能(20010 character_control_skill)仅在操控状态可用、释放期间无动画表现、仅支持挂角色操控技能节点图。客户端回传服务器两条通道：向服务器节点图发送信号（信号名+参数，所有服务器图可监听）与通知服务器节点图（3 字符串参数→服务器技能节点调用时事件）。读客户端图时 parse/explain 的节点名是服务端名字表撞号产物，一律按 client_node_metadata.ts 的 genericId+concreteId 重映射真实身份（节点图开始 isStart/设置局部变量/获取局部变量/获取自定义变量/多分支/向服务器节点图发送信号）。实证：魔方-客户端优化版本.gil 图 1082130436（191 节点客户端图）+ 技能配置 1228931073 + 玩家-界面图 Cast Specified Skill Instance 链
