### root18 镜头容器与物件镜头组件 13 绑定（真实 GIL 确认）

root 18 是镜头容器，每条 18.1 record 一个镜头：{1:自增ID, 2:{1:UTF-8镜头名, ...参数}}。新增镜头=append 一条 record（ID 自增，样本 1073741825/26）；删除镜头=移除对应 record（exp17 实测：删除“自定义镜头_1”后 208B→83B，其余 root 全部不动）。参数示例（默认自定义镜头）：f2=6.0、f3=45、f5=1、f6=6、f14=1、f15=-180、f16=180、f17=-89、f18=89、f37=1；物件镜头类型额外 f4={0.2}/f6=30/f12=10/f21=1/f23=30/f24=30/f32=1/f33={0.15×3}。元件/实体通过组件 type 13（物件镜头组件）绑定镜头：配置 f23.f4={f1=镜头槽名（如“物件镜头_1”）、f2=镜头名（如“自定义镜头_1”）、f3="GI_RootNode"、f501=1、f502=镜头ID}；绑定以名字+ID 双重引用（f2 名称↔root18 条目名，f502 ID↔root18 条目 ID）。移除绑定=清空配置（exp16 实测：f23 60B→0B，槽 67B→7B，root18 镜头定义保留）。

### 按玩家切换镜头与 UI 按钮事件转发顺序（用户说明，未验证）

镜头切换：节点图可以为指定玩家切换镜头，而不是必然让所有玩家同时切换；多人模式下镜头状态应优先视为每个玩家自己的观看状态。切换入口：选项卡（实体上配置，玩家选择后实体节点图接收事件执行切换）或屏幕 UI（玩家按下后角色收到 UI 事件，节点图再为该玩家切换）。屏幕控件 UI 按钮事件顺序：玩家按下 UI 按钮 → 事件首先发送给该玩家对应的角色（不是任意关卡实体）→ 角色挂载的节点图处理事件；若按钮最终控制其他实体，在角色节点图中增加转发逻辑（按钮按下→角色收到事件→角色节点图确定目标实体→转发信号或调用目标逻辑→目标实体执行）。

### 界面控件组状态语义（官方综合指南）

界面控件组状态分为激活/未激活；已激活的界面控件组表现状态为开启、关闭、隐藏：开启=可见性开启；关闭=可见性关闭且不保留动态改动（重开初始化）；隐藏=可见性关闭但保留动态改动（重开恢复原样）。

### 图片控件引用素材的 wire 路径（真实 GIL 差分闭合）

图片控件（root9 控件段）引用素材库素材的 wire 路径是 f505[f502=38].f503.f31.f6.f4 = 素材索引 ID（= 素材库容器 ID，0x40000000+ 段）。f6 是素材引用结构 {f2:1, f3:8, f4:素材ID}，其中 f2=1、f3=8 是固定常量（两个独立样本一致，非图片源/拉伸类型编码）；f3={f501:-1}、f4=-1 是「无颜色覆盖」标记。图片源组件 f505[f502=38] 的 f503 里 f31 是「静态引用」图片源，f504={f2:1,f3:8,f4:自身ID} 是自引用。

### 控件模板与实例双向引用 + 布局引用三步联动（真实 GIL 差分闭合）

自定义控件模板在 root9 是「模板 + 实例」两条记录：模板 f502[type4] 自标识、无 f504、含图片源；实例 f502[type3] 引用模板（f13.f501=模板ID）、f504=布局/容器 ID。双向引用：实例→模板走 f502[type3].f13.f501，模板→实例走 f502[type4].f14.f501（packed 实例 ID 列表 back-reference）。「把控件模板放进布局」= 三步联动：①新建实例记录（f504=布局ID，f502[type3] 引用模板）②实例 ID 追加进布局的 f503 packed 列表 ③模板 f502[type4].f14.f501 追加实例 ID。默认布局 1073741825 的 f503 = 14 官方预置（1073741826~1839）+ 用户新增实例；控件组容器 1073741840 的 f503 = 尚未放入布局的实例列表。
