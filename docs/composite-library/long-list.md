# 资源包 15：长列表工具包（long-list）

> 状态：当前推荐
> 来源：从 rubik-3x3 项目抽象（2026-08-22）
> 最近校验：2026-08-22
> 适用范围：千星沙箱服务端节点图；突破「初始列表字面量最多 100 元素」限制

## 用途

把多个 ≤100 元素的官方列表拼成一个「逻辑长列表」，对外像官方 `Get Corresponding Value From List`
一样按下标读取，内部自动拆封。解决「初始列表字面量最多 100 元素」的编译器/编辑器限制。

## 节点清单（2 个，纯数据流）

| 复合名 | 功能 | 输入 | 输出 |
|---|---|---|---|
| `long_list_get_vec3` | 从 3 段 vec3_list 拼接的长列表按下标取 vec3 | i, chunkSize, c0, c1, c2 | out |
| `long_list_get_int` | 从 3 段 int_list 拼接的长列表按下标取 int | i, chunkSize, c0, c1, c2 | out |

## 通用方法论（提炼）

1. **「分块 + 数据选择器」是突破长度限制的通用技巧**：把长列表拆成多个 ≤100 的 chunk（c0/c1/c2），
   按下标 `i` 算出「在哪个 chunk + chunk 内偏移」：`chunk = i / chunkSize`，`offset = i % chunkSize`。
2. **用「乘法选择器」代替 exec 分支**：`sel0 = (chunk==0)`、`sel1 = (chunk==1)`、`sel2 = (chunk==2)`，
   每个 chunk 的值乘以对应 sel（0/1），再相加——**sel 为 0 的 chunk 贡献 0，只有目标 chunk 贡献真实值**。
   这是**纯数据流实现「按条件选值」**的技巧，避免 exec 分支（更省节点、更可复用）。
3. **vec3 用向量缩放做选择器**：`_3dVectorZoom(v, sel)`（sel 是 float 0/1），int 用 `multiplication(v, sel)`。
   **不同类型的选择器用不同的「乘 0/1」实现**。
4. **chunkSize 是参数**：不同场景 chunk 大小不同（如 100 元素限制下 chunkSize=100），作为输入传入，
   同一个复合节点适配不同分块。

## 复用提示

- 这是**跨玩法通用的工具**——任何需要「超过 100 元素的列表」的场景（大量实体、大量配置数据）都能用。
- 需要更多 chunk（>3 段）时，照模板加 c3/c4 和 sel3/sel4 即可。
- 「乘法选择器」技巧本身也通用：**任何「按条件从多个候选值里选一个」的纯数据流场景**都能用
  （比 `multipleBranches` 更省节点，因为不产生 exec 分支）。
