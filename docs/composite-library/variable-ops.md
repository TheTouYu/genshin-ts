## 用途

对**节点图变量**或**自定义变量**做一次「+1 / -1 / ±N」运算。这是节点图里最高频的基础件——
几乎任何计数、状态累加、分数累加都要用到。

## 通用方法论（提炼）

1. **「读-算-写」三段式是变量运算的标准形态**：`Get 变量 → 运算 → Set 变量`。任何「对变量做一次运算」都可以套这个模板，只是中间的运算节点（Addition/Subtraction/Multiplication/…）不同。
2. **节点图变量 vs 自定义变量是两套独立 API**：`Get/Set Node Graph Variable`（图内共享，作用域=当前节点图）与 `Get/Set Custom Variable`（挂在实体上，跨图共享）。作者把两者都做成了复合节点，说明**选择哪个取决于变量要跨图还是图内**。
3. **整数 vs 浮点要分开**：整数用 `bigint`（DSL 里 `0n`），浮点用 `number`。作者为 int/float 各做一套，因为**类型不能混用**——这是节点图强类型约束的直接体现。
4. **复合节点接口 = 变量名 + 增量两个输入**：`compositePins` 把「变量名」和「增量」暴露为外部输入，内部 Get/Set 用同一个变量名。**变量名是 pin 值，不是硬编码**——这样同一个复合节点能操作任意变量。

## 复用提示

- 这些是最简单的复合节点（3 节点），**价值不在「省节点」，而在「语义清晰」**：`变量+1` 比裸的 Get→Add→Set 三连更可读。
- 需要「变量 ×N」「变量取反」「变量取绝对值」时，照这个模板把中间运算节点换掉即可。
- 注意：复合节点内部变量类型无法切换（作者在 1610612752 注释里明确提到），所以 int/float 要各做一套，不能一个复合节点通吃。
