# 资源包 8：枚举转换包（enum-conversion）

> 状态：当前推荐
> 来源：真实 GIA 资源包「常用复合节点大全 v1.7」逆向整理
> 最近校验：2026-08-22
> 适用范围：千星沙箱服务端节点图；打通「枚举值」与「可运算值」的桥梁

## 用途

把**枚举类型**（如实体类型、结算状态、胜负结果）转换成**可运算的值**（整数/字符串）或**执行分支**。

## 节点清单

|---|---|---|---|
| 1610612759 | 枚举→整数（少枚举，3 个） | Enumerations Equal ×3 + Data Type Conversion + 乘法/加法 | 1=未定 2=胜利 3=失败 |
| 1610612755 | 枚举→整数（多枚举，5 个） | Enumerations Equal ×5 + Data Type Conversion + 乘法/加法 | 1=关卡 2=物件 3=玩家 4=角色 5=造物 |

| 1610612757 | 枚举→执行分支（少枚举） | Enumerations Equal ×3 | 直接判断 |
| 1610612756 | 枚举→执行分支（多枚举） | 1610612758 + Multiple Branches | 2 节点 |

## 通用方法论（提炼）

1. **枚举转整数 = 逐项 Enumerations Equal + 加权求和**：对每个枚举值做 `Enumerations Equal`（判断「当前值 == 枚举项」），结果（0/1）乘以对应整数，再相加。**这是「枚举 → 编号」的通用编码法**（类似 one-hot 编码再解码）。
2. **枚举转字符串 = 逐项判断 + 列表取值**：`Enumerations Equal` 判断是哪个枚举，用 `Assembly List` 拼一个「枚举→字符串」的映射列表，`Get Corresponding Value From List` 取值。**这是「查表法」**。
3. **枚举转执行分支 = 逐项判断 + Multiple Branches**：`Enumerations Equal` 判断后接 `Multiple Branches` 分发到不同执行流。**这是「switch-case」的等价物**。
4. **作者反复强调「这里提供一个思路」**：枚举转换的**具体枚举项是业务相关的**（实体类型/结算状态/胜负），复用时要改成自己的枚举。**学的是「枚举→值」的编码思路，不是照抄枚举项**。
5. **少枚举 vs 多枚举用不同实现**：少枚举（3 个）用直接判断，多枚举（5 个）用查表法。**枚举项多时查表法更省节点**。

## 复用提示

- 这是**最有「思路价值」的资源包**——枚举转换是节点图里常见的「类型不匹配」痛点，这套编码法（one-hot + 加权 / 查表）可推广到任何枚举。
- 需要「枚举 → 自定义编号」「枚举 → 显示文本」时，直接套这套模板。
- 注意：`Enumerations Equal` 是专用节点，不是普通的 `Equal`——枚举比较要用它。
