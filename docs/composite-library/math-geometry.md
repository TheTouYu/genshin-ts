# 资源包 14：数学/几何运算包（math-geometry）

> 状态：当前推荐
> 来源：从 rubik-2x2 / rubik-3x3 项目抽象（2026-08-22）
> 最近校验：2026-08-22
> 适用范围：千星沙箱服务端节点图；纯数据流数学/几何复合，零玩法依赖

## 用途

三维向量旋转、轨道位置、局部坐标变换。这是**跨玩法最通用的 A 类资产**——纯数据流、
零玩法依赖，已在 2x2 和 3x3 两个魔方项目里被复用（证明其通用性）。

## 节点清单（4 个，全部纯数据流）

| 复合名 | 功能 | 输入 | 输出 | 数学公式 |
|---|---|---|---|---|
| `math_rotate_vec` | 罗德里格斯旋转 | v, u(单位轴), c(cosθ), s(sinθ) | out | v' = (u·v)u + (v−(u·v)u)c + (u×v)s |
| `math_orbit_point` | 轨道段位置 | vp, vPerp, axv, c, s | p | p = vp + vPerp·c + axv·s |
| `math_local_axis_rot` | 单轴局部旋转 | v, angle(deg), u(轴) | out | 调 rotate_vec，c=cos(rad), s=−sin(rad) |
| `math_spin_axis_triple` | 三轴局部旋转 | v, rot(欧拉角) | out | Y→X→Z 依次把世界轴转进局部系 |

## 通用方法论（提炼）

1. **罗德里格斯旋转是「绕任意轴旋转」的标准实现**：`v' = (u·v)u + (v−(u·v)u)cosθ + (u×v)sinθ`。
   节点图没有「绕任意轴旋转」的专用节点，用点积/叉积/缩放/加法组合实现。**这是「把数学公式翻译成节点图」的教科书**。
2. **「c/s 分离」是性能优化**：`rotate_vec` 接收 `c=cosθ` 和 `s=sinθ` 作为输入，而不是 `θ`——因为
   调用方可能多次用同一个 θ，**预计算 c/s 避免重复三角函数**（三角函数是重计算）。
3. **局部旋转 = 世界旋转 + 坐标变换**：`local_axis_rot` 把「绕局部轴旋转」分解为「先算 c/s，再调 rotate_vec」。
   `spin_axis_triple` 把「三轴欧拉旋转」分解为「Y→X→Z 三次单轴旋转」。**复杂变换 = 简单变换的组合**。
4. **嵌套复合调用**：`spin_axis_triple` 内部调 `local_axis_rot`，`local_axis_rot` 内部调 `rotate_vec`。
   **大复合 = 小复合的组合**，这是复合节点的标准分层方式。
5. **注意 s 的符号**：`local_axis_rot` 里 `s = −sin(rad)`（负号），因为罗德里格斯公式里是 `(u×v)sinθ`，
   而这里的旋转方向约定需要取反。**符号约定要按项目几何验证**（见 motion-devices.md 的轴语义）。

## 复用提示

- 这 4 个复合是**直接复制即可用**的 A 类资产（纯数据、零玩法依赖），任何需要「旋转/轨道/坐标变换」的玩法都能用。
- 2x2 里叫 `gsts_rotate_vec`，3x3 里叫 `math_rotate_vec`，**逻辑完全一致**——抽象时统一用 `math_*` 前缀（3x3 的命名更规范）。
- 需要「绕任意轴旋转」「轨道运动」「局部坐标变换」时，直接套这 4 个，不要从零写点积/叉积组合。
