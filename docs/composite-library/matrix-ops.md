## 用途

## 通用方法论（提炼）

1. **用向量表示矩阵**：三阶矩阵 = 三个三维向量（每行/列一个向量）。**矩阵运算 = 向量运算的组合**（加法 = 3 个向量加法，数乘 = 3 个向量缩放）。这是节点图里「没有矩阵类型」时的标准表示法。
2. **「向量形式」远优于「列表形式」**：作者做了两个数乘实现——向量形式（3 节点，低负载）和列表形式（8 节点，300ms 负载），并明确标注列表形式「负载消耗太高，基本没有实际意义；留着引以为戒」。**同样的功能，用对数据结构负载差 100 倍**。
3. **负载意识贯穿始终**：作者对每个重节点都标注了单次调用负载（行列式 30ms、伴随 60ms、逆矩阵 120ms），并提示「阶数越高负载消耗越大」「如果对负载要求更高，可以拆开求值节点用局部变量存储」。**矩阵运算是重计算，要按需优化**。
4. **代数余子式法 + 伴随矩阵求逆**：作者用「代数余子式法求行列式 → 伴随矩阵 → A⁻¹ = (1/|A|)·A*」的完整数学流程实现逆矩阵。**这是「把数学公式翻译成节点图」的完整案例**。
5. **优化技巧：角标和为奇数的余子式取反用输入值调换**（作者注释）——省了 4 个乘法运算。**节点图里每个节点都是成本，能用技巧省就省**。

## 复用提示

- 这是**「把数学算法翻译成节点图」的教科书**，适合需要矩阵/向量运算的玩法（旋转、变换、物理模拟）。
- 「向量形式 vs 列表形式」的负载对比是重要教训：**选对数据结构比优化算法更有效**。
- 逆矩阵 120ms 的负载提示：**矩阵求逆是重操作，不要每帧调用**，应缓存结果。
