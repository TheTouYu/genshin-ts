# 资源包 10：排名/结算包（ranking-settlement）

> 状态：当前推荐
> 来源：真实 GIA 资源包「常用复合节点大全 v1.7」逆向整理
> 最近校验：2026-08-22
> 适用范围：千星沙箱服务端节点图；竞技/结算玩法核心

## 用途

玩家分数排序、结算计分板、结算排名。竞技/结算玩法的核心逻辑。

## 节点清单

| 复合 ID | 功能 | 内部节点 | 关键点 |
|---|---|---|---|
| 1073741828 | 玩家分数排序（排名 1） | 字典 + 排序 + 列表循环 | 用节点图变量中转 |
| 1610612754 | 玩家分数排序（排名 2） | 字典 + 排序 + 列表循环 | 用局部变量（更省） |
| 1073741850 | 结算计分板展示 | Get/Set Custom Variable ×3 + Set Player Settlement Scoreboard | 14 个输入 pin |

## 通用方法论（提炼）

1. **「玩家实体 + 分数 → 字典 → 排序」是排名的标准流程**：把玩家实体和分数组成字典（`Create Dictionary`），`Sort Dictionary by Value` 按分数排序，再遍历设置排名。**字典是「实体→值」映射的标准容器**。
2. **节点图变量 vs 局部变量的权衡**：排名 1（1073741828）用节点图变量中转，排名 2（1610612754）「将节点图变量全部更换为局部变量，减少操作」。**局部变量比节点图变量更轻量**（作用域小、无持久化开销），能省就省。
3. **前置条件要写清楚**：排名节点需要「关卡实体挂载自定义变量：浮点数列表 排名分数、整数 列表循环、整数 排名中转」+「玩家实体挂载浮点数 排名依据变量」。**复用前必须先满足这些变量前置条件**。
4. **结算计分板是「多输入映射」**：`1073741850` 有 14 个输入 pin，把多个自定义变量映射到结算计分板的多个展示位。**「根据需要填写，若不需要则空缺即可」**——可选输入用空缺表示。

## 复用提示

- 「实体+值 → 字典 → 排序」是**通用排名模板**，可推广到任何「按某值给实体排序」的场景（分数、击杀数、用时）。
- 局部变量优先于节点图变量，是**通用性能原则**。
- 结算计分板的「多输入映射」模式适合「把一堆数据一次性展示」的场景。
