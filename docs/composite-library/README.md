> 状态：当前推荐（持续补充中）
> 来源：真实 GIA 资源包「常用复合节点大全 v1.7（补充包同步更新中）」逆向整理（作者：左岸丶寒）
> 最近校验：2026-08-22
> 适用范围：千星沙箱（原神）服务端节点图；作为「可复用复合节点」的参考目录与抽象来源

## 这是什么

本目录沉淀**从真实游戏项目/资源包里抽象出的通用复合节点**，供编写节点图时直接参考或复用。
来源是社区作者整理的「常用复合节点大全 v1.7」资源包（87 个复合节点，每个带中文注释说明用途、
依赖、负载与注意事项）。我们把它**按功能分类**，提炼出「哪些是真正通用、值得复用的资源包」，
并记录每个资源包背后的**通用方法论**（为什么这么写、踩过什么坑、负载如何）。

> 与 `docs/game-engine-knowledge/composite-usage-guide.md` 的分工：
> 那个文档讲「**怎么**写复合节点」（接口设计、四种形态、边界陷阱）；
> 本目录讲「**有哪些**现成的复合节点可以抄/复用」（分类目录 + 每个节点的用途/依赖/负载）。

## 从这份资源包学到的「通用方法论」（提炼精华）

这些是**跨资源包、真正通用**的编写经验，已回灌到 `dsl-nodegraph-development` 技能与
`composite-usage-guide.md`。详见各资源包文档，这里列提纲：

1. **复合节点 = 接口 + 注释**：每个复合节点都带中文注释说明「用途 / 依赖（挂载哪个实体、需要哪些变量）/ 负载 / 注意事项」。这是可复用资源包的核心价值——**没有注释的复合节点无法复用**。
2. **依赖前置条件要写清楚**：很多复合节点依赖「关卡实体挂载全局计时器 Update」「节点图变量 time」「玩家实体挂载排名依据变量」等，作者都在注释里写明了。**复用前先满足前置条件**。
3. **负载意识**：作者对每个重节点都标注了单次调用负载（如矩阵求逆 120ms、批量销毁需间隔 0.1s 防炸图）。**节点图不是免费算力，重操作要拆帧/间隔**。
4. **「思路型」节点比「功能型」节点更值钱**：枚举转换、空模型归纳变量、动态列表转静态这些节点，作者明确说「这里主要提供一个思路」，因为复合节点内部变量类型无法切换，复用时要按需改。**学的是思路，不是照抄**。
5. **同一功能多种实现，按负载/场景选**：销毁实体有 3 种实现（延时/迭代/批量间隔），玩家退出检测有 2 种（按频率选）。**没有银弹，按场景权衡**。

## 如何继续补充这个资源库

后续把「写得比较好的游戏项目」里的节点图抽象成通用复合节点时，按以下流程（已沉淀为
`composite-library-curator` 流程，见 `docs/composite-library/curation-process.md`）：

1. 读真实 `.gia`/`.gil`，提取复合节点 + 注释；
2. 按功能分类，判断「通用价值」（是否跨玩法可复用）；
3. 提炼「思路型」方法论（为什么这么写、踩了什么坑、负载如何）；
4. 落盘到对应资源包文档，并回灌到技能/`composite-usage-guide.md`。
