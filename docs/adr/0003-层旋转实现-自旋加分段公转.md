# ADR-0003: 层旋转实现 = 每块自旋 + 分段直线公转叠加（替代枢轴跟随方案）

2×2 层旋转（4 个角块绕层轴转 90°）的运行时实现，最初计划为"4 块绑定中心枢轴 + 跟随运动器 + 枢轴旋转"（用户 2026-08-12 教学架构），但该方案的自旋行为不可控、难调整（绑定/解绑、跟随目标切换、停止时序等多处未知规则）。P4 第二步改用**每块独立计算**：对每个角块同时施加两个运动器——

1. **自旋**：`addUniformBasicRotationBasedMotionDevice`（匀速旋转，已验证 90°/1s 连续累积、世界轴语义）；
2. **公转**：`addUniformBasicLinearMotionDevice`（匀速直线，**N=5 段折线逼近 90° 圆弧**，每段 18°，速度向量 = 弦向量 ÷ 段时长）。

选匀速直线运动器而非定点运动器：前者只需**速度向量**（相对量，段位移是固定几何，与角块当前位置无关）；后者需要**目标绝对位置**（要查实体位置或自跟踪状态），且带目标旋转/锁旋转参数属干扰。官方无椭圆/圆弧运动器，多段直线是唯一路径（N=5 为视觉/节点数折中，后续可调）。

多段衔接：运动器停止事件（`whenBasicMotionDeviceStops`，payload 含运动器名称）驱动下一段，或定时器序列同步推进（见实现计划）。旋转期间用**输入锁**（布尔图变量）忽略新输入，防连点状态错乱。

**Status**: accepted（用户 2026-08-13 拍板）

**Considered Options**
- 枢轴 + 跟随运动器（旧教学方案）：公转自旋一次到位，但自旋不可控、绑定/解绑/停止时序未知规则多，被否决。
- 定点运动器分段：需绝对目标位置 + 旋转参数干扰，被否决（见上）。
- 每块自旋 + 匀速直线分段公转：两运动器并行（引擎支持一实体多运动器），各管各的，被采纳。

**Consequences**: 每段折线有微小弓高误差（18° 段 ≈ 0.012×半径）；段间衔接平滑度待游戏核验；分派逻辑需动态计算每段速度向量（sin/cos，为 3×3/4×4 扩展保留）。
