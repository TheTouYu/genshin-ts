## 二、3071 完整调查链（现象 → 根因）

**现象**：用户 r1 交互「面旋转不对」。日志 3071（1914，21:01 会话）。

1. **交互定位**：sec5 大 turn 记录 = 开局 5s logicReset 正常级联（排除）；sec15 = r1
   （game dispatch → op3 val=1 → turn flowDoMove 93KB 逻辑全量执行 → visual×18）。
   逻辑层无异常——问题在视觉调度。
2. **假线索排除**（各耗 1~3 轮工具调用）：
   - orbit1 速度 (0,0,0)：R **中心块**位于旋转轴上（v0∥axis → vPerp=0）——数学正确，非 bug；
   - vels1/vels2 / localAxisTable2 读回空：长表选择器未选中分支的 0 缩放 + 已知短物化家族——非本轮病灶。
3. **决定性模式**：设备表全景——18 条 visual 记录中**仅两个实体**收到设备：E34（=blocks[24]=R 中心，
   A 通道 5 条）与 E17（=blocks[7]，B 通道 4 条）。即 slot = base + seq 且 **seq 恒 0**：
   A 通道 5 次全部 slot0、B 通道 4 次全部 slot5，7 块零动画。
4. **帧级铁证**：rec39 帧[0] `When Timer Is Triggered: OUT3:Integer=（空）OUT4:Integer=（空）`。
5. **wire 差分**（方法核心）：1914（坏）visual 图 `seq ← 事件 {kind:4,index:4}`；**1899 原图**
   （最后已知正确、2960 会话实际载体，同图族同引擎）`seq ← {kind:4,index:3}`——两图事件节点
   逐字段一致，唯一差异即此连线。
6. **引擎语义差分**（3067 zt-lane，同日晚注入、同引擎）：重复型 dsp OUT4=1..19 填充；非重复
   p1 双空。结合 1899+2960：**OUT3=序列序号（仅多槽携带槽位号）；OUT4=循环次数（仅重复型
   携带计数）**。
7. **归因**：b8b97ff（08-30 07:20）的 2998 取证样本全部是重复型，把「OUT3 恒空」误判为全局
   引脚换序。注入后 36h 内无面转测试（谱系 #2），3071 首测暴露。

**方法论沉淀**：①**参照物地图 wire 差分**——同图族的历史已知正确地图是最快的 golden（1899 一直
在磁盘上）；②**同引擎跨行为品种差分**——用另一个已知行为的图（zt dsp/p1）一轮拿到引擎填充
语义；③**设备/副作用接收方全景表**比逐帧追参数快一个量级（本例 18 条记录两张实体分布直接
钉死坍缩模式）。

## 三、系统性根因（为什么发生/如何复发）

1. **取证覆盖偏差**：引擎语义结论从单一行为品种（重复型）外推为全局规则（引脚换序）。
   证据是真实的（2998 帧值不假），错在**样本不覆盖结论的适用域**。
   防线：引脚/编码语义取证必须做**品种矩阵**（多槽 / 重复 / 单发），且与已知正确 wire 交叉
   验证——参照物一直都在，2998 轮没看它。
2. **回归盲窗**：编译器/定义层变更 + 地图重注入后的验证只覆盖当轮特性（探针/链路），
   从不跑最便宜的端到端烟囱（一次面转）。
   防线：**注入后烟囱交互**进核验门——「编译 0 错 ≠ 注入正确 ≠ 游戏行为正确」已有分层，
   缺的是"游戏行为"层的最小探针项。
3. **生成物漂移债务**：gen 全量输出与提交产物持续分叉（3000+ 行），迫使每轮外科手术式手改，
   生成器规则（scripts/AGENTS：不手改生成物）与现实长期冲突。
   防线：登记专项对齐轮；短期沿用外科手术先例并在提交信息注明。
