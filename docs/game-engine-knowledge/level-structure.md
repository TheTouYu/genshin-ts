# 关卡结构

> 状态：框架草案
> 来源：用户对游戏编辑器和关卡结构的说明
> 最近校验：2026-08-01
> 适用范围：关卡文件的概念结构

关卡文件包含运行和还原一个关卡所需的信息。它是节点图、静态资源和初始场景内容的共同容器。完整关卡保存为 GIL，部分资产可以导出为 GIA，详见[资产、关卡保存与导出文件](assets-and-files.md)。

## 主要内容

### 节点图

一个关卡可以包含多个节点图。每个节点图拥有自己的节点、连接和拓扑结构，但必须挂载在实体或元件上才能运行。

节点图的详细结构见[节点图与拓扑](node-graphs.md)，运行条件见[节点图挂载与生命周期](graph-mounting.md)。

### 模型原件（Prefab）

模型原件定义可以直接摆放或生成到关卡中的实体模板。它属于关卡可用资源，但对应实体在关卡初始状态下不一定已经存在。

### 初始模型

初始模型是关卡开始时已经放置在场景中的模型。它与“可供后续创建的模型原件”不同。

实体或元件可以配置官方预置的[组件](components.md)和实体级[变量](variables.md)。由元件创建的实体会继承对应的组件和变量定义。

## 当前关系

```text
关卡
├── 节点图 × N
│   └── 挂载到实体或元件后运行
├── 模型原件（可用模板，初始不一定存在）
│   ├── 组件配置
│   └── 实体级变量定义
└── 初始模型（关卡开始时已放置）
```
