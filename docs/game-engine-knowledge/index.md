# 游戏引擎知识索引

> 状态：框架草案
> 来源：用户对游戏编辑器和关卡结构的说明
> 最近校验：2026-08-01
> 适用范围：从真实关卡文件逐步还原游戏引擎规则

本目录把关卡文件中包含的游戏引擎知识整理成一本可持续补充的“书”。

知识只从真实关卡、相邻单变化快照和用户编辑器/游戏验证中逐步确认。当前代码实现可以用于对照，但不能替代真实关卡证据。

## 知识关系图

```text
关卡结构
├── GIL 根字段与资源/图容器 ────→ GIL 整体结构与语义树
├── 完整保存为 GIL ─────────────→ 资产、关卡保存与导出文件
├── 包含多个节点图 ─────────────→ 节点图与拓扑
├── 包含模型原件与初始模型
├── 实体可配置官方预置能力 ─────→ 组件
└── 为节点中的实体、配置等参数提供资源背景

GIL 整体结构与语义树
├── 严格区分 GIL payload 根与 GIA Root
├── 记录字段 presence、wire type、大小与证据状态
├── 当前有限闭合资源、NodeGraph、CompositeDef 和信号索引路径
└── 按章节和编辑器单变化逐步闭合未知字段

游戏运行生命周期
├── 初始化关卡、玩家和角色
├── 创建关卡预设实体
├── 启动实体组件
├── 持续处理组件、玩家和 UI 事件
└── 结算并退出

节点图挂载与生命周期
├── 节点图必须挂载到实体或元件
├── 挂载对象生命周期触发事件 ───→ 控制流
└── 多人实体可能使同一逻辑执行多次

节点图与拓扑
├── 事件作为执行起点 ───────────→ 控制流
├── 控制流节点组成逻辑脉络 ─────→ 控制流
├── 节点输入和输出使用类型 ─────→ 参数类型
├── 数据流节点提供参数 ─────────→ 数据流与连接
└── 用户定义节点及内部画布 ─────→ 复合节点

参数类型
├── 约束控制流节点的输入
├── 约束数据流节点的输入和输出
├── 约束变量可以保存的值 ───────→ 变量与作用域
└── 决定两个引脚能否连接

控制流
└── 执行节点所需参数可来自 ─────→ 数据流与连接

数据流与连接
├── 直接填写参数
├── 数据节点计算后连接参数
├── 已验证的发送参数规则关联 ───→ 信号
└── 输出可被一个或多个下游节点使用

信号知识
├── 引用关卡中已注册的信号定义与 identity
├── 已验证服务器发送节点骨架及 8 种固定值参数编码
├── 已验证普通监听骨架、注册信号切换与正式 GIA 导入
└── 具体实验事实与候选验证记录 → 信号实验事实

信号实验事实
└── 按实验批次保存真实快照、候选哈希和用户验证，不作为跨地图通用知识

复合节点
├── 可封装纯控制流、纯数据流或混合逻辑
├── 对外公开自定义输入和输出
├── 调用实例通过各自连线取得局部值 ─→ 变量与作用域
└── 内部拥有独立画布并可继续嵌套

组件
├── 给实体增加官方预置能力
├── 可以产生节点图事件
├── 名牌可在 3D 世界展示变量
├── 可以开启或关闭
└── 组件之间可能存在互斥关系

屏幕控件与 UI
├── 位于玩家屏幕空间，不属于 3D 世界
├── 通过控件 ID 控制显示状态
├── 接收键盘、鼠标和按钮输入
├── 按钮事件先发送给玩家角色，再按需转发
├── 可以触发玩家镜头切换 ───────→ 镜头系统
└── 可作为部分资产导出 ─────────→ 资产、关卡保存与导出文件

镜头系统
├── 预设镜头和自定义镜头
├── 节点图可为指定玩家切换视角
└── 物件镜头随挂载实体运动

资产、关卡保存与导出文件
├── GIL 保存完整关卡
├── GIA 保存可导入的部分资产
└── GIA 优先用于快速、最小验证 ─→ 验证与规则学习流程

游戏引擎知识与项目编译管线
├── 游戏知识描述真实规则
├── 高级 TS 逐层转换到 JSON/IR
├── 特殊规则与第三方库生成 GIA
└── GIA 资产可继续注入 GIL

验证与规则学习流程
├── 编辑器单变化产生真实证据
├── 临时同构重放验证已学规则
├── 已知规则进入对应编译层实现
├── 优先用最小 GIA 导入测试
└── 完整关卡关系才写回 GIL

变量与作用域
├── 实体级变量随实体实例保存
├── 节点图级变量仅在指定图内有效
└── 局部变量只沿当前数据连线传递
```

## 记录原则

每条具体规则至少说明：

- **对象**：关卡、节点图、节点、引脚、参数、连接或静态资源。
- **操作**：用户在编辑器中做了什么唯一变化。
- **证据**：相邻关卡快照、SHA-256 和定点比较结果。
- **结论**：确认了什么编码或连接规则。
- **范围**：适用于哪个图类型、节点族或参数类型。
- **验证层级**：真实编辑器观察、临时回读、真实写回或游戏行为。
- **关联**：它依赖或补充本目录中的哪些规则。

未知内容明确写成“待验证”，不依靠常见编号、代码实现或历史记忆猜测。
