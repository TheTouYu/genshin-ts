## §3 使用规则

1. 先查 §1（当前推荐）：当前结论、族级规则、方法论、覆盖状态都在这里。
2. 需要"这次是怎么定位到根因的"（调查链/帧签名/差分过程）→ §2.2 对应单主题复盘。
3. v1 总纲（§2.1）仅作历史对照（第一轮口径），结论以 v2 为准。
4. 复盘文档与新发现矛盾时，以真实日志/GIL/用户验证为准，并登记 open-items。
5. 新复盘完成后：更新 §1（新增行）+ 本索引登记数量；单主题复盘保持原位不移动。
