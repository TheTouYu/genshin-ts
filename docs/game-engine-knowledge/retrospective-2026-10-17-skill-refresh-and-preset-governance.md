## 三、为什么反复出问题——系统性根因（3 条）

1. **会话身份 > 技能路由**：persona 每轮注入、定义"我是谁"，技能 description 只在被触发时才起作用。只改技能不改 persona = 治标；只改文档 = 不生效。
2. **改配置前必须先回答三问**：**谁拥有它**（本项目 / 伞工作区 / 宿主）？**怎么生效**（热重装 / 重启 / 下次会话）？**规范在哪**（本项目 AGENTS / 伞 AGENTS / 记忆桶）？本轮两处翻车（#3 #4）都是跳过这三问。
3. **落点要按「生效载体 + 字节预算」选**：技能（按需加载，无预算压力）> 路由表（常驻但受硬门禁）> 全局守则（每轮注入，≤4KB）。同一知识放错层 = 白做。
