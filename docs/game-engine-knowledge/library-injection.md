> 关卡文件 `Beyond_Local_Save_Level/1073741907.gil`（45224B，58 条 502 记录；
> 素材段布局 dump 命令：`parseWireMessage` 全量 502 记录 → 501/503/504/名字/归属归因；
> Temp/ 同路径逐字节一致，sha256 `74fc4059…`）
> 最近校验：2026-08-22（含写回事故复盘：header 长度字段未同步 → 游戏拒载）

## 概念

游戏"素材库"（AI 生成资产直接注入的目标）在 .gil 中是一组
**容器 → 分组 → 图元**记录：1 个顶层容器 + 1 个分组 + 每个分类 1 条副本记录。
容器与分类副本通过 `502.13` / `502.14` 互指，两者不对称：
`13` 为 w0 裸 varint，`14` 为 w2 包裹裸 varint。

## 已闭合规则（真实差分确认）

- **整体骨架**：顶层容器 `502.14{501=分类副本 ID}` ↔ 分类副本 `502.13{501=顶层容器 ID}`；
  分类副本额外带 `504=parent`；`503` raw 是 group ID 列表（packed varint）。
- **注册表**：num501 含全部容器 ID（含分类链），非升序、非仅顶层。
- **root46** = 编辑器保存记录：新条目 PREPEND 头部、满 4 条替换头部——CLI 注入不得触碰。
- **位置**：元素位置 `f504` = (x, y)，画布原点在中心；编辑器 (100,100) ↔ wire (0.0729, 0.0001) 逐字节验证。
- **图元**：形状类型 `505.31.503.31.2`、颜色 `505.31.503.31.4`（-65536 = 0xFFFF0000 红 ARGB）；
  形状号段 100001=矩形 … 100006=圆环；504/505 内浮点为 wire5 fixed32。
- **命名**：游戏对重名自动追加 `_1` 后缀，注入前需查重。
- **GIA wire 层**：图像模式 class=15、装饰物模式 class=28（详见 gia 章节）。

- **header 长度字段必须同步（2026-08-22 事故实证，最高优先级）**：
  写回只重建 payload 而原样拷贝头部 20B → 文件 45224→87891B 但
  `hdr[0:4]=45220`、`hdr[16:20]=45200` 仍为旧值 → 游戏报"存档损坏"。
  规则：`hdr[0:4] = 文件总长-4`、`hdr[16:20] = payload 长 = 文件总长-24`
  （大端 uint32），其余 12B 保存时不变（样本恒为 00000001/00000326/00000002）。
  与 `gil-structure-semantics.md` L70-81（2026-08-05 实证）同款；verify 必须断言
  "长度字段已同步 + 其余 12B 与源一致"，而非"头部 20B 与源一致"。
  本次事故修复后：候选与损坏版 payload 逐字节一致、仅 header 两字段不同，
  游戏可正常加载（sha256 `55823ca6`）。
- **模板容器定位（extractTemplate）**：容器 = 有 503 组列表 **且含 14 链接**
  （顶层容器特征；分类副本含 13 无 14，注入后 ID 更大，仅按"最大 ID"会选错）。
  链接内部 501：顶层容器 14 为 w2 包裹裸 varint，分类副本 13 为 w0 裸 varint
  （读取须兼容两种 wire）。

- **素材段物理布局**：头部用户资产区（新建资产块按创建序）→ 1825 官方"默认布局"容器
  （14 个 HUD 组：小地图/技能区/摇杆等）→ 分类链容器 1840/1841/1842 → 分类副本子树；
  非乱序，是编辑器结构性行为（新资产块插在 1825 前，追加式非前插式）。
- **插入规则（注入器实现）**：num501 新 ID 与 502 新记录都插到锚点记录 1073741825 之前；
  无锚点回退末尾追加（游戏接受乱序）。候选注入 756 PASS 回读验证（2026-08-22）。
- **只读列表命令（2026-08-22）**：`gsts assets:library-inject --list --gil <file>`；
  容器判定复用注入同款读路径（14 链接=顶层、13 链接=分类副本、504=父容器）。
- **容器 ID = 资产索引 ID（2026-08-22 用户游戏核验确认，最高优先级）**：
  容器记录顶层 `#501`（0x40000000+ 段，如 guide-arrow-right = 1073741883 / 0x4000003B）
  就是该素材的**索引 ID，可被游戏 API 调用、可在节点图引用**；
  素材段共 **8 个用户素材**（用户游戏核验：数量正好 8 个），官方"默认布局"1825 不算用户素材；
  资产类型**全部为图片拼接**（用户核验确认；`#502{12{501}}` 值 19=图片，
  但 20260821 读为 1、20260821_1 读为 10，与"皆图片"不符——该字段是否真为"类型"
  待差分确认，见"未验证"）。
