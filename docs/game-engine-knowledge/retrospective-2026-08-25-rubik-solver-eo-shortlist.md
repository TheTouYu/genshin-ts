## 三、可复用规则

1. **发布 int_list 自定义变量时必须考虑“全 0 短列表”**：当列表可能全 0 时，追加一个调用方约定忽略的尾部哨兵（如 index N 放 1），调用方只读前 N 项。
2. **自动动画与实际玩家手感解耦**：只有自动求解的 executor timer 调大，不动手动转动参数。
3. **根因二分顺序**：先看每秒负载按图分布，再看求解器输入值；不要一看到“不收敛”就怀疑策略表。
