# 镜头系统

> 知识树：已验证结论已录入 `knowledge/game-engine-knowledge/camera-ui-rules.md`（2026-08-08，bnd_7320a9bd）

> 状态：部分已验证
> 来源：用户概念说明 + 真实 GIL 不可变相邻快照与独立 Validator
> 最近校验：2026-08-02
> 适用范围：玩家视角配置、切换和随实体运动的镜头；当前地图/版本的自定义镜头受限编码

3D 游戏通过镜头决定玩家看到世界的位置、方向和视角。游戏引擎提供若干预设镜头，也允许配置自定义镜头。

## 镜头类型

### 预设镜头

引擎提供若干已经配置好的镜头模式。具体数量、名称、默认参数和适用场景需要后续从编辑器中确认。

### 自定义镜头

用户可以配置自定义镜头，以实现预设模式之外的位置、方向和观察效果。

#### GIL 编码（root 18 镜头容器，真实 GIL 确认）

> 来源：component-investigation exp14/exp17（2026-08-05）；既有结论见 gil-structure-semantics.md“自定义镜头”小节

- **root 18** 是镜头容器，每条 `18.1` record 一个镜头：`{1: 自增ID, 2: {1: UTF-8镜头名, ...参数}}`
- 新增镜头 = append 一条 record（ID 自增，当前样本 1073741825/26）；**删除镜头 = 移除对应 record**（exp17 实测：删除"自定义镜头_1"后 208B→83B，其余 root 全部不动）
- 参数示例（默认自定义镜头）：f2=6.0、f3=45、f5=1、f6=6、f14=1、f15=-180、f16=180、f17=-89、f18=89、f37=1；物件镜头类型额外 f4={0.2}/f6=30/f12=10/f21=1/f23=30/f24=30/f32=1/f33={0.15×3}

#### 物件镜头组件绑定（type 13，真实 GIL 确认）

- 元件/实体通过**组件 type 13（物件镜头组件）**绑定镜头：配置 f23.f4 = {f1=镜头槽名（如"物件镜头_1"）, f2=镜头名（如"自定义镜头_1"）, f3="GI_RootNode", f501=1, f502=镜头ID}
- 绑定以**名字+ID 双重引用**（f2 名称 ↔ root18 条目名，f502 ID ↔ root18 条目 ID）
- 移除绑定 = 清空配置（exp16 实测：f23 60B→0B，槽 67B→7B，root18 镜头定义保留）

### 物件镜头

物件镜头挂在某个实体上。实体移动或旋转时，镜头随实体一起运动，从而形成运镜效果。

```text
镜头挂载到实体
→ 实体移动或旋转
→ 镜头跟随实体变化
→ 玩家看到移动中的镜头画面
```

例如，可以让承载镜头的实体左右移动、沿轨迹前进或改变朝向，以实现横移、推进和环绕等效果。

## 按玩家切换镜头

节点图可以为指定玩家切换镜头，而不是必然让所有玩家同时切换。

```text
玩家触发选择或按钮
→ 节点图确定目标玩家
→ 选择预设或自定义镜头
→ 为该玩家切换视角
```

多人模式下，镜头状态应优先视为每个玩家自己的观看状态。是否存在全体玩家统一切换接口，需要另行验证。

## 镜头切换入口

### 选项卡

可以在实体上配置选项卡，例如“俯视”“仰视”。玩家选择后，实体节点图接收事件并执行镜头切换。

### 屏幕 UI

可以配置屏幕按钮或其他控件。玩家按下后，角色收到 UI 事件，节点图再为该玩家切换镜头。

```text
选项卡或 UI 输入
→ 事件进入节点图
→ 判断选择类型
→ 调用镜头切换能力
→ 玩家视角改变
```

## 镜头、实体和 UI 的区别

- **镜头**决定玩家从哪里、以什么方向观察 3D 世界。
- **实体**存在于 3D 世界中，可以承载物件镜头并驱动其运动。
- **屏幕 UI**覆盖在最终画面上，不因镜头切换而变成 3D 对象。
- **铭牌**存在于 3D 世界中，但会面向玩家镜头以保持可读。

## 生命周期

镜头配置需要提前存在，节点图才能在运行时选择和切换。物件镜头依赖其挂载实体已经创建；如果实体尚未创建或已经销毁，镜头如何处理需要专门验证。

切换镜头后是否保留上一个镜头状态、如何恢复默认镜头、玩家死亡或退出时如何重置，也需要逐项确认。

## 当前 GIL 受限观察

当前锁定地图中，两个默认自定义镜头创建样本和一个目标镜头的属性样本由独立 Validator
接受。自定义镜头 identity、名称和“物件镜头”类型切换已观察到受限 raw 结构；“镜头视野
检测”在当前物件镜头中对应一个 fixed32 参数候选。显示值 `45`、`60`、`33.83` 分别观察到
raw `45.0000305`、`60.0`、`33.8265572`，因此 UI 显示值与文件浮点值不能直接视为同一
精度。完整路径和证据边界见 [GIL 整体结构与语义树](gil-structure-semantics.md) 及证据汇总
`camera-semantics.json`；本轮没有 round-trip、写回、编辑器导入或游戏行为验证。
