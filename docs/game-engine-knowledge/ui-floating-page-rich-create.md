## 1. 背景与目标

现状 gsts assets:ui create --type floating-page 只创建**最小骨架**（4~6 条记录：模板+实例+组+关闭按钮），
用 BUILTIN_FP_* hex 模板 remap ID 生成。编辑器做的富版悬浮页（学习资产「底板1-使用」）比骨架多：
**内容素材组引用、形式变量、页签容器、页签(t58 4状态)、页签项、文本/图片内容**。

目标：让 CLI 能生成近似编辑器富版的悬浮交互页，AI/玩家可一步落地大部分结构，细调交给编辑器。
本文给出 wire 差分与命令蓝图；未覆盖部分（页签项内部、返回服务器事件开关）标为待差分。

## 4. 骨架 vs 富版差异（核心差分，3 处内容 + 缺的记录）

骨架版 BUILTIN_FP_TEMPLATE (638B) 与富版 (1003B) **组件结构完全相同**（f505 均为
[15,42,23,12,40,41,44]）。差异：

| # | 位置 | 骨架版 | 富版 | 需要的改动 |
| --- | --- | --- | --- | --- |
| ① | t42.f503.f36.f501 | [1073741847]（仅固有组） | [1990,1992,1995,1998,2001,2004,2007]（7 个） | 追加内容素材组 ID 到 packed 列表 |
| ② | t41.f503.f34.f501 | 无条目 | {类型=2, 名="页签1", 序号=1} | 添加形式变量条目 |
| ③ | t44.f503.f35 | {f502:330001} | {f501:1, f502:330002} | t44 配置改写（语义待差分） |

以及**记录级**：CLI 需要额外创建：
- 内容页素材组 ×N（type6, f504=模板ID，带 f505[12]+[25]/[38]）
- 页签容器（f505[11/43]）+ 页签子记录（t58 4 状态 + 46/47/48/49）+ tips + 关闭按钮 + 图片
- 状态素材组容器 ×4（默认/悬浮/按下/选中，type55 + 官方图片子记录）

## 5. 命令设计（建议）

### 5.1 扩展 create --type floating-page

```
gsts assets:ui create --type floating-page --id <模板ID> [--name <n>]
    [--pages <n>]                # 内容页数（默认 1，创建 N 个内容素材组并挂 t42）
    [--tab <页签名+素材组ID>]      # 追加页签容器（可重复）
    [--variable <名:类型>]        # 追加形式变量（类型: int|float|str|text）
    [--tab-states <默认,悬浮,按下,选中素材组ID>]
    [--button-states <默认,悬浮,按下,禁用素材组ID>]
```

真实 ID 派生：模板=--id；实例=模板-3；组=模板-2；关闭按钮=模板-1（已有）。
新增内容页/页签/状态素材组 ID 建议从模板-10 起向下递减分配（连续区间，避免碰撞，需与既有分配核对）。

### 5.2 新子命令 states --set（P0-2）

```
gsts assets:ui states --id <控件/素材组ID> --set <状态名,素材组ID> [--kind button|tab] [--write]
    # 写 t50（按钮）/t58（页签）对应状态块的 f4 = 素材组 ID
```

### 5.3 新子命令（P1-3 素材组/图元）

```
gsts assets:ui asset-group create --parent <素材容器ID> --type text|image --id <ID>
gsts assets:ui asset-group update <ID> [--content <text>] [--asset <图片素材ID>]
    [--position x,y] [--size w,h] [--font-color <hex>] [--font-size <n>]
```

## 6. 实现蓝图（函数级）

```
gil_ui.ts:
  buildFloatingPageRich(bytes, { id, pages, tabs, variables, tabStates, buttonStates })
    先复用 createFloatingPage 的骨架生成（BUILTIN_FP_* remap）
    ├── appendT42ContentIds(tmpl, pageGroupIds[])   # 改 f505[42].f503.f36.f501 packed
    ├── addFormVariable(tmpl, {name, type})          # 造/改 f505[41].f503.f34 条目
    └── setT44Config(tmpl, flags)                    # 改 f505[44].f503.f35 (330001→330002)
    创建内容页素材组记录（复用素材组结构模板）
    创建页签容器 + 页签（硬编码模板，需编辑器样本）  ← 阻塞项（见第 7 节）
    创建状态素材组容器 ×4（复用 library-inject 的容器结构）
    返回 { bytes, templateId, instanceId, groupIds, pageGroupIds, tabId, ... }

assets_ui.ts: 接线 create --type floating-page 扩展参数 + states --set + asset-group create/update
```

关键实现注意：
- t42 packed 列表追加要保留现有条目（骨架已有 1 个固有组 ID），不能覆盖。
- t41 条目结构：条目消息里 f501=类型码、f502=名字、f503=序号——与 variables list 解析一致。
- t44 改写是**字节级**（现有 BUILTIN_FP_* 含 max-uint64，禁止 parse→emit 往返，必须 remap 或定点替换）。
- 所有新增记录须同步：root9 f501 模板目录（若为模板）、记录 f503 成员列表、模板侧实例回指。

## 7. 阻塞项 / 待差分（实现前需编辑器最小差分或样本提取）

1. **页签容器/页签/关闭按钮记录的空白模板**：现有骨架 hex 不含这些；需要从富版这些记录提取可 remap 的 hex 模板
   （仿照 BUILTIN_FP_*：提取 2007/2008/2021 原始字节 → 泛化 hex 模板 → varint remap）。
2. **t44 f502=330001 vs 330002 语义**：330002=富版（有内容/变量）推断，未验证；可能表示变量数或页面类型。
3. **页签项 subtype 47 内部 ~180B 结构**：页签项列表每条结构未闭合（含返回服务器事件开关？）。
4. **图元 f505[12] 富版 f502=14 vs 普通素材 f502=12**：载体内部差异待核对。
5. **游戏核验**：富版悬浮页在游戏内显示/切页/数据更新未验证。

## 8. 验收标准（实现后）

1. 候选回读：新生成模板 t42 含全部内容组 ID、t41 含全部变量、t44 到位。
2. assets:ui list / variables list / states 能读出新生成内容（与编辑器建的一致）。
3. 编辑器加载地图可见富版悬浮页结构（页签/内容/状态）。
4. 游戏内：按钮唤出 → 页签可切 → 数据可更新（verify-injection 或用户核验）。
