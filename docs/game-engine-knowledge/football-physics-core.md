# 足球物理核心（第一阶段 headless 引擎）工程规则

> 状态：当前实现
> 来源：`examples/football/sim/` 当前代码 + 自动回归（`npm run football:sim`，2026-08-31 总判定 PASS 31/0/1）；**未做游戏内核验**（游戏内节点图移植属第二阶段）。
> 适用范围：`examples/football/sim/`（确定性物理核心）及其后续维护/第二阶段节点图移植。
> 关联文档：`examples/football/sim/README.md`、`examples/football/sim/reports/verification-report.md`。

## 1. 数值积分选型（铁证：A1 误差 1.7e-14 / A2 漂移 1.8e-13）

- **半隐式 Euler 不满足 0.1% 级能量守恒**：纯重力下每步能量损失 ½g²·dt²，10s 累计 ≈2%（A2 无法达标）。RK4 对常加速度段（真空弹道）在网格点上**精确**，是解析解对齐类验收的唯一稳妥选择。
- **自旋衰减不用数值积分**：ω *= 2^(−h/T½) 精确指数因子，B2 半衰期实测 3.5000s 整。
- **安全阀与解析用例的冲突**：规范"速度阀 50 m/s"与"真空 10s 自由飞"（末速可达 85 m/s）互斥——A2 类用例必须选不触发阀值的工况（v0=49 上抛），或测试参数放宽阀值并在输入列声明。

## 2. 接触解算（铁证：A4 回高 ±0.001%、C6 反射比 0.7200 精确、穿透 1.37mm）

- **反弹能量守恒必须 TOI**：子步末端检测-反射会让反弹速度多算 g·δt（apex 偏 1.3%）；地面/墙平面用闭式分数回滚到接触时刻，胶囊（门柱/横梁）用 24 次二分 TOI。
- **CCD 子步界的几何论证**：单子步位移 ≤ 0.25r（27.5mm）< 最小合并半径 170mm（门柱 0.06+球 0.11）→ 几何上不可能穿透，无需全场景 TOI。
- **支撑（support）只杀速度不还原位置会积累下坠**：持续接触每子步重力下坠 ½gh²；皮肤区内"悬停"球会缓慢下沉并从上方穿越接触面，制造**幽灵 TOI 假弹跳**（jn≈0.03 的 BOUNCING）。修法：持续接触且 |vn|<ε_bounce 时把球心投影回 d=r（位置钉回）。
- **薄壁球壳接触冲量常数**：切向停滑冲量 P = −0.4·m·v_slip（Δv_contact = 2.5·P/m，因 I=⅔mr²）；摩擦同时改 v 与 ω（τ = r_c×P），这是碰撞改变自旋（C6）的机制。
- **区域门平面（球网）必须防背侧进入**：从平面后方进入生效区域的球（网上方飞过落网后）会被当成巨穿透猛推。修法：区域门平面仅当子步起点在有效侧（s0 ≥ −r）才参与接触。

## 3. 角速度安全阀与纯滚（铁证：A5 滑移 2.9e-3、B3 停距带内）

- **滚动旋量不由安全阀管**：8 m/s 纯滚需 ω=72.7 rad/s > 70 阀值；直接钳 ω 会制造假滑移→假滑动摩擦→假马格努斯力（ω 被破坏后 k(ω×v) 完全失真，实测曾把 25 m/s 射门压成 0.5m 侧偏）。修法：贴地且 |v_slip|<ε_lo（真纯滚）时只钳自由旋量（ω−ω_roll）；否则全向量均匀缩放。
- **滚动态自旋衰减只作用于法向分量**：滚动分量由纯滚约束 ω_t=(n̂×v)/r 锁定（每子步重锁），否则 ω 独立衰减破坏 A5 纯滚一致性。
- 滚动阻力（a_roll）无力矩、只减速 v；阻力（drag）与 a_roll 同时生效——B3 停距 22.9m = 解析解 (1/2c)ln(1+c·v²/…) 与 a_roll 的复合，调参数时要算两笔账。

## 4. 状态机与休眠（铁证：C1/C4/C5）

- **BOUNCING 构造性 ≤1 tick**：接触冲量置 Bouncing 标记，tick 末分类立即分流（法向分离 > ε_bounce → AIRBORNE，否则按滑速分滚/滑）；遥测 impact tick 显示 BOUNCING、转换记录 from→BOUNCING→resolved 两次。
- **REST 冻结的三个守卫**：①嵌入地面（pen > contactSkin）不得休眠（C7 必须先推出）；②休眠球仍要标记 groundedContact（否则带球走近自动控球判定失效——真实踩坑）；③唤醒只经外部冲量 API（applyImpulse 清 restTicks）。
- **出生分类**：静止出生+贴地+坡度可静 Hold → 直接 REST（C4 零转换要求的来源）。
- **滞回带防振荡**：SLIDING⇄ROLLING 用 ε_lo/ε_hi（0.1/0.5）；C5 审计法=滑动 1s 窗口统计同对转换次数（阈值 10 Hz）。

## 5. 确定性与回放（铁证：D1/D2 哈希逐位一致）

- 核心禁读时钟/Date/performance、禁 Math.random；随机只用固定种子 PRNG（mulberry32，状态入快照）。
- 遥测"步后递增再记录"：records[k].tick===k、records[k]=t=k·dt 时刻状态——闭式解对比索引才不会错位一格（真实踩坑：出生无初始记录导致 A1 全部偏 1 tick）。
- 快照必须含：球/球员全量、tick、time、**累加器余数**、RNG 状态、**运行哈希态**（BigInt 序列化 hex）、事件游标。
- 轨迹哈希逐 tick 覆盖（tick/状态/pos/quat/v/ω/力位掩码→Float64 位模式→FNV-1a64）；帧循环用外部供给的 frameDt（累加器钳制 ≤0.25s）。

## 6. 验收工程

- 用例三要素缺一不可：**复现命令 + 输入参数 + 实测数字**（禁止"通过"二字）；观察项（B5 电梯球）单列 OBSERVED 不判分。
- 数值标定瞄准点要含阻力补偿：30 m/s 打 10m 外门柱，气动阻力使弹道偏差 ~0.2m > 合并半径 0.17m——网格搜索补偿瞄准点后才稳定命中。
- 参数默认值进带策略：先解析预校准（e²·2m、v²/2a_roll、k⇔Cl 换算），再用实测微调落带中（草地 e=0.70：无阻力 0.98m、含阻力 0.94m ∈ [0.9,1.3]）。

## 7. 第二阶段（游戏内节点图移植）注意

- 游戏内图 X=纵深 ↔ sim Z=前（绕 Y 旋转 90°）；自旋分量同步换轴。
