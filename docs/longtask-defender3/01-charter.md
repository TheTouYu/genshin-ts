## 三、边界（已拍板，不再改主意）

1. **真 3D**：千星 3D 场景 + 真实角色/城墙/怪物建模；不用 2D 精灵冒充 3D。
2. **素材自造**：用千星/原神官方资产与自制素材，**不搬运原作美术**（原作只作设计参考）。
3. **玩家主导成长**：数值/反馈/节奏交给玩家决策（每波三选一），不做全自动成长。
4. **瞄准用射线检测**：玩家准星 → 射线 → 命中点；箭矢飞向命中点。
5. **不做**：实时 PvP（千星无此能力）、内购（改游戏内货币）、原作素材直搬。
