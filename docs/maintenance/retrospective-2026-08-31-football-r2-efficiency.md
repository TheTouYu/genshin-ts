## 二、系统性根因（3 类）

1. **已有知识没被用上**（#1 #4 #5 #6，占 18 次）：知识存在于技能/源码/上一轮 PROGRESS，但触发链路断了——技能触发描述不覆盖该场景、提示词只提名词、无检索兜底。**修法 = 触发面扩张 + 命令级速查 + PKC 检索兜底 + 工具固化**（不是"下次小心"）。
2. **编辑纪律缺失**（#2 #3，占 10 次）：同文件并行编辑 = 最后写者胜（还会静默丢改动）；old_string 凭记忆写必错缩进。**修法 = 纪律规则：同文件多编辑必须串行；old_string 一律从 grep/view 输出逐字节复制，缩进不确定先 `grep -n` 看原文**。
3. **命名预检缺失**（#7）：复合 build 函数里的局部 const 共享文件级作用域检查。**修法 = 新增局部 const 前先 grep 同文件同名**（已进 dsl 技能信号工作流第 4 点）。
