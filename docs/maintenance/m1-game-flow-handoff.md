## 一、流程本体（用户原话，seq=6641，逐字）

> 现在扩展一件事情，我们开发游戏的流程：在打开游戏编辑器之后，选择/创建游戏项目，加载,等待千星沙箱启动，打开沙箱的日志，勾选需要打开的日志模块+日志负载记录，试玩，可变流程：[执行需要测试的游戏内容]，结束试玩，查看日志，反馈，优化/开发游戏
> 可以看到这一个流程里面，我们已经覆盖大部分，现在我们来补上这一个迭代伦次的剩下部分。

**拆成 10 步**：① 打开编辑器 → ② 选择/创建项目 → ③ 加载 → ④ 等沙箱启动 → ⑤ 开沙箱日志窗 → ⑥ 勾选日志模块 + 负载记录 → ⑦ 试玩 → ⑧〔可变〕执行测试内容 → ⑨ 结束试玩 → ⑩ 看日志 → 反馈 → 优化。
