## 45-锚点

## 锚点
分辨率自适应的核心机制 | 控件与屏幕边缘的相对位置保持

### 一、锚点的定义
当分辨率变化时，控件会自适应位置，
与设置的锚点保持相对位置不变。
例：16:9 切换到 21:9 后，锚点决定控件跟随哪个屏幕边缘。
九宫格锚点系统

### 二、锚点选择建议

### 按控件位置选择：
九宫格中主体位于哪部分，就选择对应位置的锚点

### 按功能区选择：
同一功能区（如多条任务文本框）锚点应保持一致

### 三、九宫格锚点示意

### 四、拉伸锚点
锚点类型扩展，使UI元素可根据背景或容器的大小变化进行拉伸适配。
适用于需要随容器自适应缩放的控件场景。
拉伸适配

### 五、跟随固有控件
原有锚点无法与固有控件（如技能区）在不同屏幕宽度下对齐。
选取跟随对象后，屏幕大小变化时控件即可与固有控件保持对齐。
解决对齐偏移
