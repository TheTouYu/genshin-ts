## 70-白盒物件

## 白盒物件
验证关卡设计的基础几何体集合，用于空间验证与设计原型搭建

### 一、什么是白盒物件
用于验证关卡设计的基础几何体集合
提供多种标准形状和材质显示模式，支持在编辑阶段进行空间验证和设计原型搭建。
可正常当做一个模型资产使用，支持以下操作：
缩放
换色
换材质
挂载逻辑组件
挂载节点图

### 二、编辑入口
实体编辑页签 → 预制
›
动态单位 → 其他
›
将白盒物件拖入场景即可使用

### 三、白盒物件类型
支持以下 11 种标准白盒几何体
长方体
球体
平面
三棱柱
五棱柱
三棱锥
五棱锥
圆柱
圆锥
线框长方体（常用于区域标注）
线框圆柱（常用于区域标注）

### 四、额外说明
网格线：编辑视图中每个网格的长度为标准 1 米，可用于快速估算尺寸。
注意：线框长方体、线框圆柱体无法更换材质。

## 73-操控运动器

## 操控运动器
通过轮盘输入操控元件/实体移动的载具类组件

### 一、功能与使用须知
运行时通过轮盘输入操控元件/实体移动、施放技能（载具核心组件）
操控运动器和其他类型的运动器互斥，一个实体只能使用一种。
推荐操控实体缩放为等比（如 1:1:1），不等比可能导致斜坡运动形变。
复杂操控实体推荐用等比空模型主物件 + 装饰物修改缩放的形式制作。

### 二、基础设置
实体接地位置
定义运行时操控实体与
地面接触的位置。
角色退出点
操控者离开时的弹出挂接点。
操控实体碰撞
运行时以操控实体碰撞为准，
原生碰撞和额外碰撞均不生效。
默认实体碰撞仅支持胶囊体，
半径参与物理碰撞，高度判浮空。
装饰物运动表现
定义哪些装饰物部件可以有
运动动画表现（如车轮滚动）。
原理：对引用的挂接点进行旋转，
使其下的装饰物呈现运动表现。
推荐碰撞区形状使用胶囊体或球体，位置设在模型上半部分，避免碰撞异常；碰撞不可低于接地位置，否则与地面挤压导致表现异常。

### 三、运动设置
操控输入 & 运动区域
方向输入类型：镜头朝向（始终朝镜头移动）/ 操控实体朝向（以自身模型正朝向移动）
输入前进区范围：轮盘正前方为 0°，落在此区域内向前移动，反之向后；电脑端 W 键为 0°
运动坡度上限 / 跟随斜坡倾斜：决定可爬坡角度，以及倾斜表面上是否有相符的倾斜表现
运动参数
说明
转向速度
实体按 Y 轴旋转的速度
前进加速度 / 最大前进速度
前进区输入提供的加速度与速度上限
区分前进后退速度
开启后可单独配置后退加速度与最大后退速度
阻力减速度 / 减速系数
基础阻力 + 减速系数×速度²；影响实际速度与减速时长
最大速度预览
综合加速度与阻力计算出的最终最大速度
注意：角色处于操控状态下时，无法使用普通角色技能，仅可使用「角色操控技能」；阻力系数配置过大可能导致最大速度不为 0 却无法移动。

## 74-角色操控技能

## 角色操控技能
操控状态下才可使用的特殊角色技能

### 一、定义与特性
操控状态下才可使用，配置方式类似角色技能，但释放期间角色无技能动画表现
仍属于角色技能子类，释放主体为角色，添加/移除方式与角色技能完全相同。
自定义槽位时长
可自由定义单个槽位的具体时间
触发客户端节点图
节点图事件轨道打点触发
复用角色技能功能
可用节点图节点、单位状态、槽位

### 二、编辑入口与技能类型
战斗预设页签 → 技能页签 → 添加角色操控技能 → 设置名称/所属页签/预览对象 → 确认创建
瞬发技能
无动画槽位，接受输入的
瞬间立即触发逻辑
普通技能
基础技能类型，含一个可填
自定义时长的操控状态空动画
长按技能
提供长按槽位，按长按时间
进行不同分支响应

### 三、技能关键参数
参数
说明
配置ID
技能唯一标识，节点图修改技能配置时引用
技能属性组
仅支持通过属性组调整冷却时间倍率
生命周期管理
可配置次数上限，达上限后技能自动移除
技能预瞄准
瞬发/普通技能类型支持配置技能预瞄准

### 四、动画编辑（事件轨道）
角色操控技能本身不关联动画，仅含可填自定义时长的操控状态空动画槽位
1
开始事件轨道：技能开始释放时立即触发的时点
2
结束事件轨道：技能动作全部播放完成后触发的时点
3
节点图事件轨道：按进度打点，仅支持添加「角色操控技能节点图」，支持配置循环节
长按技能含长按状态与长按结束两个空动画，按松开时机落在分支轨道的响应段落转入对应分支；预览对象可选择挂载操控运动器组件的元件。
