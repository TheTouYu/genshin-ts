# 角色编辑界面（技能/投射物/道具/特效器）


## 31-技能

## 技能
综合指南：定义、类型、参数、动画编辑、槽位、资源、变量、属性组、关键行为

### 一、技能的定义
技能是通过接收游玩时的用户输入，让角色执行某一段预设行为的封装。
经典模式中，角色的普通攻击、元素战技、元素爆发等都是一个技能。
技能主要实现三个基本功能：
角色动画调用：定义技能释放后的角色动画演出效果
触发客户端节点图：通过节点图事件轨道触发指定客户端节点图
配置技能状态：在动画播放过程中特定时间窗口附加持续性逻辑

### 二、技能类型
配置ID：技能的唯一标识，在节点图修改对应技能配置时引用该ID
技能类型分为以下五种：
瞬发技能：无法编辑动画，在接受输入的瞬间立即触发逻辑
普通技能：基础技能类型，支持完整时间轴配置
长按技能：支持引用循环动画，玩家长按输入维持循环播放
连段技能：配置一连串连续动作，接受特定时点输入后在动作间跳转
瞄准技能：提供成套瞄准动作，施放时使角色进入瞄准状态
编辑入口：战斗预设页签 > 技能页签 > 新建技能

### 三、技能参数
基础设置 / 数值配置 / 生命周期 / 连段配置 / 瞄准配置
基础设置
启用运动坠崖保护：勾选时，角色位移不会触发坠崖
是否可在空中释放：跳跃/下落/滑翔等空中状态时能否使用
技能备注：编辑时描述技能的大致作用
数值配置
冷却时间(s)：可开关；释放后需等待多久才能再次释放
使用次数：默认可使用次数，归零后不可用；每过一个冷却时间恢复一次，最大恢复至默认值
技能消耗：开启后配置消耗类型（技能资源）和消耗量
索敌范围：圆柱体（半径+高度）/ 扇形（半径+高度+角度+旋转）
生命周期管理
达到次数上限是否销毁技能：开启后配置次数上限，达到上限后技能自动移除
连段配置（连段技能专有）
是否开启蓄力分支：开启后可在动画编辑处定义连段转入蓄力动作逻辑
蓄力公共前摇：开启后连段与蓄力动画共用前摇槽位；关闭后槽位不播放
瞄准配置（瞄准技能专有）
瞄准进入方式：长按（按住进入松开退出）/ 点按切换（点击切换）
瞄准中是否可移动：瞄准模式下角色是否可位移
瞄准发射动画时长：切换为自定义后可修改发射动画播放时长（运行时生效，预览不生效）
索敌范围说明
可在本地节点图中通过查询节点获取本次技能释放的目标单位

### 四、技能的动画编辑
普通技能（基础类型）
以时间轴形式配置，分为动作轴和逻辑轴。动画总长度决定事件轴总时长，按时间依次触发。
四种事件轨道
开始事件轨道：技能释放时立即触发的时点
结束事件轨道：动作全部播放完成后触发的时点
节点图事件轨道：按动画进度打点并添加事件，触发技能节点图
状态轨道：定义非触发类表现（如持续播放特效），自由配置起止时点
节点图事件轨道有极小概率跳过事件，关键逻辑应写在结束事件轨道作为兜底
瞬发技能
不可添加动作，只保留开始事件轨道，逻辑在技能释放瞬间触发
长按技能
支持引用循环动画，可调整循环持续时长。保持长按时循环持续播放至持续时长，松开后根据分支轨道跳转
连段技能
配置多个独立动作，通过连段轨道定义跳转规则和输入窗口实现连招效果
连段轨道：预输入阶段（点按接受输入，长按蓄力跳转）/ 响应阶段（点按立即跳转）
公共前摇：从待机短按技能初次进入连段时，或长按进入蓄力时，优先播放公共前摇动作
瞄准技能
三个动画槽位成套配置，不支持分别配置。蓄力动作到达持续时长后保持在最后时刻，待解除瞄准后转入分支
进入瞄准状态事件：配置镜头视野/视角偏移/俯仰角度范围/进入和退出过渡时长
开启准星事件：无可配置参数，开启后显示准星
分支轨道：长按技能和瞄准技能支持分支，可配置多个段落，每个段落对应一个跳转分支

### 六、技能资源
释放技能时需要扣除的资源
技能资源是特定技能释放时需要扣除的资源，如经典模式的元素能量。奇匠可自定义资源类型。
编辑入口
系统菜单栏 > 技能资源管理按钮，打开界面即可编辑全局可用的技能资源类型
参数介绍
技能资源名：技能资源的命名
配置ID：唯一标识，节点图调用时依赖该ID
可获取最大值：技能资源量的上限，角色获取量无法超过该值
引用信息：显示该技能资源被哪些技能引用
增长类型（三种）
无条件增长：超过可获取最大值时无条件增长
跟随技能（保留值）：仅当玩家有需要该资源的技能时才可改变，无对应技能时保留当前值
跟随技能（不保留值）：规则同上，但无对应技能时清零

### 七、技能动画
角色技能动画 vs 造物技能动画
角色技能动画
必须依赖角色实体，每个动画必须有明确角色做载体
播放依赖自定义技能的释放
按技能使用特色分三类：
普通攻击
持续引导
位移
在技能编辑中引用角色技能动画，定义动画演出效果
引用方式见技能文档（mho81frl33im）
造物技能动画
必须依赖造物实体，每个动画必须有明确造物做载体
播放依赖自定义技能的释放
按技能使用特色分两类：
普通
持续
在技能编辑中引用造物技能动画，定义动画演出效果
引用编辑方式见技能文档（mho81frl33im）

### 八、技能变量
持久化记录在玩家身上的客户端值
技能变量是一类持久化记录在玩家身上的值，与自定义变量相似但有区别：
客户端值，可被客户端节点直接修改，修改立即生效，时效性优于自定义变量
默认浮点数类型（暂时不支持其他类型）
用途：实现同一技能内异步查询，或跨技能信息传递
编辑入口
系统菜单 > 技能变量管理 > 新增变量
参数
变量名：技能变量的命名
配置ID：唯一标识，节点图调用时依赖该ID

### 九、技能属性组
动态修改技能行为
技能属性组可被技能关联，通过修改属性组的值来动态修改技能的部分行为
编辑入口
系统菜单 > 技能资源管理 > 技能属性组页签
属性组命名：属性组配置的名称
配置ID：唯一标识，外部系统调用时依赖
属性类型（两种）
动画速度倍率：在基础动画速度上叠加额外变化值，节点图触发时机也受影响
冷却时间倍率：在基础冷却时间上叠加额外变化值
计算公式
最终动画速度 = 技能属性组初始值 + (单位状态修改值 x 层数) + 技能轨道修改值
最终技能冷却 = 原始技能冷却 x (技能属性组初始值 + (单位状态修改值 x 层数))
三种修改方式
技能配置引用：在技能编辑中关联预先配置的属性组，初始值为全局默认值
单位状态修改：通过单位状态的调整施法速度/冷却缩减运行时动态修改
技能轨道修改：动画编辑的状态轨道添加"调整动画速度"事件，只支持固定参数
动画速度倍率通过技能轨道修改只支持固定参数，通常用于优化动画表现

### 十、关键行为
纯客户端指令序列
关键行为是纯客户端的数据，在技能施放过程中通过节点图定义并记录
系统将记录的关键行为列表和触发时的客户端时间保存在关键行为记录板内
可视为简化的指令序列，用于实现有时效性需求的技能连段或组合技能
基础概念
关键行为ID：关键行为的唯一标识，节点图调用时依赖该ID
客户端时间：添加关键行为时记录在客户端的时间戳
节点图操作
添加关键行为 / 清空关键行为记录板 / 获取当前关键行为 / 获取当前关键行为（高精度）
客户端时间受浮点数精度影响，需要更高精度时推荐使用高精度版本节点
