# 地形编辑与环境配置


## 02-地形编辑

## 地形编辑
关卡场景地形搭建的完整操作指南

### 一、入口与基础概念
入口位置：顶部页签栏第一个按钮
初始创生：创建存档时自动生成 100×100 地形（位于世界坐标 0,0,0）
最小操作单位：单层地块 5×5，层高 2.5

### 二、主界面组成
资产栏（左侧上方按钮开关）
地块材质
环境配置
自定义元件
预制元件
资产库
地块材质点击后进入自由编辑模式
自定义/预制元件点击后直接创建
详情栏（右侧上方按钮开关）
地形列表功能：
- 修改名称（双击名称开启）
- 聚焦（镜头定位至地形）
- 创建地形（进入地形创建流程）
地形详情（选中地形后出现）
修改地形位置（X/Y/Z）
修改地形旋转（Y值）
地块材质替换/清除
多选时地形详情不可用

笔刷模式与功能

删除：降低 x 层

地形生成逻辑：所有相连的地块形成一块地形，不相连地块会创建为多个地形。

处于任意编辑模式或地块操作模式中可用

## 03-环境配置

## 环境配置
天空盒、滤镜、光源与天气的综合配置

### 一、定义与入口
环境配置：对关卡的天空盒、滤镜、光源、天气等进行设置的预制资源，需预先定义并应用于玩家客户端。
入口：地形编辑页签 → 左侧环境配置 → 新建环境 → 确认创建

### 五、天气
一份环境配置下可设置多份天气配置，随环境配置一同启用
天气类型：雾 — 支持距离雾（远处模型被雾遮挡）和高度雾（按场景高度遮挡）

### 七、环境时间
关卡设置中可定义起始时间点和时间流逝速度，也可通过节点调整。
环境时间是全局唯一的运行值，仅有勾选「随时间自动切换」的环境配置生效时才可见时间变化效果。
