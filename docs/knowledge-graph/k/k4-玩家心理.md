## 一、这是什么（定义与官方命名）

- **本轴的口语名就是「玩家心理」，官方目录没有对应分类**——它是 `docs/knowledge-graph/MAP.md` 从 21 万字语料里用 ⊕ 维度长出来的 K 轴（`MAP.md`：K4 = 16 条 / 8 源）。

## 三、规则与做法（主体）

### A. 第一分钟：玩家跳出后不会回来

- **开局必须自带「一次性窗口」意识：玩家一旦退出就不会再给第二次机会，跳出脚本就是差评脚本。**
  - 出处：`BV19ab76LE6c` `[00:22:30]` "一旦退出来就不会给你第二次起飞就直接给你打差评"
  - 证据等级：经验共识（讲师具名案例 + 现场复盘）
  - 怎么做：把"开局 60 秒内玩家要完成什么"写进测试用例第一条；测试者第一遍玩的**直观感受**（哪里好/哪里不好/哪里 UI 该更明显）与 bug 同级对待——`[00:03:09]` "最好还要测试一下你测试者第一遍玩然后你直观感受"
- **与本体不一致的视觉语言 = 玩家的第一道墙；沿用原神已有符号可省掉整段教学。**
  - 出处：`BV19ab76LE6c` `[00:22:30]` "千金奇遇右上角的一开始的UI不是长这样子的一开始UI你根本不知道它是啥……后来有一次他更改了……抽卡的这个是个原石的形状然后一开始他不是原石的形状"
  - 证据等级：经验共识（官方改版前后对照，可复现观察）
- **引导的四条硬标准（按讲师口径逐条落地）**：① 简洁 ② 不强制 ③ 手把手但不笨拙 ④ 潜移默化的代入感。
  - 出处：`BV19ab76LE6c` `[00:32:30]` "我想把引导做的优秀呢那应该怎么做我们这里这次给出四个参考标准第一个叫做以简洁"；`[00:43:13]` "在保证你做抢清楚之后再强制显得不变得很简洁变得不强制"
  - 证据等级：经验共识
  - 正例（可直接照抄结构）：`[00:38:36]` 手机端首操引导"一小段过程告诉你手机到底能干什么……会给你一种轻盈的感觉……这就是一种非强制性的UI引导"；`[00:37:51]` 原神开局派蒙→神像→温迪→安柏的连续代入，"玩家不会觉得枯燥"。
- **别让玩家读到疲劳：信息按「一句话一屏」切分，长文本会直接把玩家推到"算了"。**
  - 出处：`BV19ab76LE6c` `[00:40:53]` "他每句话的人物说话并不长那甚至有的时候他甚至不会到20个字……但如果你一下跳出来100个字的话嗯玩家就会觉得很疲惫"
  - 证据等级：经验共识
- **文案要给出「下一步动作」而不是状态描述**——"还有事没做完"被玩家读成死档。
  - 出处：`BV19ab76LE6c` `[00:42:26]` "还有事没做完这句话那玩家会觉得有什么事没做完我不知道啊然后后面加上一个括号来告诉玩家进行什么样的操作然后就哦改改了"
  - 证据等级：经验共识（作者按测试反馈改了文案）

### B. 上手成本 = 玩家用脚投票的第一变量（有数据）

- **上手门槛低 + 不需要读规则 = 数据上明确的第一名。**
  - 出处：`BV1JCY36EEax` `[00:19:16]` "人人来了都可以玩啊就是上手非常简单门槛非常的低你不需要去学什么规则太多规则也可以玩"；`[00:17:44]` 休闲益智"综合创作排名第一名……前八名的休闲意志奇遇的平均率是95.1总热度是71.1万"
  - 对照组：桌游类"好评推荐率……平均值到78"（`[00:05:23]`）——口碑差距 17 个百分点。
  - 证据等级：**实测**（基于官方热度榜 1.5 万热度以上热门奇遇统计："上了1.5万热度以上热门奇遇的是39个啊平均推荐率是93"`[00:18:30]`）
- **"先跑起来再讲规则"是可复制的零成本做法：能试错的机关就别写教程，让玩家撞一次墙就懂。**
  - 出处：`BV18Ken6bEwT` `[00:01:31]` "大部分玩家都不需要学任何的一个新手教程甚至是引导甚至是文字教程啊都不需要啊你只要上去跑就行了如果有些机关比较特殊大不了加一个小提示甚至你让玩家去试错啊就可以了比如说掉下去会摔死"
  - 证据等级：实测（跑酷/观景类的实际数据表现支撑）
- **玩家会到处逛：出生点朝向、空气墙、远景都是"第一分钟"的一部分。**
  - 出处：`BV1Uq6vBLEJP` `[00:08:27]` "你不考虑玩家会到处逛一下吗你为什么要让玩家能够跳下去跳下去很好玩吗"；同段给出修法——"你复活之后你这个预设点的这个转向啊要朝向风景啊不要朝向这个空气啊"
  - 证据等级：实测（讲师实机逐个作品点评）
- **准备阶段没有时限 = 一个人就能卡死全场：玩家在门外挂机，其他人永远开不了赛。**
  - 出处：`BV1Uq6vBLEJP` `[00:03:04]` "这个游戏的准备练习场居然没有时间限制……这个倒计时是停的……我已经准备好了然后另一个同学一直不过来准备啊然后这个倒计时不走等了他4分钟"
  - 证据等级：实测
  - 修法（同源，K3/K4 交叉）：倒计时归零即强制准备并开始——与 `BV1K4tH6GE4k` `[00:15:38]` "在规定时间内如果没有准备的玩家就强行让他准备然后呢并开始游戏" 互为印证。
- **新手流程必须做「封路」，否则玩家会在教学里把资源花光。**
  - 出处：`BV1Uq6vBLEJP` `[00:06:09]` "你这个新手教程甚至没有考虑限制一下这个睡眠的这个不允许……有玩家不小心没有按教程走走去其他地方点了一下花钱点了一下这个选项卡也没有任何的阻挡或者阻止他不让点"，后果"任务都做不了了"
  - 证据等级：实测

### C. 时间成本：长流程天然吃亏（两个独立源同结论）

- **玩家时间是有限的稀缺资源；流程长度直接换算成打开率。**
  - 出处：`BV1JCY36EEax` `[00:09:58]` "玩家的时间也有限每天有这么多东西可以玩啊专门在千星奇遇里面玩一个流程很长的奇遇就需要你做的更加顶尖啊"；`[00:10:45]` 结论"长流程的话你很容易被玩家抓到你这个流程里面的其余有一些bug啊或者问题"
  - 证据等级：实测（`[00:09:11]` 具名数据：某战术策略作品自己"玩了67分钟只玩到序章"，热门评论"一个小时几10分钟"）
  - 平台结论（同源）："如果是那种时间比较长的话是一定会影响它的热度的玩家一看这种类型要玩很久了他又没这个碎片时间去玩他就不打开了或者就进去看两下就走了啊"
- **玩家原声独立印证同一件事**（不同证据体系，可并列引用）
  - 出处：`COMMENTS-INSIGHTS.md:13`（451 赞）"千星的游戏玩起来都很不舒服，就像在玩十多年前的山寨机……**玩家时间是有限的，觉得不好玩自然不会去玩**"
  - 证据等级：玩家共识（非 learn/ 语料，来自 `search/comments.json` 826 条评论挖掘）
- **反例留档：长流程做到极致仍有天花板级回报，不要一概劝退。**
  - 出处：`BV1NWYE6LEDz` `[00:13:58]` "有些人玩了九个小时八个小时两个小时前前排都是玩了几个小时还有16个小时"／"他能做到3.1万累计8.1万已经非常优秀了"
  - 证据等级：**实测**（作者给出的累计热度数值）
  - 分歧登记：`BV1JCY36EEax`（长流程吃亏）vs `BV1NWYE6LEDz`（长流程有天花板回报）——结论不矛盾但适用条件不同：**单局长 vs 累计长**。单局 60+ 分钟的探索解谜"玩几分钟还是在第一关啊还是在新手教学就不想玩了"（`BV1NWYE6LEDz` `[00:04:41]`，经验共识）；累计 8~16 小时的生存建造则出现玩到半夜的样本。
- **生存系的长是品类定义本身，不是设计失误；叠加建造只会更长、受众更小。**
  - 出处：`BV1NWYE6LEDz` `[00:11:39]` "毕竟涉及到生存就是说你要长时间的活下来他就注定了它的流程偏长"
  - 证据等级：经验共识

### D. 输赢与失败：负反馈是 PVP 的固有税

- **PVP 最大劣势之一 = 失败的负反馈，且任何匹配机制都躲不掉。**
  - 出处：`BV1ehYGzxEJe` `[P8 00:10:56]` "那PVP最大的劣势之一就是他的有失败的负反馈很多人弃坑这个英雄联盟啊守望先锋啊"；`[P8 00:11:41]` "玩那个游戏就是为了快乐结果老是输这怎么快乐起来……再也不想点开这个游戏了"
  - 证据等级：经验共识
- **玩家死亡后必须有「事可做」，否则就是退游戏——这是老 UGC 平台的公开历史教训。**
  - 出处：`BV1ehYGzxEJe` `[P7 00:06:58]` "但这个图当初的一个槽点就是死的早了没事做啊你输了只能退退游戏啊最后完了最后就剩两个人了就其他人早就跑了"；`[P7 00:07:43]` "对抗性游戏输了没事做啊退游戏啊到时候没办法在一起玩了然后不退的游戏就……那里没事做啊就只能看着你们玩很无聊啊"
  - 证据等级：经验共识
- **具体修法（可直接照抄的机制组合）**：被抓后可离开牢笼 + 鬼魂带短控小技能 + 跑去队友家求救 + 救活后还能再被杀拿收益。
  - 出处：`BV1ehYGzxEJe` `[P7 00:17:02]` "可以做反抗哦然后也可以出兵啊可以出出这个建筑啊可以研究科技啊"；`[P7 00:17:48]` "我做了新的设计啊后面的版本你的人被抓了之后可以被人救"
  - 证据等级：个人经验（讲师自有地图的迭代结果）
- **复活次数是硬要求，不能有「死了就退游」的机制。**
  - 出处：`BV1ehYGzxEJe` `[P9 00:09:17]` "一定要解决这个死了就退游的问题不要用这种死了就没得玩的机制"
  - 证据等级：个人经验（但讲师把它写进了设计硬约束清单）
- **手感差会被玩家算在作者头上——玩家不知道编辑器上限，只知道"你的手感很差"。**
  - 出处：`BV1NWYE6LEDz` `[00:00:46]` "在玩家看来他不懂编辑器他不知道怎么样算是编辑器的上限他就只知道你的手感很差所以可能就给你差评了"；`BV1JCY36EEax` `[00:05:23]` "你本身对这个多人游戏里面的一些延迟手感或者一个UI啊等等没做好啊玩家也会给你一个差评"
  - 证据等级：实测（具名品类数据：体育类综合推荐率 81.5，`BV1NWYE6LEDz` `[00:00:00]`）

### E. 第一印象：美术/UI 排在玩法之前（存在分歧，两个都留）

- **主张 A（`BV11d6rB4Ejc`，教程侧）：美术与 UI 优先级高于玩法与引导，是"核心之中的核心"。**
  - 出处：`BV11d6rB4Ejc` `[00:01:32]` "越往后啊这个美术和UI的优先级就越高而且到现在已经是我认为的核心之中的核心了就是比下面这两个更为重要很多人认为是引导引导和教程最重要啊我不这么认为"
  - 类比说明（讲师原话）："第一眼吸引我的永远是美术啊包括游戏的一个画质画风还有特效"
  - 证据等级：**个人经验**（讲师自称"以我80多年玩游戏的经验"，无数据支撑）
- **主张 B（`COMMENTS-INSIGHTS.md`，玩家侧）：引导与 UI 清晰度才是"能不能玩下去"的第一道门。**
  - 出处：`COMMENTS-INSIGHTS.md:12`（378 赞，本语料单条最高价值）"没有清晰的引导和UI，奇遇本身再牛逼，我都玩不下去"
  - 证据等级：玩家共识（按赞数加权）
  - **分歧处理**：两者不冲突也不等价——A 讲的是**点开率**（第一眼决定要不要玩），B 讲的是**留存率**（进去后决定玩不玩得下去）。实现时按漏斗分两段对待：封面/首屏拼 A，开局 60 秒拼 B。
- **封面与内质不匹配是纯损失（实测样本）。**
