## 一、这是什么（定义与官方命名）

- 官方**没有**「引导」这个组件名。K2 是**知识图谱自拟的优质度轴**（MAP.md 第二节明列 "K2 引导与上手"），因为它装不进官方目录：`MAP.md:15-17` 记载 D 骨架只装下 52% 的知识，**K 轴 28% 是"官方目录里没有，但决定游戏好不好"的部分**。
- 官方文档里与 K2 直接对应的**具名对象**有三个（可 grep 的硬规则）：
  - **选项卡**：实体加此组件后"赋予玩家对动态物件和造物配置交互操作的功能"，"**每个选项卡支持通过本地过滤器判定对每个玩家是否显示**"——出处 `docs/ui-tutorial/official-guide-concepts.md:3053-3065`；证据等级：**硬规则**（官方指南原文）
  - **挂载描边效果**："实体边缘会显示配置颜色描边；支持配置布尔型过滤器"——出处 `docs/ui-tutorial/official-guide-auxiliary-appendix.md:1041`；证据等级：**硬规则**
  - **任务计数 / 成就进度计数**：`src/definitions/nodes.ts:9862-9899` `设置任务计数: 仅超限模式可用`、`:9523-9563` `变更成就进度计数`
- 一句话定位：**K2 是"玩家第一分钟决定留不留"的那道门**。`docs/knowledge-graph/MAP.md:35` 定义本轴为"玩家第一分钟决定留不留；无引导=再好的玩法也玩不下去"；玩家视角最强原声（378 赞）为"没有清晰的引导和UI，奇遇本身再牛逼，我都玩不下去。很多首页奇遇都是这样的"（`COMMENTS-INSIGHTS.md` 第一节）——证据等级：**玩家共识（378 赞加权）**。
- 为什么本轴优先级被放大：千星对玩家只有一次性机会——"尤其是在千星千星因为他一旦退出来就不会给你第二次起飞就直接给你打差评了"（`BV19ab76LE6c` `[00:22:30]`，经验共识）。

## 三、规则与做法

### 3.1 总则：先讲清楚，再变简洁、变不强制

优化顺序不能颠倒——先把话说清楚（基本操作 + 阶段目标），再删字、去强制；否则只是把玩家搞晕。
- 出处：`BV19ab76LE6c` `[00:43:13]` "那接下来就是第二步那在保证你做抢清楚之后再强制显得不变得很简洁变得不强制"
- 证据等级：**个人经验**
- 案例（实测）：远古版本任务图标看不出变量在哪 → 玩家只能乱找；改进方式是在那里放个光点、或优化美术让玩家一眼认出是避难所。

### 3.2 引导的四条参考标准（可直接当 checklist 用）

- 出处：`BV19ab76LE6c` `[00:32:30]` 起；证据等级：**经验共识**

| # | 标准 | 具体做法与数值 |
|---|---|---|
| 1 | **简洁** | "用最少的文字传达最多的信息"。原神 PC 首次登录：屏幕最上方一个**标黄的 W 键**小 UI，按了即消失——"非常简洁就在上面一个非常小的UI你按了之后它就消失了"（`[00:33:16]`） |
| 2 | **循序渐进** | 不短时间内教大量操作/信息，逐步接收。崩坏三整个新手引导过程 **22 分钟**（`[00:33:16]` "他其实整个过程有22分钟"） |
| 3 | **潜移默化** | 用机制逼玩家学会，而不是弹窗打断。原神节奏为**线性解锁**：先普通攻击 → 然后元素战技 → 碰七天神像后用燃素战技 → 安柏入队后才学弓箭重击（`[00:36:20]`） |
| 4 | **代入感** | 新手教程不脱离世界观：开局动画选性别，然后被空值抓住 → 见派蒙 → 触碰神像 → 见到温迪 → 碰到安柏，**"在一个新手教程过程中玩家不会觉得枯燥"**（`[00:37:51]`） |

### 3.3 引导的基本功能 = 告诉操作 + 给出任务目标（开门见山）

- 出处：`BV19ab76LE6c` `[00:40:53]` "引导的基本功能是告诉操作还有给出任务目标那开门见山然后开局就告诉你"
- 证据等级：**经验共识**
- **关键判断**：原神玩家天然会移动（千星蹭到了这个红利——"原神已经帮你降低游玩和制作的门槛"`[00:30:09]`），所以千星作者常省掉操作说明；但**独立发布的游戏必须写清 WASD / 手柄前后左右**，否则"不显示的WASD那玩家进去就是完全动不了"（`[00:29:24]`）。
- 补充（`BV1ehYGzxEJe` `[00:02:18]`，个人经验）：**"十几秒就能讲完"的游戏基础教程**，或把教程融合进试玩关卡——"操作一玩就会"；文字很多也必须一玩就会。

### 3.4 四件套操作引导组合（唯一有完整案例的做法，案例：积木小车大冒险）

- 出处：`BV19ab76LE6c` `[00:38:36]` 起；证据等级：**实测**
1. **全程任务 + 任务点引导**——"非常细致的告诉你下一个你应该去哪……至少会让玩家知道我接下来该干什么"
2. **教程系统**（原神同款，玩家自己点开看）
3. **出现新操作时给一个醒目的大按钮提示可用**，并马上安排对应玩法让玩家熟练
4. **长镜头 + 随处可见的箭头指方向**——具体形态：先触碰一个小模型把门打开，一条镜头从那边倒过来，玩家就明白要往前面的岛去；**跳三个蹦床，蹦床旁边还有两个箭头**（`[00:40:08]`，实测）

### 3.5 潜移默化的教科书做法：先机制限制、后文字提示

- 出处：`BV19ab76LE6c` `[00:34:49]` "那么它的根方法就是开局我只给你50阳光那开局的时候那就只有向日葵亮着"
- 证据等级：**实测**（案例：植物大战僵尸）
- 两段式：① 开局只给 **50 阳光** → 只有向日葵是亮的可种 → 玩家自己就把向日葵种下来；② 后期再用提示强化"**开局先种三排一排向日葵**"，防后期植物不够用。

### 3.6 教程期必须用「空气墙 + 禁用选项卡」双管齐下锁死玩家

- 出处：`BV1Uq6vBLEJP` `[00:06:54]` "特别是新手教程所有游戏的新手教程都是要限制空气墙还有选项卡这些都要限制的不让你做其他事情"
- 证据等级：**经验共识**（"这是所有游戏新手教程的通行做法"）
- **反面实测（卡关链条，必须逐环防）**：玩家没按教程走 → 乱点"睡眠药水"选项卡（满血也扣钱、无提示）→ 回头任务要求买药水时钱不够 → "我直接去打架吗那我不是一直挂着这个任务摆牌子里吗"（`[00:06:09]`）。同一作者还点了**任务链断裂**：任务都做不了 = 挂死在任务栏里。
- 配套定量事实：选项卡**触发距离太近**——"这个选项卡触发距离也非常近啊靠的很近才能碰到"（`BV1Uq6vBLEJP` `[00:22:48]`，实测）。这是引导层而非逻辑层问题，但直接表现为"交互引导失败"。

### 3.7 用选项卡的三个字段做「按条件出现」的引导（官方硬规则 + 频道实测互证）

- **本地过滤器**（硬规则）："每个选项卡支持通过本地过滤器判定对每个玩家是否显示"——`docs/ui-tutorial/official-guide-concepts.md:3063`
- **实测做法**：`BV1uUJCzMEfs` `[00:23:27]` "本地过滤器呢它是一个节点图那么它可以用来过滤比如说哎某些情况下这个按钮是不显示的某些情况下这个按钮是显示的然后呢还有一个触发区域触发区域的意思呢就是当你进入这个触发区域之后呢这个选项卡才会显现出来"；另有**排序等级**决定多选项卡显示顺序。证据等级：**实测**（与硬规则字段名逐字一致）
- **应用到引导上的可抄做法**（`BV1Zy4JzMEvT` `[00:04:16]`，实测）：同一交互平台**不要同时摆"生成"和"移除"两个选项卡**——先用节点图让初始的几个生成选项在创建植物后直接消失，再让"移除"选项卡显现；移除后反向切回。形成"场地有植物时只有移除选项"的闭环，**避免玩家看到不该出现的按钮**。
- 另一条：可关闭实体的"创建设置"让物件初始不显示，需要时再由节点图显示出来（`BV1uUJCzMEfs` `[00:22:41]`，实测）。

### 3.8 多人玩法：准备阶段必须有超时/强制开始

- 出处：`BV1Uq6vBLEJP` `[00:03:04]` "这个游戏的准备练习场居然没有时间限制就是假如一个玩家在这里去准备的时候另一个玩家不去准备的话那你这个游戏永远也别想开"；证据等级：**实测**
- 定量：讲师"我已经准备好了然后另一个同学一直不过来准备啊一直不过来准备然后这个倒计时不走等了他4分钟"——**倒计时不走，实等了 4 分钟**。这是引导/前置流程设计缺陷，不是逻辑 bug，却导致整局永远开不了。

### 3.9 一次性弹窗说明界面 = 信息黑洞（必须常驻入口）

- 出处：`BV1Uq6vBLEJP` `[00:13:55]` "我连这个界面控件组件的游戏说明的按钮都调不出来就等于我只要在一开局点了初始弹出那个选项让我擦掉之后啊就是我们作者可以点初始创建让玩家擦掉之后你再也看不到这个游戏简介了"
- 证据等级：**实测**
- 结论：开局弹一次"游玩须知/游戏简介"**不能作为唯一的规则载体**；必须同时有常驻的界面控件组按钮，且**文字不能全是默认白色**（同段实测："全是用的默认的白色……没加文字符的那些优化都没有做"）。

### 3.10 跑酷/观景类：几乎不需要教程，教法就是"实践即懂"

- 出处：`BV18Ken6bEwT` `[00:01:31]` "大部分玩家都不需要学任何的一个新手教程甚至是引导甚至是文字教程啊都不需要啊你只要上去跑就行了"
- 证据等级：**经验共识**
- 特殊机关的教法：**"掉下去摔死 / 掉下去传送回来"这种一眼实践就懂的结果**；"甚至也不用写太多规则也可以用一些视觉引导的元素来做一些引导"（`[00:02:17]`）；并推荐新手优先做跑酷类——"跑酷类的技术难度啊编程难度节点图的这个难度是要求最低的"（`[00:03:04]`）。

### 3.11 教程能省就省、能短就短（时长硬约束）

- 出处：`BV11d6rB4Ejc` `[00:09:13]` "这个教程不能太长但本来这个游玩时间就很短你还要站5分钟的教程那里不是玩家都退出了"
- 证据等级：**个人经验**
- 量化口径：**三言两语 / 一分钟内教会**（`[00:08:26]` "你不管是做一个什么样的教程你得三言两语啊一分钟之内或者说多少时间之内能够教会玩家怎么玩循序渐进的交汇"）
- 同源结论：**"容易上手"是最大加分项**——"你的玩法即便看不懂但是一玩就会……所以我可以忽略你的小作文"（`[00:08:26]`）；反例：有作品"甚至都不需要教程只需要做一个简单的一个引导的一些文字说明"就拿到优秀作品（`[00:14:37]`）。
- 流程过长的代价（`BV1NWYE6LEDz` `[00:04:41]`，经验共识）："玩几分钟还是在第一关啊还是在新手教学就不想玩了"——玩家会看时长与评价再决定是否进。

### 3.12 视觉引导四招（做进美术，不写小作文）

| 做法 | 出处 | 证据等级 |
|---|---|---|

### 3.13 可借鉴的"笨拙但有效"手把手引导（新作者兜底方案）

- 出处：`BV19ab76LE6c` `[00:30:56]` "然后你学会了之后冒出来一个僵尸这时候你刚准备打的时候我先打断你然后再打断你"；证据等级：**经验共识**
- 形态：崩坏三**前 22 分钟从 1-1 做到 1-4**，一步步打断玩家的攻击、强制点进每个 UI 讲用途。缺点：破坏手感、强制性强；优点：绝对讲清操作和世界观。
- 讲师的判词标准（重要）：**"笨拙"是中性的，"差劲"（什么都没讲清）才是贬义**——"更别说现在大多数企业连这种手把手教学的引导都没有一点引导都没有"（`[00:32:30]`）。

### 3.14 把"技能说明"这类大段信息前置到局外

- 出处：`BV19ab76LE6c` `[00:49:31]` "那他是要先进去一趟然后看一看有什么有什么角色的技能然后考虑综合考虑一下然后再出来然后再重新进去"——"这样的情况的话可能就是对玩家来说操作还是太繁琐了"
- 证据等级：**个人经验**
- 做法：把技能列表摆在**选人界面**或**更新日志**里，别让玩家在局内看完再退出重进（想搭技能搭配的玩家尤其痛苦）。

### 3.15 提示文案："还有事情没做完"式模糊提示 = 死档错觉

- 出处：`BV19ab76LE6c` `[00:42:26]` "很多人就是第一天就是不知道有日志这个东西然后在那点睡觉然后告诉你还有事情没做完然后就觉得死档了然后直接跳出来给差评"
- 证据等级：**实测**
- 改法：模糊提示后面**加括号写清"进行什么操作"**。

### 3.16 准备阶段的"目标明确"与"试玩关卡"两条落地路径

- "进游戏之后看一个游戏基础的教程，**十几秒就能讲完**，马上开始干；或者把教程**融合进游戏的试玩关卡**，操作一玩就会；同时新玩家要目标明确知道自己这局要干什么"——`BV1ehYGzxEJe` `[00:02:18]`，证据等级：**个人经验**
- 测试侧对应做法：**"每个玩家第一次接触游戏后的反应是非常宝贵的"**，会暴露"我该怎么操作""这个背包按钮是啥""我怎么按了没有任何提示"这类**引导或交互给得不够**的问题（`BV19ab76LE6c` `[00:21:45]`，实测）。

### 3.17 平台等级门槛会改变引导设计（与本轴强相关的上游约束）

- **绝对存档 LV4 专属**、**消息队列无等级限制**：`BV1K4tH6GE4k` `[00:37:06]` "这个是LV4以上才能做的一个功能啊一个是绝对绝对存档一个下级队列消息队列是所有所有的它没有等级限制啊只有绝对存档是有等级限制的"（引文间"绝对存档"与"消息队列"对比见同段）；同源 `[00:48:03]` 指出新手必踩的坑——**存档变量初始长度是 0、必须初始化并判空**，否则"千星刚出的时候就是很多人都在问这个绝对存档他他怎么没有啊"。
- **隐藏成就需奇匠等级 4 级**：`BV1Gj1jB1EQf` `[00:03:53]` "你目前有这么一个叫做奇降等级的东西达到四级的时候你才可以做这种的隐藏成就"（音轨"奇降等级"= **奇匠等级**）。
- 证据等级：**实测**
- 对引导的含义：**"用成就/存档做长期引导钩子"这类方案有等级前提**——新作者的第一张图做不出来，引导设计必须准备降级方案。

### 3.18 鼠标/手柄操作习惯差异必须专门适配

- 出处：`BV1Gj1jB1EQf` `[00:02:20]` "有好多人说up主你是用手柄玩的好多操作习惯和我们这些用键盘鼠标的不太一样你放心这次做迷宫的时候我可考虑到这一点了"；证据等级：**经验共识**
- 同源"邪修"（实测）：**为键鼠量身定制的坑**——安排一大堆连续向左转的路，让手感到不舒服之后，玩家接下来在可行的情况下必然会向右走；**反向用视觉引导造难点**——"利用玩家的操作惯性来进行视觉引导反而可以用这个来创造一些小的难点"。
- 测试侧要求（`BV19ab76LE6c` `[00:10:10]`，实测）：多设备平台，创作者多接触键鼠，**手机触屏 / 手柄的基本操作需要测试者额外关注**。

### 3.19 专业化 vs 上手门槛：这是设计取舍，不是缺陷

- 出处：`BV1UCxWzhEcx` `[00:13:18]` "所有攻击软件都面临着创作自由度和上手门槛之间的平衡问题想追求更专业创作自由度更高的系统必然会导致上手门槛的提高"；证据等级：**个人经验**
- 配套实测（同源 `[00:12:31]`）：图形化编程降低了门槛，**"但不等于每个人一上来就可以做游戏"**；"元件/实体、组件、节点图、自定义变量"是专业游戏开发思维的产物，不懂就会"莫名其妙的发现自己设计的元件无法正常工作"。
- 官方文档的定位（同源 `[00:13:18]`，实测）：综合指南和教程写得很详细，但**大量专有名词 + 严谨书面语，"一般人看起来像专业教科书"**——文档不能替代引导设计。

### 3.20 上手成本旁证与自评偏差（两条反向提醒）

- **正面旁证**（`BV1JwiwB4EPd` `[00:00:00]` "看完千心奇遇教程后我妈花一天时间做出的奇遇"，个人经验）：非从业者用一天做出可发布奇域 → "教程 + 模板足以让外行出成品"的**间接信号**；但该视频未展示过程与产出质量，**不能据此推断玩法质量或复杂度上限**。
- **自评偏差**（`BV1WXY96GETB` `[00:03:35]` "这是很简单游戏玩法非常简单就目前来讲大家可能不太会玩"，个人经验）：作者认为很简单，实际玩家不太会玩——隐含战术（控图）需要玩家自己悟。
- **首作常态**（`BV1FaC3BVEdZ` `[00:00:00]` "第一次接触原神地图不太熟练有瑕疵望理解"，个人经验）：第一次接触地图编辑器出瑕疵是常态，成品展示类内容要接受首作的完成度损失。

### 3.21 品鉴判据：优秀解谜看的不是"酷"而是"流畅"

- 出处：`BV16mJH6EEBE` `[00:02:48]` "而是流畅包括引导包括教学包括游戏流程的推进还有美术的统一"；证据等级：**个人经验**（本作作者即《拼途》作者）
- 用法：**引导 / 教学 / 流程推进 / 美术统一四处同时在线** = 可当自查清单。

### 3.22 引导缺失可以判到 P0（验收时怎么定性）

- 出处：`BV19ab76LE6c` `[00:27:53]` "然后进去刚开始60秒完全无所适从然后无物资开局"；证据等级：**实测**
- 判据：程序本身没错（照着步骤走能通关），**但引导有问题且受影响玩家多 → 按 P0 处理**。
- 同源另一条 P0 级：教程被玩坏即卡关——"教程期必须假设玩家会做任何事"。

### 3.23 ⚠️ 与"千星优势"相反的一条：受众窄/门槛高的品类要慎选

- 出处：`BV11d6rB4Ejc` `[00:10:46]` "它的规则可以写1000多个字或者几百个字每个职业都有一个规则就比普通的狼人狼人杀的理解门槛还要高很多很多"；证据等级：**个人经验**
- 讲师自陈（`[00:12:20]`，实测）：《合金圆备幻痛》美术与新鲜题材都做到了，但潜行/气球回收题材受众窄、原神玩家圈层更窄，"好评率推荐率非常高啊但是我的热度起不来"，结论**"保住了下限，上限非常低"**。
- 本轴用法：**上手门槛是选题阶段就要算的账**，不是做完再补引导能救的。
