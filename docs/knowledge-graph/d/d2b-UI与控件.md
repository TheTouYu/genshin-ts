### A. 定义与分类（R1–R7）

- **R1** 界面控件 = 设计和实现界面布局的各种文本框、图标或特殊功能的基础资产 — `official-ui-tutorial.md:643`
- **R2** 界面控件**可直接配置在界面布局默认生效**，也可**编辑为界面控件组模板使用**（经节点图使用）— `official-ui-tutorial.md:649`、`:769`、`:773`
- **R3** **"界面控件的运行显示依赖界面布局"**——控件本身不是独立显示单元 — `official-ui-tutorial.md:651`
- **R4** 分类二分：**固有界面控件**（关卡运行时不可缺少的流程型控件，或与业务关联的功能型控件）/ **预制界面控件**（原子化的界面资产，可编辑修改和自定义组合，构成更定制的界面控件组）— `official-ui-tutorial.md:655-659`
- **R5** 固有控件"**不支持移除，不可移动，不可调节尺寸，仅支持少量编辑配置**"，仅部分支持调整可见性 — `official-ui-tutorial.md:665-669`
- **R6** 固有控件资产 13 项（清单见 §1.2）；其中**选项卡控件需通过选项卡组件进行调用**，小地图"位于界面布局左上角"，摇杆"移动端用于操控角色移动"— `official-ui-tutorial.md:677-759`
- **R7** 预制控件资产 15 项总览 + 4 项后续新增（详解章 19 项）；**交互按钮/道具展示**"点击和外接设备输入，都可以触发该界面控件的交互"，交互后向节点图发送「界面控件组触发时」— `official-ui-tutorial.md:777-935`、`:1039`

### C. 渲染模式（R15–R17）

- **R15** 月之五及之前：界面控件渲染**仅和创建时序有关，层级参数并未生效**；月之六修复并提供两种模式：【时序渲染(旧)】=按创建时序渲染（月之六前创建的存档默认）／【层级渲染(新)】=按层级配置顺序渲染、支持调整层级（月之六后新建存档默认）— `official-ui-tutorial.md:1005-1011`
- **R16** **"后续版本将不再维护新增控件在【时序渲染(旧)】模式的表现"**，建议均使用【层级渲染(新)】— `official-ui-tutorial.md:1013`
- **R17** 旧→新切换的三条推荐修复：①检查层级配置（层级越大越靠上；同层级按创建时序，后创建在上）②**层级渲染下"界面布局中的控件层级低于界面控件组库中激活的控件层级"**，原先靠创建时序让主屏控件盖在控件模板之上的要改为控件模板 + 层级配置 — `official-ui-tutorial.md:1019-1023`

### D. 界面布局（R18–R33）

- **R18** **"依赖玩家运行，运行时每个玩家有且仅有一个生效的界面布局"** — `official-ui-tutorial.md:2915-2919`
- **R19** **"仅支持对关卡运行中表现的界面做编辑和引用，不支持对匹配、结算等必要流程界面的编辑"** — `official-ui-tutorial.md:2925-2927`
- **R20** 玩家默认使用的界面布局**需通过「职业」配置**（打开"职业"编辑界面 →【选择布局】引用界面布局）；界面布局参数配置窗口可直接跳转到该编辑界面 — `official-ui-tutorial.md:2931-2941`
- **R21** **"界面布局库不可为空，最少包含一个界面布局"**（默认含"默认布局"，包含关卡运行的必要界面控件）— `official-ui-tutorial.md:2737-2739`
- **R22** 位置：**以画布左下角为原点，显示控件中心点与原点的相对位置；每个设备需单独设置** — `official-ui-tutorial.md:2995-2999`
- **R23** 大小：点击右上角链条按钮可**锁定当前长宽比**；部分控件大小不可调整；每个设备需单独设置 — `official-ui-tutorial.md:3003-3007`
- **R24** 锚点：**"当分辨率变化时，控件会自适应位置与设置的锚点保持相对位置不变"** — `official-ui-tutorial.md:3013-3015`
- **R25** 锚点选择建议两条：①根据控件在屏幕九宫格中的位置选对应锚点 ②根据功能区——**同一功能区的多条文本框锚点选择应保持一致** — `official-ui-tutorial.md:3031-3037`
- **R26** **拉伸锚点**：UI 元素可根据背景或容器的大小变化进行拉伸适配 — `official-ui-tutorial.md:3041-3043`
- **R27** **跟随固有控件锚点**：解决适配不同设备屏幕宽度时无法与固有控件对齐的问题（官方例：以技能区为跟随对象，16:9 对齐、切到 19.5:9 后仍保持对齐）— `official-ui-tutorial.md:3047-3053`
- **R28** **界面死区**："移动端界面最小，**需要以移动端 16:9 适配作为基准**，确保可点击控件在红框区域内" — `official-ui-tutorial.md:3057-3059`
- **R29** 字号规范：大标题 36–32／小标题与按钮文本 24／**正文（最常用）20**／辅助字 18／推荐最小 16；**"通常采用 20 号字"** — `official-ui-tutorial.md:3069-3078`

### E. 界面控件组（R34–R43）

- **R36** 状态：**激活 / 未激活**——激活=存在于界面布局，可通过节点图管理表现状态；未激活=不存在于界面布局，**不可操作表现状态** — `official-ui-tutorial.md:3212-3220`
- **R37** 已激活的表现状态三态语义（**最容易被写错的一条**）：**开启**=可见性开启（隐藏→开启=将可见性开启；关闭→开启=将界面控件组**重新初始化**并开启可见性）；**关闭**=可见性关闭**并且不保留动态改动的信息**（关闭后开启，表现和数据都会初始化）；**隐藏**=可见性关闭**并且保留动态改动的信息**（隐藏后开启，表现和数据都和隐藏前一致） — `official-ui-tutorial.md:3222-3242`
- **R38** 以界面布局引用时：引用的模板**默认随界面布局一同激活**；**"不可对状态修改，仅可对表现状态做调整"** — `official-ui-tutorial.md:3246-3248`
- **R39** 以节点图管理的四种操作：①激活控件组库内界面控件组（把控件组创建在玩家当前界面布局中）②移除控件组库内界面控件组（只移除由"激活"节点创建的）③修改界面布局内界面控件状态④**界面控件组触发时**（该事件只有触发按钮的玩家节点图可以收到）— `official-ui-tutorial.md:3250-3274`
- **R40** 界面控件组详情窗口的作用域：**"只有处于该窗口的界面控件组才可以被编辑"** — `official-ui-tutorial.md:2830`
- **R41** 索引的两种生成路径：多选 → 右键/编辑按键处【创建组合】**生成界面控件组组合并生成索引**；**单个界面控件也可直接选择【保存】生成界面控件组并生成索引** — `official-ui-tutorial.md:2840-2848`
- **R42** **删除模板的连带效应：若有引用，会将所有引用（界面布局、界面控件组详情）一起删除** — `official-ui-tutorial.md:2812`
- **R43** 控件组参数配置窗口四项：初始可见（模板激活时的默认表现状态）、位置、**大小（不可修改，代表界面控件组的最大范围）**、层级（代表显示层级）— `official-ui-tutorial.md:2891-2909`

### F. 节点图控制面（R44–R52）

- **R49** **"目前没有弹窗/其他控件被开启/关闭的单独事件"**（官方 FAQ ②）——想监听控件状态变化，只能靠控件自带的交互事件 — `official-ui-tutorial.md:3372-3381`

- **R62 弹窗**：标题 + 文本内容；文本内容"同文本框支持插入玩家和关卡自定义变量，变量变化同步变化" — `official-ui-tutorial.md:1321-1337`
- **R63 进度条**：形状（横向/纵向/圆环）；进度样式（不显示=隐藏进度提示文本 / 百分比=按真实比例、精度为整数 / 真实比例 / 当前值）；当前进度值、最小值、最大值均支持玩家和关卡自定义变量；升级版支持自定义底图素材与进度图素材、进度图**按进度值增减动态遮罩显示**——**"进度图素材中的动效素材无法根据进度裁切"** — `official-ui-tutorial.md:1339-1386`
- **R64 计时器**：类型（正计时/倒计时）；**指定计时器 = 枚举符合"类型"的所有预定义全局计时器**；来源实体默认关卡实体、可选关卡实体或玩家实体；**来源实体需配置"全局计时器组件"**；**若配置的计时器在来源实体运行时并未生效，界面控件会显示默认值 `00:00`**；**暂停/恢复/修改全局计时器时，引用了该计时器的界面控件显示同步暂停/恢复/修改** — `official-ui-tutorial.md:1388-1401`；`official-guide-concepts.md:4469-4488`、`:4530-4556`

- **R67 界面动效**：选择界面动效（特效资产）+ 是否播放音效（资产自带音效）；**层级仅支持"在所有控件之上/在所有控件之下"，默认在所有控件之上**；节点图 = 播放界面动效控件 — `official-ui-tutorial.md:1573-1601`
- **R68 全屏界面动效**：**层级默认在所有层级之上且不可更改；覆盖全屏、不可修改生效范围**；一般用于视野氛围表现 — `official-ui-tutorial.md:1603-1633`
- **R69 图片**：图片源 = 静态引用/动态引用/道具/状态/技能/单位状态；静态引用 = 引用素材资产 + 填充颜色（**图片资产分单色和彩色两类，单色资产改色表现更好**）+ 图片类型（基础/拉伸）；**图片属性三档：普通=拉伸时四角跟随形变（拼接特定形状或基础图案）／三宫格=横向或纵向其中一个方向拉伸时四角维持原形（自定义样式的按钮、页签项底板）／九宫格=横纵拉伸四角都保持原形（单选项视窗列表项底板、页签/单选项视窗背景）**；**"若为素材组，则无法被填充颜色"** — `official-ui-tutorial.md:1635-1695`
- **R70 自定义按钮**：样式 = 预设/自定义；自定义可配 默认/悬停/按下 状态素材；**"当且仅当功能-按键类型选择技能时，才可配置不可用状态素材"**；状态特征 = 悬停（外描边 + 颜色略高亮 + 尺寸略增大）／按下（颜色变化 + 尺寸略减小）；**预设样式时按键类型锁定为"交互事件"不可修改**，自定义时在 技能/交互事件/道具 中三选一；**响应点击区域仅自定义样式可配，且"实际触发以此点击区域配置的大小为准"**；**推荐尺寸：1 级（核心操作，如强化装备）宽度按需、高度 48~52；2 级（次要操作）32~40；3 级（提示性按钮【？】）32×32** — `official-ui-tutorial.md:1697-1788`
- **R71 自定义按钮的响应优先级**：**"无法同时响应多个同按键映射，默认规则为按按钮创建时序优先响应最近创建的按钮"**；运行时用节点图动态增删会改变响应优先级 — `official-ui-tutorial.md:1792`
- **R72 自定义开关**：**可映射玩家的布尔型自定义变量，"自定义变量变化时开关会对应变化"**；按键映射键鼠/手柄 + 提示偏移；打开音效/关闭音效；响应点击区域规则同按钮；自定义样式需配 **开启-默认/悬停/按下 + 关闭-默认/悬停/按下 六态** — `official-ui-tutorial.md:1794-1870`
- **R73 特殊数字**：数据来源 = 技能/道具/单位状态；监听技能槽位（支持所有槽位）；数据内容 = 技能冷却剩余时间/技能可用次数/技能资源/技能可用状态；计时单位 = 秒/分钟/小时；**监听模式（数据来源=单位状态时可选）：监听实体变量 = 显示指定实体的指定单位状态数据；监听父级 = 需与状态显示区控件配合使用，显示状态显示区分配的对应单位状态（可实现不同来源的单位状态区分显示在不同槽位）**；若同一单位状态存在多个（不同槽位），【单位状态层数】显示当前总层数、【单位状态剩余可持续时间】显示剩余可持续时间的**最大值** — `official-ui-tutorial.md:2351-2418`
- **R74 图文输入框**：适用于图片和文本混排；**图片会基于文本内容的实际长度进行动态适配**；行间距单位 = 字号尺寸（实际行距 = 字号 × 行间距值）；**图片不能修改颜色；图片源设置为【静态引用】时无法使用素材组**；位置单位 = 字号尺寸（实际偏移值 = 字号 × 偏移值） — `official-ui-tutorial.md:2420-2446`

### 4.1 悬浮交互页 + 页签：从建页到落地的完整链路（`BV1MVYj65EoV`，本轴主教程）

需求："很多场景需要利用显示和隐藏功能制作过渡动画"，作者要做一个**结算动画**，用**页签**做出来。链路可完整复刻：

1. **先拆需求再建 UI**："首先拆分需求碰到结算原件后弹出页面结算关卡然后按收集的星星数量依次点亮星星"（`[00:00:00]`）——**先定"碰什么 → 弹什么 → 变什么"，再动编辑器**。
2. **建页 + 固有容器打底**："打开界面控件主库新建一个悬浮交互页现在固有容器里填充基础要素包括结算文本结算特效背景"（`[00:00:00]`）——基础要素放**固有容器**，不另开容器。
3. **为"多态样式"单独开容器**："**另外再新建三个容器用来存放点亮星星的样式**我的样式包括星星以及点亮特效"（`[00:00:45]`）——**容器的粒度 = 互斥态的数量**（1 星 / 2 星 / 3 星各一个容器）。
4. **页签做总开关**："下面设置页签我们在功能栏的页签配置项里设置三个页签分别对应 1~3 颗星的点燃效果"（`[00:00:45]`）——**页签项数量 = 互斥态数量**。
5. **分清哪一层管样式、哪一层管特效**："打开控制容器显影和控制控件显影的按钮**容器控制的是星星样式控件控制的是点亮特效**点亮一星的时候就播放容器一里的特效以此类推"（`[00:00:45]`）——对应官方 R85 的两个设置项（容器状态设置 / 控件状态设置）。
6. **节点图侧：碰撞 → 唤起 → 定时器**："碰撞触发节点唤起结算悬浮液然后设置了一个定时器延时点亮星星定时器触发后按照星星数量判定动画方案"（`[00:00:45]`）。
7. **依次点亮 = 多个定时器错开启动**："每多一颗星就多启动一个点亮的定时器**给每个定时器的启动设置间隔**就有依次点亮的效果"（`[00:01:34]`）。
8. **真正的显隐切换靠一个节点**："定时器启动后呢就要用到**更新悬浮交互页列表数据**节点图这里**列表索引就填叶签的索引显示项就是叶签的序号**后面再加一个音效"（`[00:01:34]`）——**"列表索引"= 页签自身的索引，"显示项"= 页签项的序号**，一次调用完成整套显隐切换。

- 出处：`BV1MVYj65EoV` `[00:00:00]`–`[00:01:34]`（字幕 55 条 / 586 字，全片就是这一条链路）
- 证据等级：硬规则（与官方 R84/R85/R88 逐条对得上）+ 实测（一条可复现的成品链路）

> ⚠️ **这是本轴最重要的一条实操知识**：切片把它标成"野路子（页签当多路开关）"，但从官方原文看，**页签的"容器状态设置/控件状态设置"本来就是为此设计的**（R85），"更新悬浮交互页列表数据"也是官方节点（R88）——**它不是邪修，是官方既定用法**。

### 4.2 页签序号是"状态的唯一落脚点"（绕过控件级显隐的硬限制）

- **限制原文**："由于**目前无法通过节点图控制悬浮交互页里控件的显影**每次重新打开界面都会变回默认的样子所以有些细节还没法优化" — `BV1s6LB6WEF4` `[00:00:00]`

- **推论（可当设计前置条件用）**：悬浮交互页的**控件级动态显隐在界面重开时必然丢失**；要在重开后保留状态，**状态必须挂在页签序号上，而不是控件属性上**。→ **开工前就按"页签粒度"切分界面**（这条也是 `slices/d5-D5.md` 的案例复盘结论：作者明确"有些细节还没法优化"）。

### 4.3 锚点的三种用法（`BV1mLMr6QESr`，7.0 更新讲解）

- **本质**："其实这四个箭头是代表锚点在**屏幕中多少比例的位置**；实际切换比例的时候则是保持**控件的四个角落相对锚点的绝对距离**"（`[00:00:47]`）
- **用法 A｜默认锚点 = 不动**："当锚点为默认时控件的四个角落是相对屏幕中心的所以看起来在不同比例屏幕下控件是不会动的"（`[00:00:47]`）
- **用法 B｜拉到屏幕两侧 = 弹性拉伸**："空间就会随屏幕拉宽而拉宽"（`[00:01:38]`）
- **用法 C｜拉到控件四角 = 固定布局**："如果我们屏幕有多个空间想要在不同屏幕上都保持固定的布局我们可以把锚点的四个箭头拉到空间的四个角落处这样就是**规定了屏幕的多少比例到多少比例处是这个控件**从而保持布局的相对稳定"（`[00:01:38]`）
- **配套**：同版本加了**控件搜索框与过滤**（"当我们的奇遇存在大量空间时就能快速定位"）、**复制粘贴改到选取控件下方**（"不再是复制到最低层了"）——都是 UI 数量上去之后的必需工具（`[00:00:47]`、`[00:02:26]`）
