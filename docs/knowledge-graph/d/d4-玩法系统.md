## 一、官方定义与命名

官方**没有**"玩法系统"这一节名——它是本图鉴的工程切分。D4 的官方边界由七块组成（全部有官方章节）：

| 块 | 官方章节起点 | 一句话定义（官方原文口径） |
|---|---|---|
| 外围系统 | `official-guide-concepts.md:7427` | 不包含在关卡局内的部分：排行榜、竞技段位、成就、关卡结算、奇域礼盒（`:7431`） |
| 资源系统 | `official-guide-concepts.md:7993` | 局内资源管理和道具投放的一整套解决方案（`:7997`）：道具 / 装备 / 货币 / 背包 / 掉落物 / 商店 |
| 技能 | `official-guide-concepts.md:8583` | 接收游玩时的用户输入、让角色执行某一段预设行为的封装（`:8589`）；含技能资源 / 复杂造物技能 / 关键行为 / 技能变量 / 技能属性组 / 预瞄准 / 角色操控技能 / 职业 |
| 复杂造物 | `official-guide-concepts.md:857` | 可自主编辑逻辑、可像角色一样编辑自定义技能的造物（`:863`） |
| 单位状态 | `official-guide-concepts.md:9809` | 面向关卡运行中，各单位实体额外功能与属性的状态管理模块（`:9815`） |
| 关卡结算 | `official-guide-concepts.md:7656` | 由节点图触发、触发后整个关卡结束、结果传给外围系统的收口动作（`:7662`） |
| 局内存档 | `official-guide-concepts.md:10542` | 保存玩家在特定关卡内产生数据的结构，离开关卡也持续保存、每次进入带入（`:10548`） |

## 三、硬规则清单（官方）

> 用法：这是 D4 的**可依赖实现依据**。每条带 `文件:行`，行号即入口，可直接 `grep`。

### A. 外围系统（`official-guide-concepts.md:7427-7992`）

- **R1**（`:7431`）外围系统不包含在关卡局内，包括排行榜、竞技段位、成就、关卡结算、奇域礼盒几部分。
- **R2**（`:7439`）排行榜把局内信息**持久化**记录，其他玩家在大厅浏览该关卡信息时可见。
- **R3**（`:7447`）排行榜与竞技段位**仅可选择一项开放**；一个关卡支持定义多个排行榜模板，设置数据时须指定模板序号。
- **R4**（`:7451` / `:7516`）开关字段互斥：`是否开启排行榜` / `是否开启竞技段位`。
- **R5**（`:7453` / `:7518`）`允许房间内游玩结算排行榜` / `允许房间内游玩结算分数`：房间组队（非匹配）时是否允许写数据。
- **R6**（`:7463-7469`）排行榜显示格式三选一：纯数值 / 时间 / 百分比（分数在服务器上以数值存储，展示时转换）。
- **R7**（`:7471-7475`）榜单重置类型：不重置 / 随赛季重置。
- **R8**（`:7477-7481`）成绩排序规则：越小越靠前 / 越大越靠前。
- **R9**（`:7483`）**每个排行榜仅记录排名前 1000 位的玩家信息**。
- **R10**（`:7487`）设置排行榜分数兼容浮点数或整数（对应两个节点：以浮点数/以整数设置玩家排行榜分数）。
- **R11**（`:7502`）竞技段位在**关卡结算时**按结算状态给不同段位积分，各状态积分可由创作者定制。
- **R12**（`:7514`）段位分通过**计分组模板**预设，对局内每个玩家应用一份。
- **R13**（`:7528-7534`）计分四字段：胜利分数 / 失败分数 / 未定分数 / 逃跑分数；另有 `包含的玩家`（该计分组对谁生效，`:7536`）。
- **R14**（`:7542-7554`）**官方推荐分数表**（玩法预期时长 → 胜利/失败/未定/逃跑）：0-2→20/-5/0/-20；2-4→40/-10/0/-40；4-6→60/-15/0/-60；6-8→80/-20/0/-80；8-10→100/-25/0/-100；10-15→120/-30/0/-120；15-20→140/-35/0/-140；20-30→160/-40/0/-160；30-40→180/-45/0/-180；40-999→200/-50/0/-200。
- **R15**（`:7560`）逃跑扣分可按实际情况额外处理（队友逃跑/挂机、网络掉线超时、后期实力失衡使对局失去可玩性）。
- **R16**（`:7564`）连续胜利可按胜利得分的**一定百分比**给额外奖励。
- **R17**（`:7568`）连续逃跑应给额外惩罚。
- **R18**（`:7572`）建议提供**段位保护**（例：白银失败要掉青铜则给予保护，避免掉落段位）。
- **R19**（`:7574`）若有上述特殊处理，建议在**创作者公告**中说明。
- **R20**（`:7601`）成就累积进度**可跨对局继承**，重复游玩同一关卡可不断累积。
- **R21**（`:7611`）一个关卡支持**多个普通成就 + 一个极致成就**；极致成就需**至少设置 5 个普通成就**并完成名称图片配置才生效。
- **R22**（`:7637`）成就稀有度：耀金 / 星银 / 辉铜。
- **R23**（`:7639`）成就计数初始为 0，节点图累加到配置值即完成。
- **R24**（`:7662`）**关卡结算由节点图触发；触发后整个关卡结束**，结果传递到外围系统更新排行榜/竞技段位。
- **R25**（`:7666-7672`）结算状态是**每玩家属性**，两字段：①逃跑合法性（为"否"则一律按逃跑状态处理）②结算状态（合法性为"是"时才有意义：胜利/失败/未定三态）。
- **R26**（`:7682`）关卡结算**表现**仅局内展示，不影响外围系统。
- **R27**（`:7688`）结算界面类型：阵营结算 / 个人结算。
- **R28**（`:7694-7700`）可启用**游戏内排名**；排名数值比较顺序：由小到大 / 由大到小。
- **R29**（`:7745`）**每个关卡礼盒数量上限 20 个**。
- **R30**（`:7751`）礼盒索引**不能重复**；上传存档时礼盒索引**必须与线上为包含关系**。
- **R31**（`:7757`）礼盒获取条件类型：排行榜 / 竞技段位 / 极致成就。
- **R32**（`:7781-7785`）礼盒需配置：赛季更新后能否再次获取 / 持有有效期 / 有效赛季数。
- **R33**（`:7844`）奇域任务按周期**自动刷新**，任务周期内重复游玩**累计进度**。
- **R34**（`:7854`）**单个奇域最多支持配置 20 个奇域任务**。
- **R35**（`:7862`）可开启**游戏内奇域任务入口**。
- **R36**（`:7872-7880`）任务刷新类型：不刷新 / 按日刷新（每天 4 点）/ 按周刷新（每周一 4 点）/ 赛季刷新。
- **R37**（`:7886`）任务奖励**至多配置 3 类奇域嘉奖礼盒**；奇域任务**必须关联奇域嘉奖礼盒**才可生效。
- **R38**（`:7968`）**单个创作者每周可发送 3 条动态**，周一凌晨 4:00 刷新，删除**不返还**次数。
- **R39**（`:7951`）转为正式版后**不可回退**先行体验。
- **R40**（`:7978` / `:7984`）局内订阅按钮在 界面控件组管理→添加界面控件→预制模板；服务器节点可查询玩家是否订阅。

### B. 资源系统（`official-guide-concepts.md:7993-8582`）

- **R41**（`:8009`）道具分为装备、材料、消耗品、贵重物品几类。
- **R42**（`:8027`）道具稀有度五档：灰 / 绿 / 蓝 / 紫 / 橙。
- **R43**（`:8031`）**关联道具节点图：道具进入角色背包时，关联节点图被附加到角色单位上**。
- **R44**（`:8047-8053`）销毁时掉落形态：掉落 / 销毁 / 保留（**保留仅角色有意义**）；货币同规则（`:8325-8331`，角色复活后保留）。
- **R45**（`:8055-8059`）战利品掉落形式：全员一份 / 每人一份（货币同规则 `:8335-8339`）。
- **R46**（`:8061`）对应掉落物外形**必须配掉落物元件**；掉落物是有物理实体的元件。
- **R47**（`:8100`）装备**不支持配置堆叠**。
- **R48**（`:8106`）装备类型：尝试装备时**需装备栏位支持该装备类型**才可装备成功。
- **R49**（`:8124`）装备**模板类型列表**与**装备栏位类型列表交集非空**即可成功装备。
- **R50**（`:8150`）**装备词条是装备属性加成和机制加成的唯一来源**；一件装备可持有多个词条。
- **R51**（`:8162`）词条生效时机：获取时生效（进背包即对持有者生效）/ 装备时生效（装入栏位才对装备者生效）。
- **R52**（`:8172` / `:8194` / `:8200`）词条三类型：基础属性加成（每词条唯一属性，加成类型随机值/固定值）/ 赋予节点图 / 赋予单位状态。
- **R53**（`:8206`）装备模板**首次被获取进背包时初始化**，词条数值随机，抛「装备初始化」事件，出参返回**装备实例唯一索引**。
- **R54**（`:8208`）装备栏是装备容器，**词条生效依赖装备行为触发**。
- **R55**（`:8236`）**装备栏组件仅有角色可以添加**。
- **R56**（`:8305`）货币是玩法中一般等价物，可被单位持有，随交易或节点图逻辑增减。
- **R57**（`:8347`）货币显示优先级：数字越大在背包中显示越靠前。
- **R58**（`:8354`）**背包是整个资源系统的容器**，管理持有者的所有虚拟道具、装备和货币。
- **R59**（`:8370`）背包格数量：每个栏位容纳一种道具，按堆叠数量堆叠多个。
- **R60**（`:8374`）背包销毁时掉落形态**不为「应用道具掉落规则」**时，会**覆盖道具模板上配置的同名字段**。
- **R61**（`:8386`）背包掉落时**所有道具转化为一个实体**，而非每个道具单独创建实体。
- **R62**（`:8407`）虚拟物品模板编辑时**都必须关联掉落物元件，没有关联则掉落逻辑被屏蔽**。
- **R63**（`:8413`）**掉落物内容组件固定携带、不可移除**。
- **R64**（`:8417`）掉落物内容组件**支持同时配置多个拾取范围，生效范围叠加**。
- **R65**（`:8431-8441`）拾取规则四选一：交互拾取 / 自动拾取 / **打开拾取界面（推荐用于掉落列表含多个物品）** / 自动吸附拾取（需配 `自动吸附距离(m)`）。
- **R66**（`:8443-8445`）本地过滤器分布尔/整数两种 + 可引用**过滤器节点图**判条件。
- **R67**（`:8447`）掉落内容：**直接布设场景时含组件内字典全部物品；通过战利品形式创建时只含实际掉落物品，组件默认数据被覆盖**。
- **R68**（`:8451`）拾取范围形状：长方体 / 球体 / 胶囊体三种基本形状。
- **R69**（`:8486`）**商店以组件形式挂接在实体上**，可交易道具、装备、货币。
- **R70**（`:8494` / `:8496`）两类商店：**自定义商品商店**（脱离持有者背包，不影响其背包数据）/ **自身背包商店**（实际交换，**无法出售持有者未拥有的物品**）。
- **R71**（`:8514`）`开启商店时同时打开背包`：开关型显示设置。
- **R72**（`:8516-8524`）商品页签类型：无页签 / 默认页签（按道具预制类型分类）/ 自定义页签（可重定义物品所属页签）。
- **R73**（`:8546`）**是否可售为「是」才出现在交易界面**，可**运行时动态修改**以解禁新商品。
- **R74**（`:8554`）**商品序号**用于节点图动态修改出售表时识别条目（模板商店内可有多个相同道具）。
- **R75**（`:8556`）`是否限量`：为"是"则可定义该商店内总共可出售数量。
- **R76**（`:8562-8568`）收购范围：不收购（收购表为空）/ 全部道具 / 部分道具。
- **R77**（`:8576`）`是否可收购`为"是"才可卖给商店，**可在游戏运行时动态修改**。

### C. 技能与职业（`official-guide-concepts.md:8583-9553`）

- **R78**（`:8589`）技能＝接收用户输入、让角色执行某段预设行为的封装。
- **R79**（`:8595-8603`）技能三功能：角色动画调用 / 触发客户端节点图（动画节点图事件轨道打点）/ 配置技能状态（时间窗口附加持续逻辑）。
- **R80**（`:8621-8631`）技能类型五种：瞬发（不可编辑动画，输入瞬间触发）/ 长按（循环动画）/ 普通 / 连段（可跳转的连续动作）/ 瞄准（进入瞄准状态）。
- **R81**（`:8649`）使用次数：归 0 时技能无法使用；**每经过一个冷却时间恢复一次，最大恢复到默认配置次数不再增加**。
- **R82**（`:8657-8661`）索敌范围两型：圆柱体（半径+高度）/ 扇形（半径+高度+角度+旋转）；本地节点图可查询本次释放的目标单位。
- **R83**（`:8711-8719`）事件轨道四种：开始事件轨道 / 结束事件轨道 / 节点图事件轨道（按动画进度打点触发技能节点图）/ 状态轨道（可自定义起止时点）。
- **R84**（`:8723`）节点图事件轨道**有极小概率跳过事件**，某些关键逻辑应写在**结束事件轨道**上作为兜底。
- **R85**（`:8727` / `:9011`）瞬发技能不可添加动作，只保留开始事件轨道（角色技能与造物技能同规则）。
- **R86**（`:8735-8737`）长按技能：保持长按则循环动画播到"持续时长"上限；未保持则动画立即中断并按分支轨道跳转。
- **R87**（`:8753`）松开长按时，当前动画进度落在哪个**响应段落**，就转入该段落配置的分支。
- **R88**（`:8771-8775`）连段响应事件＝**预输入阶段 + 多个响应阶段**；预输入阶段长按且满足 `蓄力成功时长` 则立即跳转蓄力分支。
- **R89**（`:8845-8865`）五个技能槽位：普通攻击=PC 鼠标左键 / 技能1=E / 技能2=Q / 技能3=R / 技能4=T。
- **R90**（`:8883`）技能资源＝特定技能释放时需要扣除的资源（如经典模式"元素能量"），类型可自定义。
- **R91**（`:8905-8911`）技能资源增长类型三种：无条件增长 / 跟随技能（保留值，无技能需要时保留）/ 跟随技能（不保留值，无技能需要时**清零**）。
- **R92**（`:8915`）`可获取最大值`：角色获取的技能资源量无法超过该值。
- **R93**（`:8928` `:8960-8964`）造物技能＝让造物执行预设行为的封装；类型仅两种：瞬发 / 普通。
- **R94**（`:8968`）`归属模型`：不同造物模型可用技能动作不同，**切换模型会清空当前造物技能所有配置**。
- **R95**（`:8977-8981`）造物技能通用配置五项：可打断其他技能 / 自动面向目标 / 击败目标是否继续释放 / 目标可达时释放 / 目标不可达时释放。
- **R96**（`:9024`）关键行为是**纯客户端数据**（技能施放中由节点图记录），系统把关键行为列表与**客户端时间**保存在**关键行为记录板**内，可通过节点获取。
- **R97**（`:9051-9057`）技能变量三特性：①客户端值，可被客户端节点直接修改且**立即生效**（时效性优于自定义变量）②默认浮点，暂不支持其他类型 ③**角色倒下后技能变量值置为 0**。
- **R98**（`:9097` / `:9111-9113`）技能属性组可被技能关联，当前版本仅两种属性类型：**动画速度倍率** / **冷却时间倍率**（技能节点图触发时机也受动画速度影响）。
- **R99**（`:9119`）**最终动画速度 = 技能属性组初始值 + Σ(单位状态修改值 × 层数) + Σ技能轨道修改值**。
- **R100**（`:9129`）**最终技能冷却 = 原始技能冷却 ×（技能属性组初始值 + Σ(单位状态修改值 × 层数)）**。
- **R101**（`:9149`）单位状态【调整施法速度】【调整冷却缩减】可在运行时动态修改属性组数值。
- **R102**（`:9153`）技能轨道修改（状态轨道加"调整动画速度"事件）**只支持固定参数**，通常用于优化动画表现。
- **R103**（`:9166-9168`）预瞄准可用性矩阵：**瞬发/普通/连段**可配 `开始前预瞄准`；**普通/长按**可配 `技能过程中预瞄准`。
- **R104**（`:9217`）目标**必须有【受击盒】**才能纳入瞄准区域的合法目标筛选。
- **R105**（`:9226`）满足筛选规则的为【合法目标】，**排序第一的为【最优目标】**。
- **R106**（`:9243`）`瞄准目标数量限制`只影响瞄准表现中的"所有合法目标"数量，**节点中仍会返回所有合法目标**。
- **R107**（`:9246-9247`）**需同时满足阵营筛选与标签筛选**才视为合法目标；标签白名单需包含全部白名单标签，黑名单不能包含任意一个黑名单标签。
- **R108**（`:9249`）部分基础造物的武器、召唤物带受击盒，**当前版本会参与筛选，后续版本修复**。
- **R109**（`:9311-9314`）技能过程中预瞄准专属参数：限制瞄准最大成功次数 / 中断瞄准消耗次数 / 角色技能节点图 / 开启预瞄准时可主动取消预瞄。
- **R110**（`:9332`）**若特效器挂载对象为光标，则特效过滤器不会运行**。
- **R111**（`:9340-9342`）查询预瞄准结束原因返回三态：无 / 完成 / 取消。
- **R112**（`:9407`）角色操控技能＝**操控状态下才可使用**的特殊类别角色技能，**释放期间角色无技能动画表现**。
- **R113**（`:9421`）角色操控技能**属于角色技能子类**：添加/移除方式完全相同，可使用角色技能适配的所有节点图节点、单位状态、技能槽位。
- **R114**（`:9469`）角色操控技能**仅支持通过属性组调整冷却时间倍率**。
- **R115**（`:9497`）角色操控技能不关联动画，仅含一个可填自定义时长的【操控状态空动画】槽位（即整条技能轨道的尺度）。
- **R116**（`:9511`）**仅支持添加节点图类型为【角色操控技能节点图】的客户端节点图**。
- **R117**（`:9558-9560`）职业是玩家的一个属性，但主要影响单位是玩家的角色；**决定大部分玩家实体和角色实体的初始属性和技能**。
- **R118**（`:9566`）职业＝打包一整套配置，切换时统一修改玩家和角色；**除职业等级外，其他数据只在职业切换时覆写一次**，之后仍可用节点图修改。
- **R119**（`:9616`）**角色等级与职业等级同步**。
- **R120**（`:9620`）单次游玩可切换多个职业，**等级被记录**（例：职业1 5 级→切职业2→切回职业1 仍 5 级，**职业经验也恢复**）。
- **R121**（`:9624`）玩家模板上可覆写一次玩家**初始职业的创建等级**，该等级在关卡初始化时设置到玩家上。
- **R122**（`:9636-9638`）升级经验两种配置：线性公式（`该等级升级所需经验 = 当前等级 × 常数1 + 常数2`）/ 列表配置（二维表精确定义每一级）。
- **R123**（`:9668-9672`）成长曲线公式：最终生命/攻击/防御 = 基础值 × 等级对应倍率（默认曲线不可改；自定义曲线规则一致）。
- **R124**（`:9702-9732`）抗打断三状态循环：**抗打断**（受打断值初始 0，受击仅受击表现不被击退击飞，值每秒按衰减速度衰减）→ 值达上限进入**易受打断**（恒为上限，可能被击退击飞，持续"易受打断状态恢复时间"）→ **受保护**（受打断值恒为 0，不会被击退击飞，持续"受保护时间"）→ 回到抗打断。
- **R125**（`:9750`）职业模板配置的技能**视为职业默认技能**；使用「初始化角色技能」节点时，角色技能会被**还原成职业模板配置的技能**。
- **R126**（`:9758`）PC 端冲刺技能**可同时被鼠标右键与左 Shift 触发，且按键关系不可更改**。
- **R127**（`:9764`）满足一定空中条件（高于地面一定距离）时，**指定槽位的技能将被强制替换为空中技能**；空中技能默认可在空中释放。
- **R128**（`:9772-9776`）职业组件：玩家实体可加 自定义变量 / 单位状态；角色实体可加 自定义变量 / 单位状态 / 小地图标识 / 铭牌 / 自定义挂接点。
- **R129**（`:9784`）职业节点图**施加单位支持玩家和角色**。

### D. 单位状态（`official-guide-concepts.md:9809-10013`）

- **R130**（`:9817-9823`）每个状态**必定存在一个明确的施加者实体**；每个实体可动态持有若干状态；**超出运行时长或失去所有叠加层数都会终止**。
- **R131**（`:9831`）**生效目标**限制：状态中若存在某个效果无法对该实体类型生效，目标实体**无法成功持有**该状态（例：挂载屏幕特效只允许对"角色"生效）。
- **R132**（`:9833`）**生效强度**受有效范围限制（例：运动速度变更量不可小于 -40%、不可大于 40%，多个同类型效果不叠加超出）。
- **R133**（`:9835`）同一状态内**互斥效果以最后一个为准**（例：一个状态最多提供一种"元素附着"）。
- **R134**（`:9839`）**每个单位状态允许关联一张服务器节点图**（状态节点图）：持有状态即同步添加，失去状态一并失去。
- **R135**（`:9841`）关联节点图**只能来自状态节点图**；状态节点图中依然可使用复合节点。
- **R136**（`:9843`）多个状态关联**相同**节点图时视为只关联一次，直到失去所有相关状态才失去关联。
- **R137**（`:9853`）单位状态命名需**全局唯一**，并自动生成全局唯一**配置ID**。
- **R138**（`:9863-9871`）叠加规则：叠加计数计入已存在状态但**总数不超叠加层数上限**；可选择 `更新过量叠加数据`（过量数据依次顶替首层 / 直接丢弃）；**若叠加数据未发生变动，则本次叠加行为无效，状态的施加行为也无效**。
- **R139**（`:9877`）`无限持续时间`：不因超出生命周期移除，且该状态的任何更新都不再影响持续时间。
- **R140**（`:9887`）**禁用**`叠加共享时长`：每层独立计时，各自超时后移除并减层，**层数上限最大 10**。
- **R141**（`:9895`）**启用**`叠加共享时长`：所有叠层统一超时移除；每叠加一层可延续剩余时长（受 `最大延续时长限制` 约束），**层数上限最大 1000**。
- **R142**（`:9905`）**同一个施加者无法对目标实体施加两份同名的单位状态**，而是附加在已施加的对应状态上。
- **R143**（`:9907-9911`）不同施加者施加同名状态：可叠加（可启用 `记录最新施加者`）/ 不可叠加（需注明 `并存上限`）。
- **R144**（`:9915-9923`）达并存上限时的 `同名状态更新策略` 四种：无法更新（施加失败并终止）/ 最短剩余时长 / 最早更新时刻（未重复施加则按首次施加时刻算）/ 最早施加时刻。
- **R145**（`:9929`）目标已持有**让位状态列表**中任一种状态 → 本次施加行为**直接终止并失败**。
- **R146**（`:9931`）目标已持有**顶替状态列表**中的状态 → 对应状态**全部移除后再施加**该状态。
- **R147**（`:9937-9941`）以组件施加：实体创建时由**关卡实体**施加组件预设状态；可配叠加计数，施加顺序为配置的**从上至下**；**同一个状态在组件中只能被施加一次**。
- **R148**（`:9947-9959`）以服务器节点管理时的六种返回结果：失败（其它异常）/ 失败（让位于其它状态）/ 失败（超出并存上限）/ 失败（附加叠层未成功）/ 成功（施加新状态）/ 成功（槽位叠层）。
- **R149**（`:9963-9965`）**单位状态参数字典**：状态可预定义覆写标签，节点实际使用时动态传入参数字典，键名与覆写标签相同则按该值生效；**动态版本属性修改与原版不能一起生效，只能设置其中一个**。
- **R150**（`:9973-9977`）以服务器节点移除时的选择：所有同名并存状态 / 最快丢失叠加层数的状态（独立计时看首个叠层剩余时长，否则看状态剩余时长）/（暂无）施加者为自己的状态。
- **R151**（`:9987-9995`）状态移除原因五种：其它单位状态顶替 / 超出持续时间 / 被驱散（受技能、能力单元影响或元素被完全反应）/ 状态失效（部分效果终止导致自身移除）/ 职业变更。
- **R152**（`:9983`）若目标的多个并存状态都被移除，会收到**同等数量的事件**。
- **R153**（`:10001-10003`）以**能力单元**管理：可在本地投射物中添加/移除指定状态，也可在**本地投射物命中目标时**添加或移除状态。
- **R154**（`:10009-10013`）以**技能节点图**管理：施加时**无法得知最终施加结果**；移除者不在场视为**无来源移除**；**不论施加者是谁，所有配置ID相同的状态都会被移除**。

### E. 复杂造物（`official-guide-concepts.md:857-1065`）

- **R155**（`:877`）复杂造物支持缩放调整，**缩放调整率为 0.5-3.0**。
- **R156**（`:881`）复杂造物可调整预设状态，预设状态影响一系列表现（包括但不限于初始动作）。
- **R157**（`:887-889`）**造物状态决策节点图**：配置后造物会**持续访问**节点图，按配置条件进入不同的自主逻辑状态；决策图中可引用**造物状态节点图**来执行实际技能、战术。
- **R158**（`:893`）复杂造物自定义技能**需要先定义好**才可在造物状态节点图中使用。
- **R159**（`:897`）复杂造物技能释放受**技能公共冷却时间、技能冷却时间、技能冷却组时间三重限制**，三者全部满足才可释放。
- **R160**（`:910-911`）造物技能配置：`序号`（状态节点图引用，用于实际执行调用）/ `引用技能`（只能引用支持自身使用的技能）。
- **R161**（`:920-925`）冷却配置字段：初始冷却开始时点（入战/脱战）、初始冷却区间(s)、默认冷却区间(s)、所属冷却时间组、冷却时间触发时机（技能结束时/技能开始时）、触发技能公共冷却时间、忽略技能公共冷却时间。
- **R162**（`:937`）`公共冷却时间(s)`：当前复杂造物的**所有技能**都受公共冷却影响。
- **R163**（`:945`）同一冷却时间组的技能：都需满足冷却时间后才可释放（用于关联多个技能的释放时间）。
- **R164**（`:963`）`初始生效自主逻辑参数模板` **至多 1 个**；模板序号作为节点输入项可让状态使用不同模板。
- **R165**（`:996`）`范围感知距离`：敌对实体处于该范围内，造物可获取其信息并以此为目标进入战斗。
- **R166**（`:1006-1008`）视野检测：视野类型=视锥（视锥距离）/ 全视野（视野检测半径）。
- **R167**（`:1011`）`连锁入战距离(m)`：造物入战时，范围内未入战的造物实体也会一同入战。
- **R168**（`:1022-1025`）脱战设置：脱战距离(m) / 寻路失败脱战（无合法路径时脱战）/ 脱战延时(s)。
- **R169**（`:1032-1035`）领地设置：可配无/球体/圆柱体；**领地以造物创建坐标为中心，不随造物运动改变位置**；造物运动范围被限制在领地内（可由节点调整）；`玩家离开区域后脱战` + 脱战延时。
- **R170**（`:1045`）造物状态决策节点图以【**按顺序唯一执行**】节点起始，每个出引脚连接【**切换自身执行状态**】；若前置状态进入条件不满足优先进入 `失败执行`，仍不满足则尝试执行下一引脚的状态。
- **R171**（`:1047`）决策图**持续执行**：若前置顺序的状态满足条件，造物会**立刻切换**执行状态，执行前置顺序的造物状态节点图。
- **R172**（`:1049`）若条件不满足，复杂造物**可能不执行任何状态节点图**。
- **R173**（`:1061`）造物状态节点图的出/入引脚**仅支持单线连接**。
- **R174**（`:1063`）造物状态节点图代表**持续性行为**：未被决策图切换时持续执行其中配置。

### F. 局内存档（`official-guide-concepts.md:10542-10675`）

- **R175**（`:10548`）局内存档保存玩家在特定关卡内产生的数据，**即使离开关卡也持续保存**，每次进入关卡都一起带入。
- **R176**（`:10552`）局内存档的**读写需要使用结构体以及自定义变量**。
- **R177**（`:10558`）每个关卡可配置多个**局内存档模板**，但**每次只能启用一个**作为当前关卡使用的模板。
- **R178**（`:10560`）一个模板包含多个局内存档，**每个局内存档都是一个定长的自定义结构体列表**。
- **R179**（`:10566`）局内存档结构体**不支持**：实体、实体列表、所有类型的字典、结构体。支持 GUID/整数/布尔值/浮点数/字符串/阵营/三维向量/元件ID/配置ID 及各自的列表类型。
- **R180**（`:10585`）启用模板后，模板中每个结构体都会在**每个玩家实体上生成一个同名的自定义变量**（局内存档变量）；**用法与常规自定义变量完全相同，使用自定义变量相关节点读写**。
- **R181**（`:10589`）局内存档变量与局内存档定义一一对应，**无法直接修改玩家上的局内存档变量**。
- **R182**（`:10591-10593`）**读档**发生在玩家进入关卡时；该过程**发生在实体创建前**，因此**实体创建时事件中可以正确查询到局内存档变量**。
- **R183**（`:10595`）**存档**发生在玩家离开关卡时：把局内存档变量的数据写入局内存档并随玩家带离关卡。
- **R184**（`:10599-10601`）每个关卡的局内存档数据量有限（由结构体成员类型决定，字符串与列表类型开销高）；**总数据量超限则无法进入试玩或发布**。
- **R185**（`:10605-10607`）局内存档中**所有列表类型都有最大长度限制**（与自定义变量不同）；运行时可变长存储，**存档时超长列表被截取到最大长度（保留前若干个元素，超出丢弃）**。
- **R186**（`:10613`）局内存档模板自身作为结构体列表**也有长度限制**，超出部分存档时同样被截断。
- **R187**（`:10623-10627`）**允许**的升级方式：在已发布模板中新增局内存档结构体 / 在已发布结构体中新增成员（新数据读档时取结构体定义的默认值）。
- **R188**（`:10629-10645`）**不推荐**的操作：删除或替换已发布模板、缩减已发布模板最大长度、修改模板中引用的结构体类型或删除已有存档、修改已发布结构体成员数据类型或删除成员。
- **R189**（`:10647`）上述不推荐操作会造成新旧结构无法匹配，**读档失败后玩家局内存档数据重置**。
- **R190**（`:10669`）升级要求：升级后的模板相对升级前必须是**纯增量或完全相同**（可用「对比模板」功能校验；不符合会弹提示）。

### G. 数值与战斗（`official-guide-auxiliary-appendix.md`）

- **R191**（`:941`）单位状态**最终值 =（基础值 + 变更量）×（1 + 调整率）× 倍率 + 修正值**。
- **R192**（`:960`）`受打断倍率` 为 0 时受到伤害不增加受打断值，**即实体霸体**。
- **R193**（`:961`）`坠落效率变更量`：默认所有角色和造物有 **200% 坠落效率**，设为 **-200% 可使角色或造物无视重力**。
- **R194**（`:962` / `:968` / `:970`）其他基础属性的临界值：坠落伤害调整率 -100 → 完全不受伤；体力消耗调整率 -100% → 行为不消耗体力；体力恢复调整率 -100% → 无法恢复体力。
- **R195**（`:1013` / `:1014`）`攻击伤害调整`（挂攻击者）/ `受击伤害调整`（挂受击者）：三个攻击条件（**攻击标签、攻击类型、本地过滤器为与关系**，三项必须均为是）才可通过判定。
- **R196**（`:1013`）覆写攻击元素类型 / 覆写是否为绝对伤害：**攻击者实体上存在多个不同覆写时，生效顺序不确定**。
- **R197**（`:1020` / `:1022`）`特殊状态：无敌`——无法受到任何伤害，且受到攻击**不会触发【受到攻击时】事件**；`特殊状态：锁定生命值`——生命无法降低，但受到攻击**会触发【受到攻击时】事件**。
- **R198**（`:1021` / `:1024` / `:1025`）其他特殊状态：禁止锁定（造物自动锁定类攻击和技能无法锁定该实体）/ 禁止恢复生命值 / 禁止生命低于指定值（受生命阈值百分比限制）。
- **R199**（`:1029`）`禁止移动`：限制造物常规移动，**会影响脱战环节**（带来无法脱战或其他不稳定阻塞），建议规避或监听脱战状态时管理。
- **R200**（`:1031`）`造物沉默`：**暂时无法对复杂造物的自定义技能生效**，下个版本支持。
- **R201**（`:1009` / `:1011`）`定时触发技能`：让指定槽位的技能按触发间隔触发；`调整动画速度`/`调整冷却时间`：调整指定属性组的对应值。
- **R202**（`:324`）能力单元的目标阵营筛选用的是**战斗阵营**而非实体【阵营】属性；**超限模式**阵营关系：角色→造物 敌对 / 角色→物件 敌对 / 造物→物件 友善 / 物件→造物 敌对 / 造物→角色 敌对 / 物件→角色 敌对。
- **R203**（`:327`）攻击盒`触发类型`：生命周期只触发一次（多用于单体攻击）/ 每个实体只触发一次（攻击命中所有实体）。
- **R204**（`:345`）`是否是绝对伤害`：绝对伤害基于**伤害增量**造成一次伤害，**忽略攻击者攻击力以及防御者相关防御属性**。
- **R205**（`:346-347`）伤害变化曲线＝距离-伤害倍率曲线（两节点间线性）；距离计算方式：与当前位置的距离 / 与创生位置的距离。
- **R206**（`:348-349`）`额外破盾值`（护盾计算前移除受击者护盾值）/ `护盾穿透率`（受击者护盾承伤比例减去穿透率，**最小减至 0**）。
- **R207**（`:475`）`销毁自身`（仅本地投射物可用）可配 `延迟时间`，用于确保特效等表现播放完成。
- **R208**（`:749` 等 / `:324`）造物行为模式图鉴与造物技能说明给出**每只造物的可用行为模式（常规/仅追击/仅地面/靶标）与技能清单**（例：遗迹守卫-木桩的造物技能为 `-`，即无技能）。
