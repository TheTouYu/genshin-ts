**口语别名（语料侧，检索必用）**：ASR 同音异写严重——「千星奇域」在语料中写作 **千星奇遇 / 潜行奇遇 / 千行奇遇 / 千金奇遇 / 千心奇遇 / 精英奇遇 / 清心奇艺**；「千星沙箱」写作 **潜心沙箱 / 千金砂浆 / 沙箱 / 千星奇域编辑器**；「嘟嘟可工具箱」写作 **嘟嘟可攻击 / 嘟嘟狗师 / 多多可老师**。
> 判定：这些是**语音识别噪声而非官方别名**（官方原文只用"千星奇域"）。因此**按 BV 号定位源**比按关键词检索可靠；必须关键词检索时用别名集合（见 §6.2）。

**位置**：本域是整张图谱的**入口层**——回答"这个平台是什么、界面在哪、工具边界在哪、去哪儿学"。它不回答"怎么搭地形"（D2a）、"怎么写逻辑"（D3）、"怎么让游戏好玩"（K 轴）。
