# Stage 3 工作包历史归档

> 状态：历史记录 / 当前索引
> 来源：已归档的实时状态与 Phase 工作包记录
> 最近校验：2026-07-13
> 适用范围：已完成工作包的命令、候选路径、SHA-256、失败过程和逐包证据；不作为新会话的默认启动入口

本目录将完成工作包的详细时间线从实时状态中移出，以避免新会话在尚未确定任务前加载全部历史。

## 使用规则

- 新会话先读上级 [`STATUS.md`](../STATUS.md)；它只提供当前 Phase、唯一工作包、活跃约束和最小恢复步骤。
- 当前工作包需要某项历史证据、失败基线、候选 SHA 或精确命令时，才按链接读取对应归档章节。
- 归档保存当时的状态与措辞；当前架构决定以 [`decision-log.md`](../decision-log.md)、当前 Phase 文档和源码/测试为准。
- 不删除有证据价值的历史；后续更正应在当前权威文档或新工作包中记录，不回写为“当前实现”。
