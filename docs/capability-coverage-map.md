## 权威构成（官方指南展开）

游戏由以下构成，相互通过变量/节点图/组件联动（非独立创建）：

### A. 界面控件组（A 体系）
| 控件类型（20） | 当前 CLI/DSL | 真实样本 |
| --- | --- | --- |
| 文本框（富文本{类型:前缀.变量名}、对齐6种、字号、背景） | assets:ui create textbox / update --content | 学习资产、推箱子 |
| 图片（源6种：静态/动态/道具/状态/技能/单位状态；拉伸普通/三宫格/九宫格；颜色） | create image --asset / update --asset/--color | 学习资产（f505[38]）、推箱子 |
| 界面动效 / 全屏界面动效 | playUiAnimationOnControl 节点；控件创建无 | 素材组「界面动效」在资产中 |
| 特殊数字（技能冷却/次数/资源/可用状态） | 无 | 未探索 |
| 交互按钮（技能/交互事件/道具；次数限制） | create interactive-button | 推箱子（事件case=素材组子记录） |
| 道具展示（装备/模板道具/背包道具） | 无 | 未探索 |
| 自定义按钮（预设/自定义三状态素材） | create custom-button / states 读 | 学习资产按钮 t50 |
| 自定义开关（开/关六状态素材；映射布尔变量） | 无（list 分类有 custom-switch） | 未探索 |
| 弹窗（标题+文本+变量） | 无 | 未探索 |
| 悬浮交互页（页签/单选项视窗/形式变量/固有关闭按钮） | create floating-page（骨架）；富版待做 | 学习资产底板1-使用、推箱子快捷语言 |
| 卡牌选择器（已知/未知卡牌、决策面板） | 无 | 未探索 |
| 进度条（横/纵/圆环；变量范围） | 无 | 未探索 |
| 计时器（正/倒计时；关联全局计时器组件） | 无 | 未探索 |
| 计分板（个人/阵营；排序） | 无 | 未探索 |
| 图文输入框（图文混排） | 无 | 未探索 |
| 状态显示区（单位状态展示） | 无 | 未探索 |
| 消息队列（结构体整体推送） | refreshNotificationQueue 节点；控件无 | 未探索 |
| 界面布局（唯一生效布局/设备适配/九宫格锚点/固有vs自定义） | list 布局；创建自定义布局无 | 推箱子「开场」布局 |
| 界面控件组库（激活/未激活；表现开启/关闭/隐藏） | activate/remove + modifyStatus 节点 | 推箱子临时提示模式 |
| 素材库（素材组=控件模板组合；引用控件6种） | library-inject；素材容器创建 | 学习资产 213 素材组 |

### B. 实体与元件（B 体系）
实体元件核心规则（单位→实体→元件、六种单位类型、动态/静态）、元件组、造物行为、复杂造物、掉落物、关卡实体、玩家模板与复苏、职业模板、阵营、单位标签。
当前覆盖：prefabs create/convert（动态/静态）、entities import/export、aux 装饰物、level-variables、custom-variables（玩家/角色初始变量 syncInstances）。
未覆盖：元件组规则、造物行为配置、掉落物、职业模板配置、阵营关系配置、单位标签。

### C. 功能与通用组件（C 体系）
变量体系（自定义/节点图/技能变量，全21类型）、数据结构（字典/结构体）、全局计时器、单位状态效果池、碰撞触发器/源、特效播放、自定义挂接点、音效播放器、货币与背包、战利品、铭牌、文本气泡、装备系统、扫描标签、小地图标识。
当前覆盖：变量读写（assets:custom-variables/level-variables）、dict 编码；名称引用绑定、组件类型映射部分闭合（见 components.md）。
未覆盖：组件级配置命令（特效/音效/铭牌/气泡/装备/扫描/小地图/单位状态/碰撞触发器）。

### D. 外围/资源/技能/其它系统（D 体系）
外围：排行榜/竞技段位/成就/关卡结算/奇域礼盒/奇域任务/先行体验/奇匠订阅。
资源：道具/装备/货币/背包/掉落物/商店。
技能：技能定义与编辑、复杂造物技能、技能变量/属性组/预瞄准/操控技能；职业/单位状态/预设点/护盾/路径/特效器。
其它：局内存档、多语言、语音文字聊天、BGM、环境配置、元件组、场景生成模板。
当前覆盖：客户端图七类（characterSkill/characterControlSkill/creationSkill/creationStatus/creationStatusDecision/boolFilter/intFilter）可编译；成就/排行榜等节点若有 DSL 生成即可用。
未覆盖：资源/商店/掉落/职业/外围系统的 CLI 配置命令。

### E. 节点图基础
节点图类型（服务器/客户端）、挂载生命周期、控制流/数据流/信号/复合节点（见 game-engine-knowledge index 知识关系图）。
当前覆盖：gsts 编译注入全链路、assets:node-graphs create/read/patch、mounts、signals、definitions 全量 DSL。

## 联动关系（用户口述 + 样本印证）

| 联动 | 机制 | 样本 |
| --- | --- | --- |
| UI <-> 节点图 | 事件（界面控件组触发/悬浮页操作触发）+ 节点（唤起/关闭/改状态/更新列表） | 推箱子玩家发言/存档点按键 |
| UI <-> 变量 | 富文本{类型:前缀.变量名}实时更新；动态引用图片源；自定义变量驱动 | 官方指南+推箱子「快捷消息」「第三人称」 |
| UI <-> 元件 | UI 显示元件变量；单位状态展示/特殊数字监听 | 官方指南（特殊数字/状态显示区） |
| 元件 <-> 节点图 | 动态创建元件、挂组件、机关逻辑 | 推箱子机关/平台/传送门 |
| 镜头 <-> 节点图 | 切换主镜头/跟随 | 推箱子 Switch Main Camera |
| 技能 <-> 节点图/UI | 技能槽位监听（特殊数字/交互按钮技能类型）；客户端技能图 | 精确输入检测/点击事件响应资产 |

## 覆盖率结论（初表）

- 高覆盖：控件基础（文本框/图片/按钮/布局读）、素材库、变量、节点图 DSL、实体基础创建
- 中覆盖：悬浮交互页（骨架）、按钮状态读、信号、挂载
- 低/缺：16+ 控件类型（特殊数字/道具展示/开关/弹窗/卡牌/进度条/计时器/计分板/图文输入框/状态显示区/消息队列/动效控件）、组件级配置、外围系统、资源系统、阵营/职业/标签

## 评估方法（本轮更新）

1. 以本全景为基准，每个探索样本登记：用了哪些构成块（A-E）、哪些联动、现有 CLI/DSL 覆盖与否。
2. 登记本：ui-coverage-exploration-log.md（做得好/覆盖/缺陷/不清楚）。
3. 先手选样本完整探索（容错高）→ 试点后批量扫描 → 异常点单点深挖。
4. 批量阶段按「构成块 x 支持状态」生成覆盖矩阵表。
