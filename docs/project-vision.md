# 项目愿景与目标（genshin-ts）

> 状态：长期目标（2026-08-14 用户定义）
> 适用范围：所有工作方向——做 demo、生产补强、技能迭代、知识录入都应服务于本愿景

## 本质：自进化能力的锻炼

与其说是在做这个项目，不如说是**一边做、一边扩充项目的能力**。
我们当前做的每一件事——游戏 demo 实现、技能的使用/迭代/优化、文档更新、游戏引擎知识理解——
本质上都是在**教会大模型如何做游戏**。

## 短期目标（当前执行中）

1. 一边实现游戏 demo（rubik-2x2 等），一边**补充现有游戏代码生产能力的缺陷与 bug**；
2. **技能更新**：每轮沉淀的方法论回灌到技能（debug-log-investigator、gil-node-graph-reading、
   gil-node-graph-editing、static-gil-model-builder、verify-injection、game-from-scratch 等）；
3. **知识落盘**：游戏引擎规则进 docs/game-engine-knowledge + PKC 知识树。

## 中期目标

**让大模型能够触及游戏这个行业**——具备从玩法想法到可玩 demo 的完整闭环能力
（建模/资产/节点图逻辑/调试/验证/知识复用）。

## 长期目标

完整建立一套**资金化和学习的机制**——
把"做游戏的能力"沉淀为可积累、可复用、可持续进化的资产（技能库/知识树/通用复合节点资产/生产能力）。

## 执行原则

- 每轮：做 demo → 发现生产缺陷/bug → 修复 + 记录 → 方法论回灌技能 → 知识录入。
- 复合节点等可复用资产：能复合的一定复合（不亏 → 复用赚 → 跨项目大资产）。
- 防丢失：任务顺序/发现/愿景写入文档（防止对话丢失，下一迭代可续）。
