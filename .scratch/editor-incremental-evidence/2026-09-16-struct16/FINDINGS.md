### C7 结构体定义记录 = **root10 的 `f6` 记录，一个结构体一条**（第一轮未定位到）

第一轮只知道「root10 子记录 +1」，本轮**两条 `f6` 记录 = 两个结构体**，形状完全一致：

```
root10.f6 = {
  f1 = { f1: <structId>  f3×N: <成员>  f501: "<名>"  f502: 1  f503: <V> },
  f2 = { …与 f1 逐字节相同的镜像… },
  f3 = <V>  f4 = 2  f5 = 1
}
```

**`f1` 与 `f2` 是同一内容的镜像对**（v1 两条均 151B；v2 分别 151B / 150B）。外层 `f3` == 内层 `f503`。

### C8 结构体 id 空间与「序号」在第二样本上的表现

| 结构体 | id | 名字 | 成员数 | 结构级 `f503` |
|---|---|---|---|---|
| A | 1077936129 | 测试结构体名称 | 2 | v1=**2** → v2=**3** |
| B | 1077936130 | 结构体测试test2 | 2 | v2=**2** |

→ **id 顺延 +1 确认**（C2 加强）。但 **A 的 `f503` 在 B 出现后从 2 变成 3**——
即**编辑器在新增结构体时会改写既有结构体记录**（A 的记录仍是 314B，只变了这一个字节）。

### ❓ 未闭合（本轮唯一未解释项，不猜）

`f503`（及等值的外层 `f3`）的语义**不确定**。已排除的假设：
- ✗ 「成员数+1」：A 有 2 成员却是 3，B 有 2 成员却是 2；
- ✗ 「结构体总数+1」：v2 有 2 个结构体，A=3 符合但 **B=2 不符合**。

**待验假设**：该值可能是「**创建该记录时的全局计数**」——A 在 v1 时写 2，v2 被改写为 3；
B 创建时写 2 但**尚未被改写**。若如此，再保存一次（不做任何修改）应使 A、B 两值趋同。
→ 需**第三个样本**（再建一个结构体，或原样再保存一次）才能判定。

### C10 方法论：**差分配对假象**（本轮实测踩到）

`gil-quick-diff.py` 的紧凑文本输出把 `f6` 记录渲染成
`- 314B …结构体A… / + 312B …结构体B…`，**看起来像「A 被替换成 B」**。
实际用 `compare-level10-containers.ts` + `gil_wire_lib` 定点复核后：
**A 的记录仍在（314B），B 是新增的（312B）**——那是**按 index 配对重复 occurrence** 造成的显示假象。

→ **纪律强化**：紧凑差分文本**只能用来发现「哪里变了」，不能用来断定「什么被替换了」**；
凡出现 `-X / +Y` 长度相近的配对，必须用定点工具按 occurrence 复核一次再下结论。
（技能已有「重复字段必须按 occurrence 比较，不能按字段号去重」——本条是它在**展示层**的同类陷阱。）
