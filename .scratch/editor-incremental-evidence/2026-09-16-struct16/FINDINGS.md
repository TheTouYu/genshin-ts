### C4 结构体类型的引脚引用方式 ← **票 17 直接要用的**

### C5 建结构体会「物化」结构体节点族到地图

root10 新增 **9 条节点定义**（+1 结构体定义）：`拼装结构体` / `拆分结构体` / `修改结构体`，
且**为多个图类型各注册一份**（差分中可见 `f2=20000 / 20001 / 20002 / 20007` 四族）。

节点定义结构（以拼装结构体为例）：
```
f4{ f1{f1=10001 f2=20000 f3=22001 f5=1610612737} f2{...} f4{} }   ← 签名/id
f102{"新增变量1" …} f102{"新增变量2" …}    ← 成员变成输入引脚（f102=input，f103=output）
f103{"测试结构体名称" … f4{f1=10001 f3=25 f4=25 f104{f2=1077936129}} …}  ← 输出引脚 = 结构体类型
f107{...} f200="拼装结构体" f203=5 f204=4
```

**含义**：结构体的成员会**驱动节点引脚**——所以节点定义必须物化到地图（内置定义无法预知成员）。
