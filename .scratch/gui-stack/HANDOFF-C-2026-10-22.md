## 5. 执行配方（拿到用户的第一个点之后）

```bash
cd /home/h/genshin-ts

# ① 只读取一次当前世界状态（零占屏，离线帧不碰游戏）

tools/ys-editor/ys-session begin --seconds 90 --task gui-agi-C \
  --reason '<做什么>' --user-said '<用户原话>'

# ③ 动作（示例：按键，走 ys-key 而不是裸注入）
tools/ys-editor/ys-key --help

# ④ 收尾必须交还
tools/ys-editor/ys-session end
```

**判据**：每步之后用 `worldsvc look --summary` 或 `ys-read` 复验；`ys-session end` 后 `ys-screen-grant status` 应为 NO_GRANT，`ys-wins --attrib` 里 firefox 应 `ACTIVE`。

**失败解读**：`NO_GRANT` = 没走 `ys-session begin`；`ATTRIBUTION_OTHER_DESKTOP` 在 begin 后第一次 look 可能发生，重试 1–2 次即可（已知竞态）。
