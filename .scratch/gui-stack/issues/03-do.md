## What to build（用户视角端到端）

不再"点一个坐标然后祈祷"：用**意图**驱动，每个意图自带前置态、定位、后置态；
每一步都进**账本**。今天"跑完一轮不知道哪环断了"从此消失。

```
$ ys-do playtest-start
[1/3] 前置态=MENU ✓  定位=试玩磁贴(模板 0.98) → 点击(183,389)  后置态=OK ✓
[2/3] 前置态=—       定位=直接上传(模板 0.96) → 点击(1444,811) 后置态=OK ✓
[3/3] 前置态=—       定位=开始游戏(模板 0.97) → 点击(1280,1052) 后置态=PLAYTEST ✓
账本：~/ys-round/<ts>/ledger.jsonl
```

## 验收项

- [ ] 存在**动作定义表**（`actions/*.json`：`{intent, pre, steps[{locate, do}], post, artifacts}`）
- [ ] `ys-do playtest-start` 成功，账本每行含 `意图/前置态/定位来源与置信度/实际注入的事件/后置态/判定/证据图`
- [ ] **失败场景**：人为把 Firefox 置顶后跑 `ys-do playtest-start` → 明确 `FAIL` + **账本行号** + 前后证据图，
      且**不继续往下点**
- [ ] 所有注入强制经 `ys-gui-slot`（代码里不存在裸 `ydotool` 调用；shim 层兜底）
- [ ] 账本 append-only JSONL，`jq -c .` 逐行可解析
- [ ] **不存在没有 `post` 判据的动作入口**（构造一个缺 post 的 action → 加载时即报错）
