## 实施中挖出的真 bug（比票本身更值钱）

**`ncc` 在平坦块上返回天文数字**：`np.maximum(den*Tn, 1e-9)` 把"**未定义**"变成"**巨大**"——
实测一张深蓝紫的存档页让 40×40 侧栏模板报出 `score=4055667456`，而 `score >= 0.9` 的阈值
把它**当成命中** ⇒ 「侧栏图标 ⇒ 系统菜单」这条判据在存档页/结算页全部误触发。

修法（fail closed）：有效性判据改为「**搜索块与模板各至少有 1 个灰阶的标准差**」（`MIN_STD = 1/255`），
未定义一律记 0；结果再 clip 到 [-1,1]。CPU 与 GPU 两条路径同修。

**这个 bug 不止影响本票**——它影响一切用 `ys_look`/`ys_match` 做模板判定的地方（含 `ys-where2`）。
