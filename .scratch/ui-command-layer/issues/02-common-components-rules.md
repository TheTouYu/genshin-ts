**What to build:** 最终需求涉及的常见 UI 组件学到「能判别 + 能读属性 + 能基础创建」的程度：优先 ①独立文本框
（非素材内联版：富文本/<color>/<b>/{1:ps.变量} 插值）；②独立图片控件动态引用形态（道具/状态/技能/单位状态）；
