# 01 — 按钮族规则学习（布局 + 悬浮页 + 判别 + 细排特征）

**What to build:** 「按钮」这个 UI 对象族的编辑器规律全部学到 CONFIRMED 并落盘——玩家/AI 从此能看懂一个按钮在
.wire 里是什么、在哪、什么属性、怎么加怎么删。覆盖：① 界面控件中添加自定义按钮进默认布局（官方预制 vs 自定义模板
两分支，含「哪个字段=可点击按钮」判别规则）；② 按钮属性逐项差分（文本/字号/颜色/图片源/缩放/位置/尺寸/锚点，含
坐标换算复核）；③ 删除按钮的引用链清理规律（布局 packed/模板 back-ref/素材组/容器成员）；④ 悬浮交互页详情中添加
第二个自定义按钮（与既有按钮同型对照）+ 四态素材（常态/悬停/按下/**禁用**）配置 + 同步到模板；⑤ 玩家细排读回特征：
同一按钮「脚本产物 → 玩家手动改位置/文本/颜色」在字节上表现为哪些字段变化。学习是高效块：一轮可连续学多个差分/
多条小规则，轮次逐条记在本票「轮次记录」，不拆子票。
