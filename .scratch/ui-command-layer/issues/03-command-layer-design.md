# 03 — UI 命令层设计稿（学习收口 → 命令面定案）✅

**What to build:** 把 01/02 学到的规则整理成「规则 → 命令」映射并产出冻结的设计稿：AI 像游戏引擎分层设计一样操控 UI。
覆盖四能力：① List（列出玩家加了哪些按钮/组件，含类型/布局归属/属性摘要）；② 玩家改动识别（相对上次状态的差异报告：
新增/删除/改了哪些属性——把「脚本产物 vs 玩家细排」特征转成判定）；③ Create（一键创建按钮，位置大致正确、常用属性设好，
玩家细排收尾）；④ Edit / Delete（属性编辑、删除+引用链清理）。设计稿必须定：命令面语法与语义、分层（用户视图 → 记录层 →
字节层）、AI 默认值与玩家保留字段策略、备份/回滚、防编辑器自动补全与旧内存覆盖的流程、核验方法（字节级 compare + 游戏内
验收句式，沿用仓库证据分层：编辑器观察/回读/写回/游戏行为分开报告）。用户裁决后本票才算完成，设计稿是 04-07 的唯一实现依据。
