# 静态 UI 语义资源覆盖度分析

> 日期：2026-09-05
> 输入：`resources/ui_semantic_names.json`（由 AnimeGameData CN7.0.0 beyond_excel + TextMap 生成）
> 对照：`docs/capability-coverage-map.md` A 体系 20 控件类型 + 现有 UI wire 知识

## 静态表能覆盖什么

| 静态表 | 覆盖对象 | 能回答的问题 |
|---|---|---|
| `presetAssets` (24) | 300/310/320/330 预设样式 | 按钮/开关/页签/背景的“预设 ID → 中文名” |
| `imageTypes` (15) | 自定义图片素材类型 | 底板/功能图标/玩法图标/装饰/基础形状/特殊字符/技能天赋/道具/造物/自定义素材等 |
| `imageTags` (21) | 图片素材标签 | 地区/主题/通用/战斗/状态等筛选标签 |
| `imageIcons` (1543) | 自定义图片素材库 | 素材库 ID 100001+ 的分类/标签/排序 |
| `uiEffectCategories/Tags/Effects` | UI 特效 | 循环/非循环、元素/颜色标签、特效 ID 名称/时长/图标 |
| `TextMapCHS/EN` | 所有 UI 文案 | hash → 中文/英文 |

## 对 A 体系 20 控件类型的覆盖判定

| 控件类型 | 静态表能否覆盖 | 说明 |
|---|---|---|
| 文本框 | 🔶 部分 | 文本内容来自 TextMap/富文本，但控件 wire/结构不由这些表覆盖 |
| 图片 | ✅ 部分 | 素材类型/标签/图标库可解析；图片源 6 种语义仍需 wire |
| 界面动效/全屏界面动效 | ✅ 较全 | `uiEffect*` 可给类别/元素/颜色/名称；但“控件动效”的挂载 wire 仍需差分 |
| 特殊数字 | ❌ | 静态表无对应预设/类型表 |
| 交互按钮 | 🔶 部分 | `300xxx` 只给预设按钮样式名；交互/技能/道具语义无 |
| 道具展示 | ❌ | 无 |
| 自定义按钮 | ✅ 部分 | `presetAssets 300001-300010` 给样式名；wire 仍走已有 t50/t52/t54 |
| 自定义开关 | ✅ 部分 | `presetAssets 310001-310004` 给预设名；六态 wire 未差分 |
| 弹窗 | ❌ | 无 |
| 悬浮交互页 | 🔶 部分 | `320001/330001` 等至少覆盖“页签/背景预设”命名；页内容器/列表 wire 仍靠差分 |
| 卡牌选择器 | ❌ | 无 |
| 进度条 | ❌ | 无 |
| 计时器 | ❌ | 无 |
| 计分板 | ❌ | 无 |
| 图文输入框 | 🔶 部分 | 图片素材库可用；输入框 wire 已靠轮 19-23 闭合，非本表 |
| 状态显示区 | ❌ | 无 |
| 消息队列 | ❌ | 静态表无；已有轮 51-63 wire 知识 |
| 界面布局 | ❌ | 无预设名表（布局是实体容器，不是 30/31/32/33） |
| 界面控件组库 | ❌ | 无 |
| 素材库 | ✅ 较全 | `imageTypes/Tags/Icons` + `uiEffects` 可支撑素材库 list/filter |

## 结论

1. 静态 UI 表主要覆盖 **“预设/素材/特效的命名与分类”**，不是“控件 wire 结构”。
2. 对**还没差分的控件**（特殊数字、道具展示、弹窗、卡牌选择器、进度条、计时器、计分板、状态显示区、界面布局、控件组库）：
   - 静态表**不能**直接给出 wire 结构；
   - 只能提供可能的预设名/素材分类辅助，仍需最小差分或样本资产探索。
3. 对**已差分过的控件**，静态表能显著提升可读性：
   - `300001` → 预设按钮_1、`300009` → 预设按钮_9；
   - `310001` → 预设开关_1；
   - `320001` → 预设页签_1；
   - `330001` → 预设背景_1；
   - 图片类型/标签/特效类别同理。

## 建议

- 先把 `resources/ui_semantic_names.json` 接入 `assets:ui list` 的“名称解析层”：
  list 输出控件时，如果其样式/类型落在 preset/image-type/ui-effect 表内，自动附 `decodedName`。
- 未覆盖控件仍走“样本资产 + 少量差分”路线；静态表作为辅助，不能替代差分。
