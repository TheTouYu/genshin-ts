# T01 · 关键词扩张式检索 → 信息源库 + 关键词库

**Status**: ⬜ 未开工
**Blocked by**: —
**目标（用户视角端到端）**: 当我要学「千星奇域怎么做出优质游戏」时，我有一份**完整的信息源库**（B站教程 + 官方 KB + 社区资源包）和一份**从检索结果里长出来的关键词库**，能证明我已穷尽公开信息源，而不是随手搜了几个词。

## 为什么要做这一步

用户明确要求：**"你应该学着用更多的关键词、相关的关键词去找到更多的信息和信息源，然后再用更多的信息去检索，这样子就会拿到一个完完整整的高质量的知识。"**
→ 检索本身是**迭代扩张**过程，不是一次性动作。本票就是把这个过程固化并留痕。

## What to build

1. **播种词**（≥12）：来源三处——官方指南章节目录（`docs/ui-tutorial/`）、我方既有知识域（`docs/game-engine-knowledge/`、`docs/composite-library/` 21 类）、用户维度提示（设计思路/引导/难度/高级节点/邪修/隐秘知识）。
2. **B站多轮检索**：浏览器内 fetch `x/web-interface/search/type`，落盘**原始 JSON**（不加工）。
3. **关键词生长**：从每轮结果的 `title` + `description` 提取共现词 → 生成下一轮检索词。
4. **收敛判定**：连续两轮新增源率低于阈值（或无新词产出）即停，并**记录收敛证据**。
5. **官方 KB 映射**：305 篇按域登记，`official/tutorial` 85 篇全部进候选源。
6. **评论区采集**（邪修/隐秘知识的富矿）：对高相关视频取 `x/v2/reply/main`，提取战术性评论。

## 验收项（全勾才可收轮）

- [ ] 播种词 ≥12 个，每个附来源（官方章节 / 我方文档 / 用户提示）
- [ ] 第 1 轮 B站检索完成，原始 JSON 落盘 `research/千星知识图谱/search/round1-*.json`
- [ ] 从第 1 轮结果提取第 2 轮检索词 ≥20 个，附命中依据
- [ ] 第 2、3 轮检索完成，关键词库落盘
- [ ] 收敛判定有证据（新增源率曲线 + 停止理由），**不是"搜够了"这种主观话**
- [ ] 官方 KB 305 篇完成域映射登记
- [ ] 高相关视频（≥N 个）评论区已采集并提取战术性内容
- [ ] `research/千星知识图谱/SOURCES.md`：**全量**源清单（不抽查），字段=类型/标识(BV或文档路径)/标题/作者/时长/播放/相关度初判/目标域
- [ ] `research/千星知识图谱/KEYWORDS.md`：关键词库（词/命中源数/产生轮次/父词）

## 反模式

- ❌ 只搜 3-5 个词就宣称"检索完成"
- ❌ 抽样看结果后断言"就这些了"——必须全量落盘
- ❌ 关键词靠我拍脑袋编，而不是从检索结果里提取
- ❌ 只取视频不取评论区（邪修/隐秘知识大量在评论里）
