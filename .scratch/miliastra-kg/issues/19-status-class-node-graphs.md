### ⚠️ 过程中抓到并修掉的两个检测器缺口（比主功能更重要）

CLI 报 `type=20003(状态)`，**但产物里 type 是 20000**（wrapper 写死 `GRAPH_TYPE`）。
`verifyNodeGraphReadBack` 放行了，因为它**只验「图在 root10」+「folder 有条目」，从不核对类型号**。
已补：① 回读核对 `Id.f2 == spec.type` ② 回读核对 folder `typeValue`。

**同族教训（第三次）**：读了输出却没核到关键字段 —— 前两次是读 `kind` 得 `SysCall`、看 6.7KB 残缺文件。
**定则：回读必须声明「要核哪几个字段」，而不是「产物存在即通过」。**
