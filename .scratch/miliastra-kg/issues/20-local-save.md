# 20 — 局内存档：从零到可用的存档通道

**What to build:** 一个玩法能把玩家进度存下来、下次进游戏读回来。官方名「**局内存档**」，
必须用**结构体列表**，且**每次只能启用一个模板**。

**Blocked by:** 17（结构体变量落地）+ 18（结构体 DSL API）。**另有一条外部门槛**：讲师称局内存档为
**LV4 专属**，官方文本未载（后由图谱 K6 专题三处互证为真）——若确实需要等级门槛，**用户账号需满足**。

**Status:** ⬜ 待开工

---

## 起点（写票时实测）

`grep -rn "局内存档" src/ tools/` = **0 命中** —— 全库零覆盖。

官方约束（`docs/ui-tutorial/official-guide-concepts.md:10542-10590`）：
- `:10548` 定义；`:10552` **需用结构体 + 自定义变量**；`:10558` 每次只能启用一个模板
- `:10566` **局内存档结构体不支持实体 / 实体列表 / 所有类型字典以及结构体**（嵌套被禁）
- `:10587` 「局内存档变量与常规自定义变量的用法完全相同」

官方上限（`official-guide-auxiliary-appendix.md:2125-2160`）：局内存档模板 10 / 单个局内存档结构体 100 /
数据内结构体长度 200 / 单关卡局内存档大小 10000 / 试玩数据 50。

南航课程 P3 的两个坑（讲师实测）：**默认值不能直接改、须在初始化时拼装**；
**玩家首次进游戏该结构体列表长度为 0**，需在「实体创建时」判空后用拼接列表 + 拼装结构体塞入开局存档。

## 验收项

- [ ] 差分闭合局内存档模板的 GIL 编码（同 16 手法）
- [ ] CLI 能创建/列出/启用局内存档模板
- [ ] 遵守 `:10566` 的类型禁令（实体/实体列表/字典/结构体全禁）——**fail closed，不猜**
- [ ] 最小样例：一个计数字段存下来、重进游戏读回
- [ ] 处理"首次进游戏列表长度为 0"的初始化分支（南航课程 P3 实测坑）
- [ ] 核对官方上限表，超限 fail closed
- [ ] 游戏内核验（需用户）
- [ ] 收轮三件套

本票是四个候选里**成本最高**的（依赖 17+18 + 可能有等级门槛），排在最后。
