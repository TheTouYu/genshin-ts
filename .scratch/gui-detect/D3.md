# D3 结构层 v1（对象列表 → 组 / 容器 / 类别 / 缺行槽）

> 输入 = D2 的对象列表 `{objects:[{id,bbox:[x,y,w,h],kind,score}]}`（无像素、无 OCR）。
> 代码：`.scratch/gui-detect/d3_structure.py`（v0 存档 `d3_structure_v0.py`）；评测 `d3_eval.py`。
> 日期 2026-10-19。**未 commit**。

## 0. 一句话结论

**"全帧一个 pitch" 是伪命题**：pitch 是「每组一个常数」。v1 改成"先找节奏链、再逐链估 pitch"，
parent/group 配对 F1：编辑器 0.37/0.18 → **0.78/0.58**，游戏 0.48/0.37 → **0.91/0.88**；
删行/丢框/抖动下 pitch **完全不变**（v0 会从 48 漂到 64~74）。

## 1. 算法（全几何，五步）

1. **行带**（`cluster_rows`，v0 沿用）：y 中心聚类，`y_tol=10`、`h_tol=0.30*h`，只留 ≥2 成员的带 —— 只作上下文（同行高度、槽位邻行），**不再当 pitch 来源**。
2. **节奏链**（`find_chains`，v1 核心）：对轴 y/x 各跑一次。任两件为种子（同尺寸 `h` 差 ≤8%、交叉轴首沿差 ≤6px、间距 ≥6px），向上延伸：`|d - m*p0| ≤ max(2, 0.03*m*p0)`、`m≤3`（**允许中间缺位**，记进 `missing`）。质量闸门 `pstdev(gaps) ≤ max(2px, 5%*pitch)`（真值组内实测 ≤2%，给 D2 抖动留余量）；去子链留极大链。
3. **垂直链 × 水平链相交 → grid**：共享成员的横竖链并成一组（r003 的 4×5 格阵否则会被拆成 4 竖链 + 5 横链）。
4. **容器 + 归属优先级**：候选 = 检测到的 `panel` 框（>0.4% 画面）∪ 相邻组的竖排并集（横向重叠 ≥50%、竖距 ≤max(1.2*pitch, 1.2*组均高)）∪ **检测到的 `row` 对象**（≤25% 画面且含 ≥2 件）；加内边距 `3%*max(w,h)`（≥8px）；**丢弃面积 ≥75% 画面的底板**。
   对象归属优先级 = **detected panel > group_union > row**，同级取面积最小（见 §2.1：这是编辑器 R 从 0.54 提到 0.75 的唯一原因）。
5. **类别修正**（`fix_kind`）：**只在 icon/tile/chip 三类间改**。tile 矮于同行且 ar≥2.2→chip；chip 高于同行 1.15 倍且近方形（实测 143×93）→tile；icon 但 ≥120×90 近方形→tile；tile 但 ≤72×72→icon。
   - **反例（踩过）**：v0 式"小方件 ≤72 且近方形→icon"在工具栏里把 **153 个 button 改成 icon**，净损失。**工具栏的 button 与 icon 几何同构，尺寸不能区分二者。**

### 2.1 行对象当父：已实现，实测**不是** R 的病根

按裁决实现（`--no-rows` 可关），三种归属策略实测（parent F1，18 帧）：

| 归属策略 | v8-editor | v8-game | 结论 |
|---|---|---|---|
| 面积最小（v1 初版，行对象也算容器） | 0.65 | 0.89 | 推断小容器抢走了真父 |
| 行优先（行容器压过一切） | 0.73 | 0.87 | **更差**：有 panel 时切到行会打断跨行同父配对（r022 0.87→0.56、r045 0.52→0.26） |
| **detected panel > 组并集 > 行**（现行） | **0.78** | **0.91** | ✅ |

- 逐帧看，行父只在**没有 panel 容器**的地方赢（r021 好友列表 0.49→0.59、r044 0.39→0.50、r006 0.72→0.80），在有 panel 的帧一律输（r022 −0.31、r045 −0.26）。所以行对象放**最低优先级**。
- 真结论：编辑器 R 卡住的真原因是**容器归属优先级**（推断的小组并集抢在真 panel 前面），不是"缺行层级"。

## 3. 评测边界（口径固定）

1. **D3 的输入固定为"给定对象列表"**（干净输入 = truth 对象）。D2 的检测可靠性单独报（bbox P/R / IoU 匹配率），不混进 D3 的结构指标。
2. **parent 只评 truth 里有 parent 的对象**；没有 parent 的对象不参与配对（既不算 TP 也不算 FP）。
3. **group 只评 truth `groups` 里出现的对象**（4 帧游戏界面有 group 真值）；对象不在任何组里就不评。
4. 配对口径：同组=正例；`P = TP/(TP+FP)`、`R = TP/(TP+FN)`、`F1`；pred↔truth 一对一贪心匹配 IoU≥0.5（干净输入时全部匹配）。
5. 真实 D2 输出（`truth-v9-pred`）与 truth 帧**不是同一次标注**（r028 的 116 框只匹配上 28 个，容器 P≈0，只找到 2 条链 @16）→ 该套 pred **不可用于评 D3**，只能评 D2。

|---|---|---|---|
| r003 | 2 | 6.6% | 1/2 |
| r013 | 2 | 25.0% | 1/2 |
| r021 | 4 | **0.1%** | **4/4** |
| r022 | 2 | **0.1%** | **2/2** |
| **合计** | **10** | **3.3%** | **8/10 = 80% ✅ 达标** |

r022 的 g4 是 4×2 网格，真值同时给 `col_pitch=172.0`/`row_pitch=213.0`；第一版评测只比 row 把正确命中的列节距算成 19.2% 错误（**评测口径 bug**），已改成两轴取更近者。未过的 2 组：r013 25%、r003 6.6%（链配对选了重叠成员另一条链）。

### 4.2 帧级 pitch **不要再用**

r028 真值右属性面板 14 个 row 的行距实测 `22,28,45,45,47,50,59,59,77,78,79,97,128`（中位 59，行高 28~34），左树列 16~24。**任务书里的 48.0 是 v0 行中位数在整帧上的聚合产物**。拿它卡 5% 会奖励错的估计器：v0 在干净输入上恰好 47.25（1.6%），丢 25% 框+抖动后变 64（33%）。**帧级 pitch 这个 KPI 作废。**

## 5. 几何先验失效的具体边界（实测）

1. **全帧不存在单一 pitch**（§4.2 实测行距）；帧级聚合值不可当验收线。
2. **pitch 只在组内是常数**：组内 std ≤2%（7/9 组 ≤1px），组间 166~416。任何"整屏 spread"都是组间差伪影。
3. **gap/pitch 分两档**（0.077~0.19 整行/整格；0.33~0.51 行内小件），中间没有值 → 可作链分类先验（未接，TODO）。
4. **父容器 ≠ 节奏组**：真值 parent 可以是 row 对象；组可以是"行间方向"的列（行内头像列/动作钮列/私聊气泡列）。
5. **整屏底板必须丢**（≥75% 画面）：r021 的整屏 panel 会吞掉所有配对，P 0.44→0.19。
6. **工具栏 button 与 icon 几何同构**（40×40 近方形）。
7. **槽位只能从"链中间缺位"推**：整块面板漏检时链根本不存在，纯几何无从推断 —— **这不是 D3 的缺陷，是 D3 的边界**，需要 D2 或第二条通道。

## 6. 未过 / 卡点（如实）

- **槽位**：误补 ≤1 处/帧 ✅（6 个编辑器帧合计 6 个）；但"补出的槽 ≥ 实际漏检行数"**没达成** —— r028 真值漏 7 行，D3 只补 3 个（原因见 §5.7）。
- **逐组 pitch 2/10 组超 5%**（r013/r003），修法：配对时按"成员重叠率 + pitch 一致性"联合判。
- **group R（编辑器 0.45）偏低**：`group_of` 只认节奏链，容器覆盖的对象没有组身份 → 跨容器配对丢分。
- **类别修正增益小**：真实 pred 上 kind 0.78→0.80 / 0.79→0.82；真实混淆以 `row→unknown/panel` 为主，不在 icon/tile/chip 三类内。

## 7. 运行

```bash
# 结构输出（CLI 与 v0 兼容）
python3 .scratch/gui-detect/d3_structure.py --truth-dir .scratch/gui-corpus/truth-v8-game --json-out /tmp/d3.json
python3 .scratch/gui-detect/d3_structure.py --truth-dir <dir> --eval        # 自带 parent 自评
python3 .scratch/gui-detect/d3_structure.py --truth-dir <dir> --no-rows    # 关掉行对象当父（对照）
# 评测：parent / group / kind / pitch / 槽位，编辑器与游戏分开汇总
python3 .scratch/gui-detect/d3_eval.py --all
```

参数：链种子同尺寸 8%、首沿 6px、节距 3%；链质量 pstdev ≤max(2px,5%)；容器内边距 3%（≥8px）；底板阈值 75% 画面；归属优先级 panel > group_union > row。
