## 结论

**第一个最近 30 天未上线的好友 = 匿叶龙（Lv.60，31 天前最后登录）**；
它在列表中的上一条是 **朵朵（26 天前）**，所以「≥30 天」的边界就落在这一对相邻行上。

## 旁证（同一帧序列里读到的其余 31 天好友，均在匿叶龙之后）

`Violet / 莘 / 闲鱼真的闲 / 爱吃小蛋糕 / Alastor / Shiroha / 大佬 / 夏超 / 林益航 / 琪亚娜·卡斯兰`（Lv.60），

⇒ 若只报「任意一个 31 天的」，会报出一串；判据必须是**列表顺序里第一个**，而排序口径 =
先按冒险等阶降序、同阶内按最后登录时间降序（与 D410 一致）。

## 已知不确定与缺口（见报告「能力缺口」节）

- 模块不提供「列表里的第几条 / 当前滚动位置」，`31天前` 是显示上限值（≥30 均显示 31），故只能判「≥30 成立」，判不出精确天数。
- 好友面板/角色面板在状态机里都落 `GAME_WORLD`（粗判据假阳性）——本任务的界面身份是靠 free_text 文本确认的。
