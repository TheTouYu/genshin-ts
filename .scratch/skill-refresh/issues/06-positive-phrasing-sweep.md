# T06 · 正向表述 sweep（20 个游戏技能）

**What to build**：按用户令（2026-10-17 通用准则），把游戏技能里"禁止/不要/别/不能"式表述改写成"要 X"式。

- Blocked by：无（可与 T04 并行，但**同一文件不并发**）
- Status：⬜

## 验收
- [ ] 先出**清单**：`grep -c "禁止\|不要\|别\|不能"` 逐技能计数，按命中数排序（只为"可改成正向句"的条目动手）
- [ ] 逐条问判据：**"这句能给出动作吗？"**——能 → 改成正向句；纯边界声明（如"fail closed 不猜字节"这类安全红线）→ 保留
- [ ] 每改完一个技能跑一次 `grep` 复测，读数入票
- [ ] 安全红线类（写回 fail-closed、不得覆盖用户存档、注入确认制）**保留原样**并在票里记录"刻意保留"
