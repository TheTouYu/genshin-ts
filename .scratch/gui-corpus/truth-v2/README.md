## 方法（可复算，且与 ys-screen 无关）

- 结构边界：`.scratch/gui-corpus/tools/edges.py` 沿**平坦带**扫描线找亮度跃变（输出文字不是图）；
  规则网格再用 `.scratch/gui-corpus/tools/remeasure_grid.py`（低亮度同色连通域）复核。
- 小图标/头像/铅笔：`.scratch/gui-corpus/tools/boxer.py` 量像素紧致边界。
- 身份与"算不算一个单元"：`read_image` 人眼判定。
- 最后才跑 `tools/ys-screen`（只读）做**"我漏了什么"**对照，结论写进各帧 `_provenance.tool_crosscheck`。
