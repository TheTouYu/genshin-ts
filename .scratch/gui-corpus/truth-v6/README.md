## 三、我这批改了 `audit_truth.py` 的第 3 处口径（必须报告）

**OCR 的 `text[].bbox` 是 `xyxy`**（同一对象另给 `w`/`h` 字段），而上一版按 `[x,y,w,h]` 解释 ⇒
框被放大成 `x..x+w`，把**已标好**的行判成漏标（v6 首跑 r022 报 6 处、r044 报 5 处未覆盖，全是假阳性）。
现改为**用自带 `w/h` 字段判别口径**，缺字段按 xyxy 兜底。修完后 r022 6→1、r044 5→1，剩下的都是 HUD 碎片。

> 这是本项目**第三次**踩"bbox 口径"（前两次：ys-screen containers=xyxy vs schema xywh；
> OCR 高框当单框覆盖）。共同教训：**跨工具传 bbox，先用自带 w/h 或数值关系验证口径**。
