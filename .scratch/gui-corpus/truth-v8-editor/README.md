## 方法（切块标注法）

1. 概览切 5–8 块（`grid.py --crop ... --step ... --scale ...`，标签=原帧坐标）。
2. 每块用 `edges.py` 量面板/行边界；JPG 压缩会造伪边，故多条扫描线交叉（r032/r034 属性面板左沿 x=2080 由 y=250/300 两条线一致确认）。
3. 文字用 `inbox/repjson/*.json` 的 `text[].bbox`（**xyxy**，另带 w/h 可判口径）逐行落到行框。
4. 无文字边界的元素（滑轨、开关、+ 按钮、片段条）用颜色 run 扫描或 1:1–2× 裁图现读，并在 `_provenance.uncertain` 写明 ±px。
5. 汇总去重（IoU≥0.5 留大者）后全图 overlay 人眼复核，按 R1–R10 补缺。
