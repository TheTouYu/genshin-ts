| 指标 | 读数 |

**分区命中（IoU≥0.5）** —— 这张表是结论核心：

| 区域 | 命中/真值 |
| --- | --- |
| 右侧属性面板 | **0 / 35** |
| 模型资产库弹窗 | **0 / 17** |
| 左侧树行 | 5 / 29 |
| 调色板卡 | 3 / 11 |
| 顶栏 | 5 / 10 |
| 视口/底部 | 9 / 11 |

**结论：两者兼有，但分工明确。**
- **多猜**发生在平坦的左侧/视口区：同一目标重复输出（41 对重复、16 对完全同框）+ 大量越界框 + 把一个树行输出成 624×103 的巨型行（真值 258×40，x 偏 −184、宽 2.4 倍）。
- **少猜**发生在密集的右侧面板与弹窗：`0/35`、`0/17` —— 这两个区域不是"猜歪了"，而是**完全没被覆盖**。
- 机制解读：模型缺少"容器/行距先验"，于是把整栏塌成一个大框（`[151,-28,2274,104]` 这类退化框），再在平坦区反复撒碎片。**要提升编辑器类界面，光加正样本不够，得先压掉重复框与越界框，再给面板内"等距行"先验。**
