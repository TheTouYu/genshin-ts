## 三、我改过 `audit_truth.py`（门禁工具，Lead 已复核）

1. **丢弃越界坏框**：OCR 实测存在 `x1=4572 > 2560` 的框（`ms`/`i9`），任何真值框都盖不住 ⇒ 会永久算漏标。
2. **HUD 词表补 `ms|fps|i9|纯数字`**。
3. **覆盖率改为"真值框并集"**（原为"与单框最大重叠"）：OCR 会把相邻多行**粘成一个高框**（实测 `自定义` 高 231px 跨 5 行），
   单框覆盖率永远 <0.6 ⇒ 会把已逐行标好的误判成漏标。并集才对应"这块文字有没有被框住"。
