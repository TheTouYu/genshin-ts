## 方法（与 v2 相同，可复算）

- 行/树/网格边界：`.scratch/gui-corpus/tools/edges.py`（扫描线亮度跃变）+ `remeasure_grid.py`（低亮度同色连通域）
- 小图标/头像/按钮：`.scratch/gui-corpus/tools/boxer.py`
- 行**标签**：用 OCR 文本核对（`label-capture/_screen/*.json`），**不用它的 bbox**
- 身份判定：`read_image` 人眼
- ys-screen 只在最后跑一次做交叉对照，读数写进各帧 `_provenance.tool_crosscheck`
